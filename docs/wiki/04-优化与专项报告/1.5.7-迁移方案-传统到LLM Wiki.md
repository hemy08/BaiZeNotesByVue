# 1.5.7 迁移方案：传统工作区 → LLM Wiki 迁移与编译

> 状态：**方案稿（待拍板，归入 1.5.7 追加批次）**｜编制日期：2026-11-28｜目标版本：**1.5.7（当前开发版本，未发布）**——本方案为 1.5.7 追加批次；1.5.7 已含基础切换/初始化/编译能力
> 关联：[1.5.7 需求清单与方案](./1.5.7-需求清单与方案.md)（已追加迁移批次章节）｜[LLM Wiki 集成实施计划](../02-设计与架构/LLM-Wiki-Implementation-Plan.md)｜帮助文档第 26 章

## 0. 结论先行（推荐方案）

1. **切换（模式切换 + 初始化）不自动搬动任何现有文件**；初始化完成后由**迁移向导**询问用户是否迁移。
2. **迁移方式默认「复制到 `raw/`」（原文件保留）**；「移动到 `raw/`」作为进阶选项（明确警告 + 可回退）；**不提供「原地修改原文件」**。
3. **编译只写入 `wiki/`**（生成新页面），**绝不原地改写原始 Markdown**；编译由用户确认后触发，支持全部/部分/跳过。
4. **批量编译走任务队列 + 分批 diff 审批**（复用 1.5.7 的 diff 审批 UI），支持取消/失败重试。
5. 所有迁移/编译操作**可追溯、可回退**（操作日志 + 可选备份；回滚恢复到原位置）。

## 1. 背景与现状（1.5.7 已实现的基础）

| 能力 | 现状 |
| --- | --- |
| 模式切换 | 设置页「工作区模式」/ 菜单快捷入口/ 右侧边栏 AI 按钮：确认 → 初始化 `raw/`、`wiki/`、`schema.md` → 保存配置 → 布局切换 |
| `raw/` 只读 | 14 类写盘入口被写入守卫拦截；索引/搜索/反链/图谱忽略 `raw/` |
| AI 编译 | 命令面板「AI 编译」：单文件 raw → 生成 wiki 草案 + 行级 diff → 审批后写入 `wiki/` |
| 迁移现有文档 | **无**（初始化只创建目录；现有文件原地不动） |

**待解决的问题**：传统项目切换为 LLM Wiki 后，现有文档如何进入 `raw/`/`wiki/`？是否自动编译？如何避免破坏原文件？

## 2. 切换流程设计（总览）

```text
① 触发切换（设置页/菜单/边栏入口）
   └─ 确认对话框（说明将创建 raw/、wiki/、schema.md 并开启 raw 只读）
② 执行初始化（创建目录 + schema.md 模板；幂等）
③ 迁移向导（新增）——检测现有 Markdown/资料数量后询问：
   ├─ 暂不迁移（默认）
   ├─ 复制到 raw/（推荐）
   └─ 移动到 raw/（进阶，原路径失效警告 + 可回退）
④ 编译向导（新增）——询问是否基于 raw/ 资料编译：
   ├─ 全部编译（后台任务队列 + 进度）
   ├─ 选择部分（勾选文件/目录）
   └─ 跳过
⑤ 完成页：显示「已迁移 N / 已编译 M / 跳过 K」，提供「查看效果」「回滚迁移」「稍后继续」
```

> ① ② 为 1.5.7 已有；③④⑤ 为本方案新增。

## 3. 迁移策略（③ 展开）

| 选项 | 行为 | 适用场景 | 推荐 |
| --- | --- | --- | --- |
| **A. 暂不迁移**（默认） | 仅完成初始化；现有文件原地不动，以后可手动/工具栏迁移 | 想先体验、或文档较少 | ✅ 默认 |
| **B. 复制到 `raw/`** | 原文件**复制**一份到 `raw/`（按原相对目录保留结构）；原文件保留在原位置 | 大多数场景；安全可回退 | ✅ **推荐** |
| **C. 移动到 `raw/`** | 原文件**移动**进 `raw/`，原路径消失 | 希望工作区结构彻底迁移、接受路径变化 | ⚠️ 进阶（需警告） |
| D. 直接当 wiki 内容 | 现有文件视为 wiki 页面（不编译、不迁移） | 纯手写知识库 | ❌ 不推荐（"编译态"名不副实） |

**迁移执行细节（B/C 通用）**：
- **预览清单**：迁移前列出将处理的文件（路径、大小、类型、数量），用户可勾选排除；
- **范围**：默认仅 Markdown（`.md/.markdown`）与常见资料（图片/PDF/文本/HTML）；可配置是否包含附件目录；
- **非 Markdown 资料**：原样复制/移动到 `raw/`，`wiki/` 页面用相对链接引用（1.5.7 嵌入功能已支持）；
- **冲突处理**：`raw/` 已存在同名文件 → 跳过并记录（不覆盖）；
- **结果清单**：迁移完成后列出成功/跳过/失败明细；
- **回滚**：B 方案删除复制体即可；C 方案按操作日志把文件移回原位置（失败中断时逐项报告）。

## 4. 编译策略（④ 展开）

| 项 | 设计 |
| --- | --- |
| 触发 | **用户确认后**才编译（不自动），支持「全部 / 选择部分 / 跳过」 |
| 输入 | 仅 `raw/` 下的资料（迁移完成后执行；B/C 与编译的顺序由向导保证） |
| 输出 | 仅 `wiki/` 下的新页面；front matter `source:` 指向对应 raw 相对路径 |
| 审批 | 复用 1.5.7 的**行级 diff 审批**；批量时按批（如每 10 个）或逐个审批，提供「全部应用（汇总预览）」 |
| 队列 | 后台任务队列：进度、当前文件、可取消、失败可跳过/重试；单文件超时与重试上限 |
| 模型 | 使用 AI 助手配置的默认模型（可切换）；未配置 AI 时编译入口引导配置 |
| 可追溯 | 每个 wiki 页面记录来源 raw 文件（front matter `source`）；应用记录写入本地操作日志 |

## 5. 文件处理规则（关键约束）

1. **绝不原地修改原始 Markdown**：编译是"生成新页面"而非"改写原文"；
2. **原文件去留由用户决定**：复制方案默认保留；移动方案需明确确认；
3. `raw/` 在迁移完成后进入**只读**状态（迁移阶段使用专用 IPC/流程特权写入，不绕过普通守卫的语义）；
4. 所有写 `wiki/` 的操作**必须经 diff 审批**（包括批量编译）；
5. 附件/图片不进入索引；`wiki/` 页面用相对链接引用 `raw/` 资料；
6. 迁移/编译**不修改** `schema.md` 之外的约定文件；`schema.md` 初始化后永不自动覆盖。

## 6. 交互设计（单个弹窗，2026-11-28 用户确认）

> **所有需要用户决策的项目合并到一个弹窗中现场选择**，不预置隐藏默认值。

弹窗结构（切换时出现一次，复用 BaseDialog）：

```text
┌─ 切换到 LLM Wiki ─────────────────────────────┐
│ ⚠ 警告条（仅选中「移动到 RAW」时显示，页面顶部）      │
│   移动到 raw 后原路径将失效，历史链接/最近文件可能失效，  │
│   迁移可回滚（保留操作日志）。                        │
│                                               │
│ ① 迁移方式（单选）                               │
│   ○ 不迁移（默认）   ○ 复制到 raw/   ○ 移动到 raw/    │
│ ② 迁移范围（按文件格式多选，显示各格式数量）          │
│   ☑ Markdown  ☐ 图片  ☐ PDF  ☐ HTML  ☐ 其他文本       │
│ ③ 是否启动编译（开关）  [开]                      │
│ ④ 编译范围（仅③开启时显示，单选）                  │
│   ○ 全量编译  ○ 指定目录编译（选择目录…）  ○ 分批编译  │
│ ⑤ 分批大小（仅「分批编译」时）：每批 [10] 个          │
│                                               │
│                  [取消]  [开始迁移]              │
└───────────────────────────────────────────────┘
```

- **迁移方式**：不迁移（默认）/ 复制到 raw/（推荐）/ 移动到 raw/——**移动到 raw 时弹窗顶部显示警告条**；
- **迁移范围**：按**文件格式**多选（Markdown 默认勾选；图片/PDF/HTML/其他文本可选；显示各格式文件数量）；
- **是否启动编译**：开关（否 = 只迁移或只初始化）；
- **编译范围**：全量编译 / 指定目录编译（选择目录）/ 分批编译（可设每批数量）；
- **入口复用**：设置页工作区模式切换、顶部菜单栏模式按钮、右侧边栏 AI 入口三处统一走该弹窗；
- **完成/进度**：弹窗内或独立进度视图展示「已迁移 N / 已编译 M / 跳过 K」+「回滚迁移」+「查看结果」；
- 无现有文件可迁移时可简化（仅确认初始化 + 是否编译）。

## 7. 任务拆分（1.5.7 追加批次）

| 任务 | 内容 | 预估 |
| --- | --- | --- |
| T-M1 | 迁移向导 UI（多步对话框 + 文件清单 + 结果页） | 3 天 |
| T-M2 | 迁移执行 IPC：复制/移动到 raw（路径校验、冲突跳过、操作日志、回滚）；专用迁移通道不破普通 raw 只读语义 | 3 天 |
| T-M3 | 批量编译任务队列（进度/取消/分批 diff 审批/失败重试） | 4 天 |
| T-M4 | front matter `source` 路径校验与更新（迁移后） | 1 天 |
| T-M5 | 帮助文档（切换与迁移章节）+ E2E 规格 | 2 天 |
| 辅助 | 测试（迁移/回滚/批量编译/边界）、文档口径、门禁 | 并行 |

## 8. 验收标准

- 初始化**不自动**搬动/编译任何文件（默认行为可验证）；
- 迁移向导：A/B/C 三选项可用；B 方案原文件哈希不变；C 方案回滚可恢复原路径；冲突/失败有清单与提示；
- 编译：全部/部分/跳过均可用；批量编译每一批经 diff 审批；取消后已应用的不回滚但未应用的不写盘；
- `raw/` 只读不被普通保存通道绕过；`wiki/` 写入全部经审批；
- 操作日志完整可审计；回滚可用；
- 门禁全绿 + E2E（切换→迁移→编译→回滚 主链路）。

## 9. 决策方式（已确认：运行时单弹窗询问，2026-11-28）

用户确认：**不预置隐藏默认**——上述所有决策项（迁移方式、迁移范围/文件格式、是否编译、编译范围）**全部放进同一个弹窗**，由用户在切换时现场选择：

| 决策项 | 弹窗中的呈现 | 默认 |
| --- | --- | --- |
| 迁移方式 | 单选：不迁移 / 复制到 raw/ / 移动到 raw/ | 不迁移 |
| 移动到 raw 时的警告 | **弹窗顶部警告条**（原路径失效、链接可能断、可回滚） | 仅选中移动时显示 |
| 迁移范围 | 按文件格式多选：Markdown / 图片 / PDF / HTML / 其他文本（显示各格式数量） | Markdown 勾选 |
| 是否启动编译 | 开关 | 关（保守） |
| 编译范围 | 单选：全量编译 / 指定目录编译 / 分批编译（可设每批大小） | 分批（每批 10） |
| 入口 | 三处切换入口统一走该弹窗 | — |

> 仅「取消/开始迁移」两个动作；选择"不迁移 + 不启动编译"时按钮显示为「完成初始化」。
