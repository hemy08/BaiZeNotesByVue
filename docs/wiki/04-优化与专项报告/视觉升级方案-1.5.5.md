# 视觉升级方案（v1.5.5）

> 更新于 2026-11-27　|　**归属版本：v1.5.5**（1.5.3 已发布，体验优化线整体排入 1.5.5）　|　性质：**设计方向稿 + 执行规格（本阶段不改代码）**
> 方法来源：ECC `design-system`（令牌/评分/AI-slop）、`make-interfaces-feel-better`（细节质感）、`frontend-design-direction`（设计方向）、`motion-patterns`（动效）、`accessibility`（对比度/键盘）。
> 关联：[产品体验优化方案](产品体验优化方案.md)（三线总纲，本文是其「线 A 视觉统一」的**升级版**：从"等值替换"升级为"有方向的视觉升级"）。

## 0. 结论先行

- 现状不是"没设计"，而是"逐组件手写、缺少统一视觉语言"：802 处硬编码色值（80 文件）、242 处圆角用了 **21 种值**、91 处 transition 无统一节奏；菜单栏 4px 圆角 / 对话框 8px / 工具窗未统一，同一产品出现"三种性格"。
- 建议采用 **「纸感正文 + 工作台工具区」混合方向**：编辑器/预览走内容优先的静默纸感，菜单/工具窗/表格/状态栏走清晰紧凑的工作台密度。它最贴合"长文写作 + 知识管理"双场景，且能在不推翻 28 套主题观感的前提下落地。
- **已确认实现范围（2026-11-27 拍板）**：① **A/B/C 三种基础风格全部实现**，通过「系统设置 → 外观」开关切换（互斥单选）；② 新增**三档界面密度**（紧凑/默认/宽松），独立于风格；③ **6 个组件全部升级**；④ 追加 **D · Hybrid 混合**（正文纸感 + 外壳工作台）作为第 4 个可选风格（见 §2）。
- 全部升级通过**语义令牌层**完成：主题数据不变、用户已选主题不变，仅统一"尺寸/层级/边界/动效/图标"五类细节。

## 1. 现状基线（实测）

### 默认观感口径（P1 起，2026-11-27 澄清）

- **P0（令牌/风格/密度框架）已达成默认渲染零变化**：组件未消费新令牌前，默认 workbench + default 密度下输出与升级前一致（`ui-style.css` 零组件选择器 + 默认变量=现状 + 全量测试验证）。
- **P1（6 组件 × 4 风格）起，默认 workbench 按 §4 规格显式升级**（对话框标题栏 40、标题 15、遮罩 .32、按钮 32、菜单栏 36、表格行高 28/列头 32 等）——这是"视觉升级"的预期结果，不是回归。
- **回退路径**：默认观感差异集中在默认令牌映射（`ui-style.css` 的 workbench/default 块）与组件规格常量（`dialog-metrics.ts`、`table-style.ts`、`menu-keyboard.ts`），可集中调整而非散落回滚。

| 项 | 现状 | 问题 |
| --- | --- | --- |
| 硬编码色值 | 802 次 / 80 文件 | 主题切换时局部不跟随 |
| 圆角 | 21 种值（菜单 4px、对话框 8px、卡片 6px…） | 同一界面出现"三种性格" |
| 间距 | 无阶梯，padding 6/8/10/12/16 混用 | 视觉"差 2px" |
| 动效 | transition 91 处；菜单用 `all 0.2s cubic-bezier(0.4,0,0.2,1)`，其他混用 ease | 节奏不一致，无 reduced-motion |
| 阴影/层级 | 无分级，z-index 分散 | 悬浮层与弹窗层级感弱 |
| 菜单栏 | `padding 6px 12px`、`radius 4px`、`font 14px` | 与工具窗/对话框风格不统一 |
| 对话框 | `width` 由各调用点自由传入，无阶梯 | 同层对话框宽窄不一 |
| 图标 | 现有 SVG 风格未统一（stroke/尺寸/网格） | 细节杂乱 |
| 键盘可达 | MenuBar 无 role/aria/keydown | 键盘用户不可用 |

## 2. 四个设计方向（全部实现，开关切换）

> **预览与 HTML 版**：
> - [HTML 版方案报告（含四张预览图 + 悬浮导航）](../../design/preview/视觉升级方案-1.5.5.html)
> - 预览图（SVG 矢量）：[A · 纸感](../../design/preview/style-paper.svg) ｜ [B · 轻玻璃](../../design/preview/style-glass.svg) ｜ [C · 工作台](../../design/preview/style-workbench.svg) ｜ [D · 混合](../../design/preview/style-hybrid.svg)

四种风格（A/B/C + Hybrid 混合）**全部实现**，在「系统设置 → 外观 → 界面风格」互斥单选；风格只改「材质与装饰层」（透明度/模糊/阴影/边框/圆角/间距节奏），**不改变主题色相**——因此与 28 套主题正交，不推翻用户已选主题。

| 风格 | 视觉语言 | 技术令牌差异（相对默认） | 适用场景 |
| --- | --- | --- | --- |
| **A. 静默纸感（paper）** | 低饱和纸面、1px hairline、字重层级、极简阴影、微动效 | `surface` 不透明；`shadow-1/2/3` 减弱 30~40%；无模糊；边框以 `border` hairline 为主；圆角偏 4/6 | 长文写作、阅读 |
| **B. 轻玻璃（glass）** | 半透明悬浮层、柔和阴影、8px 圆角、强调色点缀 | `surface` 带 12~20% 透明度；`--surface-blur: 8px`（仅工具窗/下拉/命令面板小面积）；shadow-2/3 偏柔；强调整体层次 | 现代桌面工具感 |
| **C. 高密度工作台（workbench）** | 紧凑行高、清晰分区线、状态色克制、结构化表格 | 行高 28/32、内边距偏小；`border-strong` 用于分区；阴影克制；信息层级靠字号字重而非留白 | 知识管理、高信息密度 |
| **D. 混合（hybrid）** | **正文/预览走 paper 纸感 + 外壳/工具区走 workbench 密度**；两种材质在内容区边界自然分界 | 内容区（正文/预览）用 paper 令牌；顶栏/左栏/状态栏/工具窗/表格/命令面板用 workbench 令牌 | 写作 + 知识管理兼顾（新增可选） |
| **默认：workbench**（可改） | 与 1.5.3 现有工具区观感最接近，迁移成本最低 | — | — |

### 2.1 风格 × 主题 × 密度的关系

- **主题（28 套）**：只提供颜色（18 组语义令牌取值）——不变。
- **风格（3 种）**：提供"材质/装饰"（透明度、模糊、阴影、边框强度、圆角档位）。
- **密度（3 档）**：提供"尺寸节奏"（行高、内边距、字号微调、控件尺寸）。
- 实现：根元素 `data-style="paper|glass|workbench"` + `data-density="compact|default|spacious"`，令牌由 CSS 变量按属性覆盖（与主题变量正交叠加）。
- 组合矩阵：28 主题 × 4 风格 × 3 密度 = 336 种组合，验收采用**代表性采样**（见 §5）。
- hybrid 规则：内容区（正文/预览）使用 paper 令牌，外壳（顶栏/左栏/状态栏）与工具区（工具窗/表格/命令面板）使用 workbench 令牌；材质切换不改主题色。

## 3. 令牌层升级（先立规范，再改组件）

### 3.1 颜色（语义 18 组，替代 802 处硬编码）

`bg`（页面底）/`bg-elevated`（卡片）/`bg-sunken`（代码/输入）/`surface`（工具窗）/`border`（hairline）/`border-strong`/`text`/`text-secondary`/`text-tertiary`/`accent`/`accent-hover`/`accent-soft`（12% 底）/`success`/`warning`/`danger`/`info`/`focus-ring`/`selection`。

- 主题映射不变（28 套主题仅提供这 18 组的取值）；`--accent-color` 保留为 `accent` 别名（兼容）。
- 对比度：正文 ≥4.5:1、大字/图标 ≥3:1；浅色/深色/护眼三类主题分别校验。

### 3.2 尺寸与形状

| 令牌 | 档位 | 说明 |
| --- | --- | --- |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 / 48 | 只允许 7 档（4px 基准） |
| 圆角 | 2（chip/标签）/4（控件按钮）/6（输入/卡片）/8（弹窗/工具窗）/999（胶囊） | **21 种 → 5 档** |
| 行高（密度） | 紧凑 28 / 默认 32 / 宽松 36 | 菜单项、工具按钮、表格行 |
| 字号 | 11（辅助）/13（UI 默认）/15（强调）/18（小标题）/22（大标题）/正文 16 | UI 不再出现 14/15 混用 |
| 字体 | UI：系统栈；正文：用户可选（含中文衬线）；代码：等宽栈 | 写作模式可调 18~20 |

### 3.3 阴影与层级

| 令牌 | 取值 | 用途 |
| --- | --- | --- |
| shadow-1 | `0 1px 2px rgba(0,0,0,.06)` | 卡片、输入聚焦底 |
| shadow-2 | `0 6px 24px rgba(0,0,0,.12)` | 悬浮层、工具窗、下拉 |
| shadow-3 | `0 16px 48px rgba(0,0,0,.18)` | 对话框、命令面板 |
| focus-ring | `0 0 0 3px accent-soft` | 键盘焦点（替代 outline） |

z-index 层级表：内容 0 / 侧栏 10 / 拖拽 20 / 工具窗 30 / 下拉 40 / 对话框 50 / 命令面板 60 / Toast 70 / 引导 80。

### 3.4 动效

| 场景 | 时长/缓动 |
| --- | --- |
| 状态反馈（hover/active/toggle） | 120ms `cubic-bezier(.2,0,0,1)` |
| 弹出/收起（下拉、工具窗） | 180ms `cubic-bezier(.2,0,0,1)`，自动淡入+位移 4px |
| 对话框进出 | 240ms 标准；遮罩 200ms 淡入 |
| 页面/模式切换 | 300ms，缓动 `cubic-bezier(.4,0,.2,1)` |
| 减少动效 | `prefers-reduced-motion: reduce` → 全部降级为 0ms 或 100ms 淡入 |

### 3.5 图标与边框

- 图标：24 网格、stroke 1.5、currentColor；统一尺寸 16/20/24 三档；禁用 emoji 作为功能图标。
- 边框：所有分隔用 1px hairline（`border` 令牌）；禁止 2px 实线（除选中态外）。

### 3.6 风格层与密度层（新增，开关驱动）

**风格层令牌（按 `data-style` 覆盖）**：

| 令牌 | paper | glass | workbench |
| --- | --- | --- | --- |
| `--surface-opacity` | 1 | 0.86 | 1 |
| `--surface-blur` | 0 | 8px（限小面积） | 0 |
| `--shadow-1/2/3` | 减弱 30~40% | 柔化、扩散更大 | 克制（1 档为主） |
| `--border-strength` | hairline 全量 | hairline + 高光边 | 分区用 `border-strong` |
| `--radius-scale` | 4/6/8 | 8/8/12（偏大） | 2/4/6（偏小） |
| 透明降级 | 无 | 检测 `prefers-reduced-transparency` / 性能差 → 回退 paper 材质 | 无 |

**密度层令牌（按 `data-density` 覆盖）**：

| 令牌 | compact | default | spacious |
| --- | --- | --- | --- |
| 行高（菜单/表格/列表） | 24 | 28 | 32 |
| 控件高（按钮/输入） | 28 | 32 | 36 |
| 内边距基准 | 8 | 12 | 16 |
| UI 字号 | 12 | 13 | 13（行高放宽） |
| 工具窗标题栏 | 36 | 40 | 44 |

**配置项**（系统设置 → 外观，新增）：
- `uiStyle`：`paper | glass | workbench`（默认 `workbench`）
- `uiDensity`：`compact | default | spacious`（默认 `default`）
- `uiReduceTransparency`：布尔（默认 false；glass 下可强制不透明，照顾性能/可读性）

**约束**：风格不改变颜色；密度不改变字号字重层级；两者均不得改变布局结构（仅尺寸节奏），保证与现有 E2E/截图基线可对齐。glass 的 blur 仅用于悬浮层（工具窗/下拉/命令面板），禁止整窗大面积 blur。

## 4. 组件升级规格（6 个对象）

### 4.1 菜单栏

- 高度 36（现状约 36~40，统一）；项内边距 `0 12px`、行高 28、圆角 4；下拉面板 radius 8 + shadow-2、内边距 6、项高 28、悬停 `accent-soft`。
- 键盘：`role=menubar/menu/menuitem`、方向键/Enter/Esc/Home/End（与体验线 B1 合并）。
- 分隔符：1px hairline + 上下 6px 间距。

### 4.2 非模态工具窗（1.5.3 新增，优先级最高）

- 统一壳：标题栏高 40（标题 13/600 + 图标 + 关闭/最小化 28×28）、内容内边距 12、radius 8、shadow-2、边框 hairline。
- 拖拽把手：标题栏左侧 6 点纹理；缩放边界限制在窗口可视区；外部点击不关闭（现状）保持不变。
- 焦点：打开时聚焦内容首个可交互元素；`Esc` 只关闭最顶层工具窗；与编辑器滚动同步互不干扰。

### 4.3 表格编辑器

- 行高 24（紧凑）/28（默认）/32（宽松）；列头 = 行高 + 4；字重 600、底色 `bg-elevated`；单元格边框 hairline；选区 `accent-soft`；列宽拖拽手柄 4px（hover 才显色）。
- 数字右对齐、文本左对齐、日期统一 `YYYY-MM-DD`；空单元格占位不显示"0"。

### 4.4 对话框（BaseDialog）

- 宽度阶梯：360（确认）/520（表单）/720（中等，默认）/960（复杂）/全宽（特殊）；不再由调用点自由传任意值。
- 标题栏 40、标题 15/600；内容内边距 16；底部按钮 32 高、主按钮 accent。
- 遮罩：`rgba(0,0,0,.32)`（浅色）/`.48`（深色），可选 2px 模糊；radius 8、shadow-3。

### 4.5 命令面板

- 宽 720、radius 8、shadow-3；行高 32、左右内边距 12；分组标题 11/600 大写 + `text-tertiary`；选中行 `accent-soft` + 左侧 2px accent 条；快捷键 chip：radius 2、hairline 边框、字号 11。

### 4.6 状态栏与空态

- 状态栏：高 24、字号 12、`text-secondary`；分隔用 1px hairline；错误用 danger 点 + 可点击打开详情。
- 空态：统一 SVG 插图（1 套 6 变体：空文件/无搜索/无标签/无附件/无标注/未启用）+ 主标题 15 + 描述 13 + 主按钮；不得使用大段占位文字。

### 4.7 编辑器正文（纸感）

- 正文 16/1.75、段落间距 0.75em、标题上 1.5em/下 0.5em；引用条 3px accent 30%；代码块 radius 6 + 内边距 12；列表缩进 1.25em；选中色 accent-soft。

## 5. 主题兼容与验收

### 5.1 主题适配策略（28 套主题 × 4 风格）

28 套主题当前每套只定义 **10 个基础颜色字段**（backgroundColor / cardBackground / textColor / secondaryTextColor / borderColor / accentColor / buttonBackground / buttonTextColor / hoverBackground / titleBarGradient），没有 18 组语义令牌。风格层不改颜色，因此需要 **P0 先建立派生映射**，之后四种风格对全部主题自动适用：

| 语义令牌 | 派生规则（28 套主题通用） |
| --- | --- |
| `bg` / `bg-elevated` / `bg-sunken` | backgroundColor / cardBackground / hoverBackground 加深 |
| `border` / `border-strong` | borderColor / borderColor 加深 8% |
| `text` / `text-secondary` / `text-tertiary` | textColor / secondaryTextColor / 派生降低 20% |
| `accent` / `accent-soft` / `accent-hover` | accentColor / accentColor 12% alpha / accentColor 加深 |
| `success` / `warning` / `danger` / `info` | 全主题共用语义色（浅色/深色各一套） |
| `focus-ring` / `selection` | accentColor 30% / accentColor 15% |

**按主题类别差异化处理**：

| 主题类别 | glass | paper | 备注 |
| --- | --- | --- | --- |
| 浅色主题（多数） | 正常：surface 0.86 + 8px blur | 正常：主题浅色面 + hairline | 预览图基准 |
| **深色主题**（dark / deepdark / 白泽数据深色 / 白泽镜像深色） | **surface 用主题深色面 + 透明度**（非固定白）；高光边降为 10~18% 白；自动降低透明度 | **不强制暖白**：主题深色面 + hairline + 轻阴影（安静材质） | 严禁固定白底破坏深色主题 |
| **高饱和/渐变主题**（珊瑚暖阳 / 日落余晖 / 森林秘境 等） | **自动降级**：透明度 ≥0.94 或关闭 blur（玻璃稳健模式） | 正常 | 半透明叠彩色渐变会视觉混乱 |
| **护眼主题（7 套）** | 降低透明度、提高对比 | 正常 | 本身低对比，风格不得进一步降低对比度 |
| Monaco 编辑器（57 套） | 不参与 | 不参与 | 风格不改编辑器主题；paper 只改 UI 正文排版（行高/字重/留白） |

**结论**：四种风格**适用于全部 28 套主题**——前提是 ① 18 组语义令牌派生落地（P0）；② 深色/高饱和/护眼主题按上表自动降级；③ 固定色（如预览图暖白）仅作示意，实施以主题色驱动。

- **不改变 28 套主题的观感基线**：主题仍只提供颜色，升级的是"尺寸/层级/边界/动效/图标"；`--accent-color` 等旧变量保留别名。
- **验收采样矩阵**（252 组合不全测，按代表性抽样）：
  - 风格矩阵：6 组件 × 4 风格 × 2 代表主题（浅/深）= **48 张截图基线**；
  - **主题类别矩阵**：4 风格 × 3 类主题（浅色/深色/高饱和·护眼）× 6 组件抽样 = **额外 12 张**（重点：glass 深色/高饱和降级、paper 深色、护眼对比度）；
  - 密度矩阵：6 组件 × 3 密度 × 1 主题 = **18 张截图基线**；
  - glass 专项：blur 降级（reduceTransparency）与 `prefers-reduced-transparency` 6 张；
  - 合计 **78 张基线** + 对比度扫描（18 色 × 4 风格 × 浅/深/护眼）+ 键盘走查 + 四风格下 Esc/Tab 语义一致。
  - 口径说明（P2 回写）：78 = 48（风格矩阵）+ 18（密度矩阵）+ 12（主题类别矩阵）；glass 专项 6 张若单列则合计 84 张。P2 执行状态与真实截图覆盖见 [P2-VERIFICATION](../../design/P2-VERIFICATION.md) §6。
- 评分：沿用 `design-system` 10 维评分（升级前 vs 三风格各自对比，目标总分 +20%）。
- 回归守护：新增 `tests/unit/ui-style-tokens.test.ts`——校验三风格令牌完整、18 色对比度、密度档位数值唯一来源；视觉基线截图纳入 E2E（可选软门禁）。

## 8. 已确认决策与待定细节

**已确认（2026-11-27）**：
1. **A/B/C 三种基础风格全部实现 + D Hybrid 混合**（共 4 种），通过「系统设置 → 外观 → 界面风格」互斥开关切换；
2. **新增三档密度**（紧凑/默认/宽松），独立于风格；
3. **6 个组件全部升级**，批次 P0→P2 见 §6。

**仍需你确认的实现细节**（我会按建议默认执行，除非你另有指示）：
1. **默认风格**：建议 `workbench`（与 1.5.3 现有观感最接近，迁移成本最低）；默认密度 `default`（现状不变）。
2. **风格是否作用于编辑器正文**：建议 `paper` 风格下正文启用纸感排版（行距/字重），`glass`/`workbench` 下正文保持现状；三者都允许写作模式独立覆盖版式。
3. **glass 的透明度与模糊**：默认 `--surface-opacity: 0.86` + 8px blur（仅悬浮层）；提供「减少透明」开关（默认关），检测 `prefers-reduced-transparency` 自动回退。
4. **验收基线**：按 §5 的 60 张截图采样矩阵（不做 252 全测），截图归档 `out/`（不入库）。
5. **开关的默认可见性**：三项新设置放在「外观」页签，`glass` 标记为"实验性"（性能提示），是否接受？
