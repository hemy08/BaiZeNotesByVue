# 1.5.6 需求清单与方案（需求建议稿）

> 状态：**需求建议稿（待拍板）**｜编制日期：2026-11-28
> 依据：1.5.5 已发布版本的实测基线 + 当前 `main`（工具窗体验批次）的遗留盘点 + 三轮用户反馈模式
> 关联：[产品体验优化方案](./产品体验优化方案.md)｜[ECC 能力驱动的项目优化方案](./ECC能力驱动的项目优化方案.md)｜[视觉升级方案-1.5.5](./视觉升级方案-1.5.5.md)

## 0. 结论先行

建议 1.5.6 定位为**「可读性与可发现性」版本**——不新建大框架，把 1.5.5 视觉升级的"效果"落到"每天用得顺手"上：

| 批次 | 内容 | 优先级 | 工作量 | 风险 |
| --- | --- | --- | --- | --- |
| **A. 主题可读性治理** | 14 套主题按钮文字对比度修复 + 3 套主题分组/明暗数据修正 + 对比度硬门禁 | **P0** | M（2~3 人日） | 低（纯配色数据 + 测试） |
| **B. 插件工具可发现性** | 38 项插件工具：面板搜索框 + 最近使用 + 收藏 + 分类折叠 | **P1** | M（2~3 人日） | 低（局部 UI，无 IPC 变更） |
| **C. 帮助文档重采集与瘦身** | 帮助截图按 1.5.6 UI 重采集 + PNG→WebP（回收 ~1MB 体积）+ 帮助内搜索 | **P1** | M（1.5~2.5 人日） | 低（脚本 + 资源） |
| D. 命令面板增强（可选） | 最近命令/使用频率排序 + 分组折叠 + 空态建议 | P2 | S（0.5~1 人日） | 低 |
| E. 工具窗收尾（可选） | 插件面板最小化联动工作区空白收起 + Alt+字母助记符 | P2 | S（0.5~1 人日） | 低~中 |

> 若 1.5.6 只做一组：**优先 A**（可读性直接影响所有用户；且工作量可控、零架构风险）。
> 若做两组：**A + B**（可读性 + 工具可发现性，覆盖"看得清"与"找得到"两个高频痛点）。

### 1.3 能力盘点（需求不得重复建设）

- 38 项插件工具（加解密 8 / 编解码 5 / 格式转换 / 文本转换 / 格式化 / 小工具 / 网络计算 / 对照表）
- 28 套应用主题 + 57 套 Monaco 编辑器主题；10 项可选能力开关
- Markdown 编辑：格式工具栏、统一表格编辑器、公式/Mermaid/PlantUML、图片插入、EPUB/幻灯片/打印导出、未命名草稿保护
- 知识库：Wiki 链接、工作区搜索、反向链接（按需确认）、命令面板、AI 导航、写作模式、自动保存/备份/历史
- 工程：369 测试文件 / 6,806 用例、coverage 93.06%、9 项体积预算、8 项 fuses、E2E 16 spec

### 1.4 用户反馈模式（三轮）

1. 视觉升级后：**"风格切换看不到效果"** → 根因是令牌消费缺位 + 验收只测稳定性（已修复）
2. 菜单：**"三级子菜单不显示 + 滚动条"** → 根因是 overflow 裁剪（已修复）
3. 工具窗：**"表格编辑器不能调大小"** → 根因是 padding 溢出裁剪 resize-grip（已修复）；同时提出**工具窗最大化/最小化**需求（已实现）

> 模式：**用户高频关注"看得见的效果"与"可操作性"**，而非底层架构。1.5.6 需求应优先"用户可感知的品质"。

## 3. 建议的 1.5.6 范围与批次

### 方案一（推荐）：A + B + C 三批次

1. **批次 1（P0，先做）**：REQ-01 / REQ-02 / REQ-03 —— 主题可读性治理（含硬门禁）
2. **批次 2（P1）**：REQ-04 / REQ-05 —— 插件工具搜索 + 最近/收藏（面板顶栏已具备承载位置）
3. **批次 3（P1）**：REQ-07 / REQ-08 —— 帮助截图重采集（脚本入库）+ WebP 瘦身

预期版本主题：**看得清、找得到、查得准**。

### 方案二（轻量）：只做 A + C

- 若时间紧：先保证 28 主题可读性（REQ-01/02/03）+ 帮助配图与体积（REQ-07/08），B 顺延 1.5.7。

### 不做（避免范围膨胀）

- 插件工具增删（38 项已稳定，不做新工具）
- 框架级重构（contract-first/ADR 等工程治理项 1.5.7 再做）
- 整窗玻璃模糊（性能取向不回归）

## 5. 需要拍板的三件事

1. **1.5.6 范围**：方案一（A+B+C，约 5~8 人日）还是方案二（A+C）？
2. **REQ-01 的修法**：按钮文字改深色（保持强调色）还是压暗按钮底（保持白字）？——影响 14 套主题观感，建议逐主题按"对比度优先 + 主色尽量保留"处理，需授权可微调主题配色。
3. **帮助截图采集脚本**：是否纳入仓库 `build/`（推荐，长期可复跑）？以及是否允许把 22 张 PNG 转为 WebP（需接受帮助文档图片格式变化）。
