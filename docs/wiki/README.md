## 六、文档维护约定

1. **时效标注**：当前状态类文档开头统一写 `> 更新于 YYYY-MM-DD（对照 vX.Y.Z）`；历史快照不加该行，正文数字保持原貌。
2. **数字口径**：版本、技术栈、组件/测试/覆盖率等数字以 `out/doc-baseline.md` 最新基线为准，不凭记忆填写。
3. **功能一致性**：功能说明必须与当前源码一致；不确定处标注「需人工确认」并写明依据文件与行号。
4. **新增文档**：放进对应分类后，同步更新本 README 的「目录结构 / 文档清单」与 `_sidebar.md`，并更新文档计数。
5. **链接检查**：分类间引用使用相对路径；改文件名后全量检查 Markdown 相对链接是否仍能解析（当前 27 篇文档 0 处失效链接）。
6. **格式约定**：优先表格/列表；图使用 SVG；Markdown 与 HTML 报告分目录存放（见 `AGENTS.md`）。
