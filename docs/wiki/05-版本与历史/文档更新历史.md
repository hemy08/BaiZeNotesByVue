## 三、架构分析更新

### 3.1 三层架构详解

```
┌─────────────────────────────────────────────┐
│           主进程 (Main Process)              │
│  • 应用生命周期管理                           │
│  • 原生 API 调用                             │
│  • 文件系统操作                               │
│  • IPC 通信处理                               │
│  • 窗口管理                                   │
└─────────────────────────────────────────────┘
                    ↕ IPC 通信
┌─────────────────────────────────────────────┐
│         预加载脚本 (Preload Script)          │
│  • contextBridge API 暴露                    │
│  • 安全的进程间通信                           │
│  • 配置和应用信息 API                         │
└─────────────────────────────────────────────┘
                    ↕ 
┌─────────────────────────────────────────────┐
│          渲染进程 (Renderer Process)         │
│  • Vue 3 组件系统                            │
│  • 用户界面渲染                               │
│  • 状态管理 (Vuex + Composition API)         │
│  • Monaco 编辑器集成                          │
└─────────────────────────────────────────────┘
```

### 3.2 模块职责分析

**主进程模块**:
- config/: 配置管理（主题、编辑器、系统设置）
- dialogs/: 对话框管理（20+ 对话框）
- ipc/: IPC通信（处理器、菜单、监听器管理）
- renders/: 自定义渲染器（KaTeX、Mermaid、Material）
- utils/: 工具函数（文件操作、加密解密、日志）

**渲染进程模块**:
- components/Markdown/: Markdown编辑器核心
- components/WorkSpaceArea/: 工作区管理
- components/MenuBar/: 菜单栏
- components/dialogs/: Vue对话框组件
- common/: 公共模块（状态管理、模板、事件总线）

## 2026年11月15日更新 (v1.3.0)

- **更新日期**: 2026-11-15

- **更新内容**: 全量扫描与两轮修复（94 项问题、15 项技术债），版本升级 1.3.0。
- **主要变更**:

  - 性能：预览 `highlightAuto` 修复（慢 12~155 倍 → 正常）、目录增量刷新（-94.8%）、KaTeX LRU 200 与大文档降级（-94.9%）、Admonition 线性化（-91.9%）、monaco 语言 worker 移除（-14.74MB）。
  - 安全：Path Guard、配置 schema 校验、GCM authTag 打通、远程图片隐私开关、日志脱敏、F12 生产禁用。
