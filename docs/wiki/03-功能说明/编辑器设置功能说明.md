# 编辑器设置功能说明

> 更新于 2026-11-19
>
> 事实来源：`src/renderer/src/components/dialogs/complex/EditorSettingDialog.vue`、`src/main/config/editor-setting.ts`、`src/main/config/config-manager.ts`、`src/renderer/src/components/Markdown/MarkdownMonacoEditor.vue`、`src/renderer/src/components/Markdown/editor-option-maps.ts`，以及对应单元测试。
> 一句话结论：**编辑器设置只有一个真源（主进程 `editorSetting`）**，渲染层对话框字段经映射写入该真源，保存后由主进程广播 `INIT_SETTING` 让 Monaco 立即生效；对话框内 **7 个「暂未实现」字段在 UI 上禁用并标注**。

## 1. 功能概述

| 项 | 当前实现 |
| --- | --- |
| 对话框类型 | **Vue 组件对话框** `EditorSettingDialog.vue`（主窗口内 Teleport，非独立 HTML/JSDOM 对话框） |
| 菜单入口 | 设置 → 编辑器设置（`menuAction = baize:menu:setting:monaco-editor`）→ 渲染层 `showDialog('editorSettings')` |
| 主进程旧 HTML 对话框 | `src/main/dialogs/ShowEditorSettingDialog.ts` **已删除**（P2 死代码清理）；主进程不再产生任何编辑器设置 HTML 界面 |
| 设置字段数 | **16 个**（9 个真实生效 + 7 个禁用占位） |
| 生效对象 | 主进程 `editorSetting` 单一真源 → 渲染层 Monaco（`EDITOR.GET_SETTING` / `INIT_SETTING`） |
| 默认值真源 | `src/main/config/editor-setting.ts` 的 `defaultEditorSetting`（约 200 个 Monaco 选项） |
| 即时生效 | 保存后主进程广播 `IPC.EDITOR.INIT_SETTING`，已挂载的 Monaco 立即 `updateOptions` |

> 与旧文档最关键的差异：**不是 59 项/13 类**，也没有「应用 / 确定 / 取消 / 重置默认」四个按钮的旧 IPC 信号。当前界面只有 16 个字段、4 个侧边面板、3 个按钮，且**没有「重置默认」按钮**（主进程 `resetEditorSetting()` 仍保留函数，但无 UI/IPC 调用方）。

## 2. 入口与界面结构

### 2.1 打开链路

```text
MenuBar（设置 → 编辑器设置，menuAction=baize:menu:setting:monaco-editor）
  → menu-actions.ts：configStore.showDialog('editorSettings')
    → BaiZeNotes.vue 渲染 <EditorSettingDialog :visible="configStore.dialogs.editorSettings.visible" @close="hideDialog('editorSettings')" />
      → visible 变 true 时 loadSettings()：并行读取 config:read('editor') + config:read('system')
```

- 对话框的 `apply` 事件**未被父组件消费**（`BaiZeNotes.vue` 只监听 `close`）：所有持久化副作用在对话框内部通过 `window.api.config.write('editor', {...})` 完成，父组件无需再处理。
- 打开时读取失败只记录日志，保持默认值，不阻塞对话框打开。

### 2.2 界面结构（900 × 700）

| 区域 | 内容 |
| --- | --- |
| 标题栏 | 文案 `编辑器设置`（i18n `dialogRenderer.editorSetting.title`），可拖拽，右上角关闭按钮 |
| 左侧栏 | 4 个面板入口：基础设置（⚙️）/ 外观设置（🎨）/ Markdown（📝）/ 高级设置（🔧） |
| 内容区 | 对应 4 个 `.setting-panel`（`v-show` 切换，保留输入状态） |
| 底部按钮 | 取消 / 应用 / 确定（i18n `common.cancel` / `common.apply` / `common.ok`） |

### 2.3 4 个面板与字段分布

| 面板 | 分组 | 字段 |
| --- | --- | --- |
| 基础设置 | 自动保存 | 启用自动保存、自动保存间隔（秒） |
| 基础设置 | 编辑体验 | 启用代码折叠、显示行号、启用自动补全 |
| 外观设置 | 光标与选择 | 光标样式（线条/方块/下划线/闪烁）、光标宽度（1~5） |
| 外观设置 | 字体设置 | 字体大小（10~24）、行高（1~3 倍，步进 0.1） |
| Markdown | 实时预览（禁用） | 启用实时预览、预览延迟（毫秒） |
| Markdown | 语法高亮（禁用） | 启用代码块高亮、启用链接高亮 |
| 高级设置 | 性能（禁用） | 最大文件大小（MB）、渲染延迟（毫秒） |
| 高级设置 | 实验性功能（禁用） | 启用实验性功能 |

Markdown 与高级面板顶部各有一条警示提示（`hintNotImplemented`：*该选项暂未接入实际功能，保存后不会产生效果，后续版本支持*）；基础面板顶部有说明提示（`hintAppliedImmediately`：*保存后立即应用到当前编辑器*）。

## 3. 设置项清单（16 项）

### 3.1 生效字段（9 项）

| # | 字段 | 控件 / 范围 | 默认值 | 持久化去向 | 实际消费方 |
| --- | --- | --- | --- | --- | --- |
| 1 | `autoSave` | checkbox | `true` | **系统设置** `systemSetting.autoSaveEnabled` | 主进程自动保存定时器 `StartAutoSaveFileTime` |
| 2 | `autoSaveInterval` | number，10~300 秒 | `30` | **系统设置** `systemSetting.autoSaveInterval` | 自动保存定时器（`interval * 1000`，<5 秒按 60 秒兜底） |
| 3 | `enableFolding` | checkbox | `true` | `editorSetting.folding` | Monaco 折叠 |
| 4 | `showLineNumbers` | checkbox | `true` | `editorSetting.lineNumbers = 'on' / 'off'` | Monaco 行号 |
| 5 | `enableAutoComplete` | checkbox | `true` | `editorSetting.quickSuggestions` | Monaco 快速建议 |
| 6 | `cursorStyle` | select：line / block / underline / blink | `'line'` | `line/block/underline → editorSetting.cursorStyle`；`blink → editorSetting.cursorBlinking='blink'` | Monaco 光标 |
| 7 | `cursorWidth` | range 1~5 | `2` | `editorSetting.cursorWidth` | Monaco 光标宽度 |
| 8 | `fontSize` | number 10~24 | `14`（初次渲染默认；主进程默认值 15） | `editorSetting.fontSize` | Monaco 字号 |
| 9 | `lineHeight` | number 1~3（倍数） | `1.6` | `editorSetting.lineHeight = round(fontSize × 倍数)` 像素 | Monaco 行高 |

> 说明：字段默认值来自 `EditorSettingDialog.vue` 的 `initialSettings`（渲染层回填兜底），与主进程 `defaultEditorSetting` 不完全相同（如 `fontSize` 14 vs 15）；首次打开会先 `config:read('editor')` 用**真源反算值**覆盖，因此实际以主进程为准。

### 3.2 禁用字段（7 项，标注「暂未实现」）

| # | 字段 | 控件 | 默认值 | 禁用原因 |
| --- | --- | --- | --- | --- |
| 10 | `enableLivePreview` | checkbox | `true` | 无 Monaco/渲染层消费方 |
| 11 | `previewDelay` | number 100~2000 | `300` | 无消费方 |
| 12 | `enableCodeHighlight` | checkbox | `true` | 无消费方（代码高亮由预览管线固定启用） |
| 13 | `enableLinkHighlight` | checkbox | `true` | 无消费方 |
| 14 | `maxFileSize` | number 1~100 | `10` | 无消费方（大文件保护由 Monaco 的 `largeFileOptimizations` + 5MB 流式读取阈值等固定常量控制） |
| 15 | `renderDelay` | number 50~500 | `100` | 无消费方 |
| 16 | `enableExperimental` | checkbox | `false` | 无消费方 |

禁用字段的 DOM 统一 `disabled` + `title="该选项暂未接入实际功能…"`，并在面板顶部显示警示条（`.panel-hint-warning`）。**保存时这些字段仍会随 payload 提交，但映射函数会忽略**（`mapRendererSettingsToEditorSetting` 只读取 7 个有对应项的字段），因此不会污染真源。

## 4. 单真源持久化模型

### 4.1 存储位置与键

| 项 | 值 |
| --- | --- |
| 文件 | `~/.baizenotes/config/editor-setting.json`（`getUserDataPath()` = 用户主目录 + `.baizenotes`，见 `src/main/utils/app-paths.ts`） |
| 键 | `editorSetting`（`createSafeConfigModule` 的 `storageKey`） |
| 历史残留键 | `rendererEditorConfig`（ARC-04 双轨期旧键）：启动迁移 `migrateRendererEditorConfig()` 一次性映射合并进 `editorSetting` 后删除，**不再写入** |
| 默认值落盘 | 首次 `getEditorSetting()` 访问时把 `defaultEditorSetting` 写入存储（历史行为，测试依赖） |
| 管理模块 | `src/main/config/editor-setting.ts`（导出 `getEditorSetting` / `saveEditorSetting` / `resetEditorSetting` / `getDefaultEditorSetting`） |
| 类型真源 | `src/shared/types/editor.ts` 的 `EditorSetting`（跨进程契约类型，主进程 `import type` 并 re-export） |

### 4.2 单一真源原则（P1-FE-05）

```text
EditorSettingDialog（渲染层，16 个历史私有字段）
   │  config:write('editor', {...})            ← 保存
   ▼
config-manager.ts  applyEditorSettingsFromRenderer()
   ├─ applyRendererEditorConfig(data)          // 7 个字段映射 → editorSetting 唯一真源
   ├─ applySystemSettings({autoSaveEnabled, autoSaveInterval})   // 自动保存 → 系统设置
   └─ broadcastEditorSetting()                 // 广播 INIT_SETTING
   ▼
editor-setting.json（editorSetting 键）  ←→  Monaco（GET_SETTING / INIT_SETTING / UPDATE_OPTIONS）
```

- 读写经 `config:read('editor')` / `config:write('editor')` 路由到 `STORE_BACKED_CONFIGS.editor`：
  - `read: () => getRendererEditorConfig()`：把主进程 `EditorSetting` **反算**成对话框可回填的字段形状（含默认值兜底：`lineHeight` 自动时回填 1.6 倍、`cursorWidth` 为 0 时回填 2）。
  - `write: (data) => applyEditorSettingsFromRenderer(data)`：映射写盘 + 自动保存副作用 + 广播。
- 因此**不存在第二份渲染层配置**；`editorSetting` 是 Monaco 与对话框共同读写的唯一真源。

## 5. 字段映射规则

`mapRendererSettingsToEditorSetting(data, base)`（纯函数，便于单测）：

| 对话框字段 | Monaco `EditorSetting` 字段 | 规则 |
| --- | --- | --- |
| `fontSize` | `fontSize` | 正数才覆盖并 `Math.round`；否则保留原值 |
| `lineHeight`（倍数） | `lineHeight`（像素） | 正数时 `max(1, round(fontSize × 倍数))`；非正保留原值 |
| `showLineNumbers` | `lineNumbers` | `true → 'on'`，`false → 'off'` |
| `enableFolding` | `folding` | 布尔直传 |
| `enableAutoComplete` | `quickSuggestions` | 布尔直传（Monaco 侧由 `updateEditorOptions` 展开为 `{other, comments, strings}`） |
| `cursorStyle = 'blink'` | `cursorBlinking = 'blink'` | 特殊映射 |
| `cursorStyle = 'line' \| 'block' \| 'underline'` | `cursorStyle` | 同名直传 |
| `cursorWidth` | `cursorWidth` | `>= 1` 才覆盖并取整 |
| 其余 7 个禁用字段 + `autoSave*` | — | **不写入 `editorSetting`**（`autoSave*` 走系统设置；禁用字段直接忽略） |

反算 `getRendererEditorConfig()`：

| `EditorSetting` | 对话框字段 | 规则 |
| --- | --- | --- |
| `fontSize`（<=0 兜底 15） | `fontSize` | 直读 |
| `lineHeight`（0 表示自动） | `lineHeight` | `round((lineHeight / fontSize) * 10) / 10`；为 0 时回填 1.6 |
| `lineNumbers !== 'off'` | `showLineNumbers` | 布尔 |
| `folding !== false` | `enableFolding` | 布尔 |
| `quickSuggestions`（非布尔兜底 true） | `enableAutoComplete` | 布尔 |
| `cursorBlinking === 'blink'` | `cursorStyle = 'blink'` | 否则把 `line-thin/block-outline/underline-thin` 归一为 `line/block/underline` 后回填 |
| `cursorWidth`（0 兜底 2） | `cursorWidth` | 数值 |

## 6. 保存后即时生效链路

### 6.1 两条触发路径

| 时机 | 链路 |
| --- | --- |
| **应用启动** | `main/index.ts` `ready-to-show` → `mainWindow.webContents.send(IPC.EDITOR.INIT_SETTING, getEditorSetting())`；组件同时另有挂载时的 `GET_SETTING` 兜底（见第 6.2 节），避免启动时序丢配置 |
| **对话框保存** | `config:write('editor')` → `applyEditorSettingsFromRenderer` → `broadcastEditorSetting()` → `send(IPC.EDITOR.INIT_SETTING, getEditorSetting())` |
| **编辑器挂载兜底** | `MarkdownMonacoEditor.vue` `onMounted` 后主动 `invoke(IPC.EDITOR.GET_SETTING)`，解决「INIT_SETTING 早于编辑器创建」的时序问题 |

### 6.2 渲染层应用

`MarkdownMonacoEditor.vue`：

```ts
window.electron.ipcRenderer.on(IPC.EDITOR.INIT_SETTING, handleUpdateEditorOptions)
// handleUpdateEditorOptions → editor.updateEditorOptions(editorInstance, settings)
```

`updateEditorOptions`（`editor-option-maps.ts`）：

- 以 `EditorOptionMaps`（137 条字段 → Monaco 选项映射）逐字段写入，**未知字段只告警不抛错**（`logger.warn('未知的配置项: ...')`）。
- 特殊形状转换：`minimap → { enabled }`、`rulers` 字符串 `"80,120"` → `number[]`、`guides`/`bracketPairColorization`/`unicodeHighlight`/`stickyScroll` 对象直传、`quickSuggestions` 布尔 → `{other, comments, strings}`、`occurrencesHighlight` 布尔 → `'singleFile'/'off'`、`selectionHighlight` 布尔 → `'always'/'never'`、`renderIndentGuides`/`highlightActiveIndentGuide` 合并进 `guides`、`showAdjustSettingTip` → `hover.enabled`。
- 一次性 `editor.updateOptions(options)`，避免逐项刷新。

> 结论：**保存即生效，无需重启**；「取消」不写盘，编辑器保持原配置。

## 7. 7 项禁用字段说明

- **判定依据**：这 7 个字段在 `EditorSetting` 中**没有对应项**，渲染层也没有任何消费者（预览/高亮/大小限制等由其它固定实现控制）。若保持可编辑会造成「假开关」误导演示（P1-FE-05）。
- **UI 表现**：`disabled` + 面板警示条 + `title` 提示；`tests/unit/vue2/complex-dialogs.test.ts` 断言 Markdown 面板 3 个禁用 checkbox + 1 个禁用 number（共 4 项）、高级面板 3 个禁用控件（共 3 项），合计 **7 项**。
- **保存行为**：字段仍随 payload 提交（保持将来启用时的数据通道），但映射函数显式忽略。
- **正确口径**：是 **7 项**，不是 13 项（历史基线文档中的「13 项」为笔误，以代码/测试为准）。

## 8. 按钮语义

| 按钮 | 行为 | 效果 |
| --- | --- | --- |
| 取消 | `Object.assign(settings, initialSettings)` 回滚本次改动 + `emit('close')` | 不写盘，对话框关闭 |
| 应用 | `window.api.config.write('editor', {...settings})` + `emit('apply', settings)`（父组件未消费） | 映射写盘 + 自动保存副作用 + `INIT_SETTING` 广播；对话框保持打开 |
| 确定 | 先执行「应用」，再 `emit('close')` | 保存并关闭 |
| 右上角 × | 同「取消」的关闭路径（`handleClose → emit('close')`），不回滚内存值 | 关闭；下次打开会重新 `loadSettings()` 回填，因此不会保留未保存修改 |

> 旧文档中的「重置默认」按钮、`dialog-editor-setting-apply/ok/cancel/reset` 信号均**不存在**。

## 9. IPC 与通道

| 通道 | 方向/模式 | 用途 |
| --- | --- | --- |
| `IPC.EDITOR.GET_SETTING` = `baize:editor:get-setting` | 渲染 → 主（invoke） | 编辑器挂载时读取当前 `editorSetting`（sender 校验） |
| `IPC.EDITOR.INIT_SETTING` = `baize:editor:init-setting` | 主 → 渲染（send） | 启动 + 保存后下发完整 `EditorSetting` |
| `IPC.EDITOR.UPDATE_OPTIONS` = `baize:editor:update-options` | 主 → 渲染（send） | 视图菜单的行号/空白字符开关（`lineNumbers` / `renderWhitespace`） |
| `IPC.CONFIG.READ` = `baize:config:read` | 渲染 → 主（invoke） | 对话框打开时读 `editor`（反算）/ `system`（自动保存） |
| `IPC.CONFIG.WRITE` = `baize:config:write` | 渲染 → 主（invoke） | 对话框保存写 `editor` |
| `IPC.DIALOG.OPEN_VUE_DIALOG` = `baize:dialog:open-vue` | 主 → 渲染（send） | 打开编辑器设置等 Vue 对话框的通用通道 |
| `IPC.DIALOG.AUTO_SAVE_CHANGED` = `baize:setting:auto-save-changed` | 渲染 → 主（invoke） | 自动保存开关/间隔变更通道：系统设置对话框使用；编辑器设置对话框的自动保存字段经 `config:write('editor')` 间接写入系统设置 |
| `IPC.EDITOR.SYSTEM_SETTING_UPDATE` = `baize:setting:updated` | 主 → 渲染（send) | 系统设置变更广播（本对话框保存自动保存字段后触发） |

> 历史通道 `baize-notes:init-editor-setting`、`baize-notes:editor-setting-updated`、`EDITOR.SETTING_UPDATED` 均已不存在（死通道清理）。

## 10. 与其它设置/开关的边界

| 设置 | 归属 | 与本对话框关系 |
| --- | --- | --- |
| 自动保存（开关 + 间隔） | 系统设置（`systemSetting`） | 本对话框的 2 个自动保存字段**写入系统设置**，与「系统设置 → 文件设置」共用同一真源 |
| 行号 / 空白字符开关 | 视图菜单（`EDITOR.UPDATE_OPTIONS`） | 运行期临时切换，不写 `editorSetting`；下次 `INIT_SETTING` 后会回到真源值（需人工确认这是否符合预期） |
| 字体族、界面字号 | 系统设置（`fontFamily`/`fontSize`，全局 CSS） | 与编辑器 `fontFamily` 独立；本对话框只有 Monaco `fontSize`/`lineHeight` |
| Monaco 主题 | 主题设置（`theme` 配置 + `LOAD_MONACO_THEME`） | 见 [Monaco Editor 全量配置](monaco-editor全量配置.md) |
| 快速链接、主题、系统设置 | 其余 Vue 对话框 | 见 [菜单配置详细文档](菜单配置详细文档.md) 7.6 |

## 11. 已知限制与后续

| 类别 | 内容 |
| --- | --- |
| 未实现（UI 已标注） | 实时预览、预览延迟、代码块高亮、链接高亮、最大文件大小、渲染延迟、实验性功能（7 项） |
| 无重置入口 | 主进程有 `resetEditorSetting()`，但无 UI/IPC 调用方；如需要请新增「恢复默认」按钮并走配置写入 |
| 映射覆盖有限 | 对话框只映射 7 个 Monaco 选项；`editorSetting` 其余约 190 个选项仅能通过默认值/其它代码路径调整（无 UI） |
| 字段形状差异 | 对话框字段是历史私有形状（`showLineNumbers`/`enableFolding`/`enableAutoComplete`），与 Monaco 选项不同名，靠映射层换算；新增字段需同步两处映射（正/反算） |
| 行号开关易被覆盖 | 视图菜单的运行期开关在下次 `INIT_SETTING` 后被真源值覆盖（见第 10 章） |
| i18n | 对话框文案在 `src/shared/i18n/messages/*/dialogRenderer.ts` 的 `editorSetting` 段（中英齐全） |
