## 1. 产品概述

### 1.1 产品简介

白泽笔记是一款基于 Electron 和 Vue 3 构建的跨平台桌面 Markdown 编辑器，旨在为用户提供强大、灵活的文档编辑和管理体验。产品名称来源于中国古代神话中的神兽"白泽"，寓意智慧与知识的汇聚。

### 1.2 产品定位

- **目标用户**：开发者、技术写作者、学生、研究人员
- **核心价值**：提供专业的 Markdown 编辑体验，支持丰富的图表绘制和文档管理功能
- **竞争优势**：集成 Monaco 编辑器、预览渲染本地化（零主进程渲染往返）、多主题体系、内置 38 个插件工具、中英双语

## 3. 技术规格

### 3.1 系统架构

#### 3.1.1 进程与分层

| 进程 | 目录 | 职责 |
| --- | --- | --- |
| 主进程 | `src/main` | 窗口创建与生命周期、文件/配置读写、菜单动作分发、IPC 处理、PlantUML 本地渲染、自动更新 |
| 预加载 | `src/preload` | `index.ts`（主窗口，暴露 `window.electron` / `window.api`）、`dialog.ts`（对话框，暴露 `window.electronAPI`，send 白名单 2 个通道） |
| 渲染进程 | `src/renderer` | Vue 应用：欢迎页、主界面、菜单栏、状态栏、编辑器、预览、资源管理器、插件工具、Vue 对话框 |
| 共享层 | `src/shared` | IPC 通道唯一真源、跨进程类型、i18n 词典、常量 |

#### 3.1.2 关键架构约束

- **preload 单文件约束**：主窗口与对话框均 `sandbox: true`，preload 必须打包为单文件——`electron.vite.config.ts` 的 preload 配置必须保持 `isolatedEntries: true` + `externalizeDeps: false`，否则共享 chunk 的 `require("./chunks/...")` 在 sandbox preload 中失败，`contextBridge` 不注入、渲染层所有按钮失效。
- **IPC 唯一真源**：`src/shared/ipc-channels.ts` 定义 **91 个通道 / 17 个常量组**，命名 `baize:<domain>:<name>`（domain 白名单 18 个，当前实际使用 17 个）；业务代码禁止写字面量。
- **事件总线**：渲染层 `src/renderer/src/common/event-bus/`（**24 个事件**）负责组件间通信，不跨进程。
- **预览链路**：Markdown 预/后渲染全部在渲染进程本地完成（`preview-local-render.ts` + `preview-markdown-it.ts` + `preview-chapters.ts`），无 `PRE_RENDER`/`POST_RENDER` 主进程 IPC；仅 PlantUML 图保留 1 个渲染 IPC。
- **配置单真源**：渲染层经 `window.api.config.read/write` 读写；`config-manager.ts` 的 `STORE_BACKED_CONFIGS` 将 `system`/`theme`/`editor`/`quick-links`（及 `backup` 命令）路由到 electron-store 模块，其余（`recent-folders`/`show-welcome`）为裸 JSON。
- **启动行为**：启动**始终显示欢迎页**（2026-11-15 产品决策），主进程在后台恢复上次目录/文件；用户点击最近文件夹或打开文件后进入主界面（`show-welcome === false` 配置可直进主界面）。

#### 3.1.3 安全规格

| 措施 | 实现 |
| --- | --- |
| 进程隔离 | 所有窗口 `contextIsolation: true`、`nodeIntegration: false`、`sandbox: true` |
| 路径守卫（Path Guard） | `security.ts` 的 `isPathAllowed` / `assertSafePath` / `registerTrustedPath`；工作区根、用户对话框选择路径、临时目录为受信范围 |
| 发送方校验 | `ipc-security.ts` 的 `withSenderCheck`，非受信主窗口/对话框发送的 IPC 丢弃 |
| 配置校验 | `config-schema.ts` 白名单配置名 + 逐字段校验（字体、字号、语言等） |
| 导航边界 | 主窗口 `will-navigate` / `will-redirect` 仅放行 dev server 与本地 renderer；`setWindowOpenHandler` 一律 deny |
| 协议白名单 | `shell.openExternal` 统一经 `openExternalSafely()`，仅 http/https |
| 内容消毒 | Markdown 预览经 DOMPurify 消毒后 `v-html`；HTML 查看器 iframe 不执行脚本 |
| 隐私 | 远程图片默认不加载（系统设置 `allowRemoteImages` 开关）；PlantUML 远程外发在 `session` 层阻断 |
| 更新安全 | 更新源强制 https；开发环境外禁用 F12 DevTools |
| 加密 | GCM 认证加密打通（返回/校验 authTag） |

## 5. 约束条件

### 5.1 技术约束

- 必须基于 Electron 框架，主进程/预加载/渲染进程三层分离
- 必须使用 TypeScript 开发，`noImplicitAny: true`
- 必须保持 preload 产物单文件（sandbox 硬性要求）
- 必须支持 Windows（当前发布平台）；macOS / Linux 打包配置保留
