## 1. 项目概述

### 1.1 项目基本信息

| 项目属性 | 值 |
|---------|-----|
| **项目名称** | 白泽笔记 (BaiZe Notes) |
| **版本** | 1.1.5-beta |
| **项目类型** | Electron桌面应用程序 - Markdown编辑器 |
| **开发语言** | TypeScript + Vue 3 |
| **作者** | hemy08 (zhaojunwei008@yeah.net) |
| **仓库** | https://github.com/hemy08/BaiZeNotesByVue.git |
| **许可证** | MIT |
| **支持平台** | Windows、macOS、Linux |

### 1.2 项目简介

**白泽笔记** 是一款基于 Electron + Vue 3 + TypeScript 构建的现代化 Markdown 桌面编辑器。项目以"白泽"神兽命名，寓意智慧与知识管理。

这是一个具有丰富编辑功能、主题系统和插件工具集的专业级Markdown编辑器，集成了Monaco编辑器、支持多种图表语法、拥有丰富的模板系统。

### 1.3 项目定位

- **目标用户**: 开发者、技术写作者、学生、研究人员
- **核心价值**: 提供专业的Markdown编辑体验，支持丰富的图表绘制和文档管理功能
- **竞争优势**: 集成Monaco编辑器、支持多种图表语法、丰富的模板系统

### 1.4 核心特性

- ✅ **强大的编辑器**: 基于 Monaco Editor，支持实时预览、语法高亮、自动补全
- ✅ **丰富的主题**: 20种应用主题 + 55种Monaco编辑器主题
- ✅ **多格式支持**: 支持7种格式导入、6种格式导出
- ✅ **图表渲染**: Mermaid和PlantUML，支持40+种图表类型
- ✅ **数学公式**: KaTeX数学公式渲染
- ✅ **实用工具**: 43个插件工具，涵盖加密、转换、格式化等
- ✅ **模板系统**: 丰富的Mermaid、PlantUML和写作模板
- ✅ **编辑器设置**: 59个配置项，13个分类，完善的持久化机制
- ✅ **自动更新**: 支持应用自动更新
- ✅ **多语言**: 支持中英文界面

### 7.4 配置持久化

**存储方式**:
- 使用 **electron-store** 进行本地持久化存储
- 配置文件位置：`%APPDATA%/baize-notes/config.json`
- 存储键名：`editorSetting`

**相关函数**:
```typescript
// 获取编辑器设置
function getEditorSetting(): EditorSetting

function saveEditorSetting(setting: EditorSetting): void

// 获取默认设置
function getDefaultEditorSetting(): EditorSetting
```

| 信号 | 说明 |

| `dialog-editor-setting-reset` | 重置配置 |

| 应用 | 保存配置，保持对话框打开 | `dialog-editor-setting-apply` |
| 确定 | 保存配置，关闭对话框 | `dialog-editor-setting-ok` |

## 9. 数据流与状态管理

### 9.1 状态管理架构

**Vuex Store 结构**:
```
store/
├── index.ts          # Store入口
├── modules/
│   ├── editor.ts     # 编辑器状态
│   ├── file.ts       # 文件状态
│   ├── theme.ts      # 主题状态
│   └── ui.ts         # UI状态
```

### 9.2 主要数据流

**文件打开流程**:
```
用户点击打开
    ↓
渲染进程: IPC调用
    ↓
主进程: 读取文件
    ↓
主进程: 返回文件内容
    ↓
渲染进程: 更新编辑器
    ↓
Vuex: 更新文件状态
```

**主题切换流程**:
```
用户选择主题
    ↓
渲染进程: IPC调用
    ↓
主进程: 更新主题配置
    ↓
主进程: 生成CSS变量
    ↓
主进程: 广播更新
    ↓
所有窗口: 应用新主题
```

**编辑器配置更新流程**:
```
用户修改配置
    ↓
渲染进程: 发送IPC信号
    ↓
主进程: 保存配置（electron-store）
    ↓
主进程: 广播配置更新
    ↓
渲染进程: 应用新配置
    ↓
Monaco编辑器: 更新显示
```
