#### 3.1.1 配置系统 (`config/`)

| `quick-link-config.ts` | 快速链接管理 | ~60 行 |

**配置持久化策略：**
- 使用 `electron-store` 封装为 `baize-store.ts`，内部集成 LRU 缓存（max 50 个文件）
- 配置文件存储在 `~/.baizenotes/config/` 目录
- 通过 `config-manager.ts` 提供统一的 CRUD 接口
- IPC 通道暴露给渲染进程

#### 3.1.2 IPC 通信 (`ipc/`)

| 文件 | 职责 |
|---|---|
| `handlers.ts` | 核心 IPC 处理器（窗口控制、文件操作、主题切换、编码检测等）|
| `menu_handle.ts` | 菜单命令分发器，25,190 行，是项目最大 TypeScript 文件 |
| `menu_context.ts` | 右键菜单定义（工具、链接、编码选择）|
| `ipc-listener-manager.ts` | IPC 监听器生命周期管理，带清理机制 |

**IPC 通道清单：**
- 窗口控制：`minimize` / `maximize` / `close` / `isMaximized`
- 文件操作：`open-file` / `save-file` / `read-all-file` / `write-file` / `delete-file` / `rename-file` / `get-folder-tree`
- 编码：`auto-detect-encoding` / `convert-encoding-with-bom`
- 主题：`get-theme-styles` / `baize:theme:apply`
- 菜单：`baize:menu:action`（统一分发到 `menu_handle.ts`）
- 对话框：各对话框专用 IPC 通道
- 版本：`get-app-version`

- 基于 Vue 3 `reactive` API

- 分离持久化状态和运行时状态，避免不必要的磁盘写入

## 4. 数据流分析

### 4.1 文件打开流程

```
用户操作 → MenuBar / ResourceManager
    ↓
IPC: 'open-file' → main process
    ↓
读取文件 (fs-extra) + 编码检测 (jschardet)
    ↓
IPC 返回文件内容 + 编码信息
    ↓
Monaco Editor 设置内容 + 语言模式
    ↓
EventBus 通知预览组件更新
    ↓
MarkdownPreviewComponent 解析并渲染
```

### 4.2 主题切换流程

```
用户操作 → ThemeSettingDialog
    ↓
写入配置 (electron-store)
    ↓
IPC: 'get-theme-styles' → main process
    ↓
主进程读取 theme-config.ts 中对应主题的 ThemeStyles
    ↓
IPC 返回 CSS 变量
    ↓
渲染进程更新 document.documentElement.style
    ↓
EventBus: 'theme-changed' → 所有组件响应
```

### 4.3 菜单动作分发

```
用户点击菜单 → MenuBar.vue
    ↓
IPC: 'baize:menu:action' → main process
    ↓
menu_handle.ts (25,190 行) 根据 action 分发
    ├── 文件操作 → file-utils/
    ├── 编辑操作 → IPC 回渲染进程
    ├── 格式操作 → IPC 回编辑器
    ├── 视图操作 → 窗口管理
    ├── 工具操作 → 打开对应对话框
    └── 帮助操作 → 打开帮助对话框
```

## 5. 性能分析

### 5.1 已实施的优化措施

| 优化项 | 措施 | 效果 |
|---|---|---|
| 大文件加载 | 分块读取 + LRU 缓存 | 速度提升 50%+ |
| 内存管理 | Monaco Editor 实例池 + 复用 | 内存减少 40% |
| Mermaid 渲染 | 并行渲染 + 渲染缓存 + 按需渲染 | 速度提升 3 倍 |
| EventBus | 自动清理 + 泄漏检测 | 修复内存泄漏 |
| 状态管理 | 持久/运行时状态分离 | 减少磁盘写入 |

### 5.2 潜在瓶颈

| 位置 | 问题 | 建议 |
|---|---|---|
| `menu_handle.ts` (25,190 行) | 单一文件过大，职责过多 | 按模块拆分为多个 handler |
| `hemy-editor.ts` (20,379 行) | 编辑器核心逻辑过于集中 | 拆分到独立模块 |
| `hemy-editor-quick-access.ts` (20,642 行) | 快速访问逻辑庞大 | 拆分数据与视图 |
| `theme-config.ts` (17,638 行) | 主题定义全部在内存中 | 按需加载主题 |
| `editor-setting.ts` (15,393 行) | 编辑器配置项巨大 | 分层配置定义 |

- **构建工具**：electron-vite
- **打包工具**：electron-builder 24.13.3
- **入口**：`out/main/index.js`（编译后）
- **开发模式**：`ELECTRON_RENDERER_URL` 环境变量指向 Vite 开发服务器

### 6.2 构建脚本

```bash
npm run dev                # 开发模式（Vite HMR + Electron）
npm run build              # 编译 + 构建目录
npm run build:win:nsis     # Windows NSIS 安装包
npm run build:win:portable # Windows 便携版
npm run build:win:all      # NSIS + 便携版一起
npm run build:mac          # macOS
npm run build:linux        # Linux (AppImage + snap + deb)
```

### 6.3 打包特性

| 平台 | 包类型 | 特性 |
|---|---|---|
| Windows | NSIS | 自定义安装路径、桌面快捷方式、请求管理员权限 |
| Windows | Portable | 免安装独立 exe |
| macOS | dmg | 摄像头/麦克风/文档授权 |
| Linux | AppImage/snap/deb | 通用 Linux 分发 |

### 6.4 更新机制

- 使用 `electron-updater`（版本 6.1.8）
- 发布配置：generic provider
- 更新服务器：`https://example.com/auto-updates`
- 开发环境使用 `dev-app-update.yml`

## 8. 代码质量分析

### 8.1 优势

1. **类型安全**：全项目 TypeScript，完善的类型定义（`global-types.d.ts`, `index.d.ts`）
2. **模块化设计**：主进程/预加载/渲染进程职责清晰分离
3. **组件化**：89 个 Vue 组件按功能合理分组
4. **内存安全**：EventBus 自动清理 + IPC 监听器生命周期管理
5. **错误恢复**：自动保存 + 崩溃恢复 + 文件状态持久化
6. **配置集中管理**：所有配置通过 config-manager 统一读写

### 8.2 可改进点

| 问题 | 严重程度 | 建议 |
|---|---|---|
| `menu_handle.ts` 25,190 行 | 高 | 按文件/编辑/视图/工具/帮助拆分 |
| `hemy-editor.ts` 20,379 行 | 高 | 拆分为多个关注点分离的模块 |
| 对话框分散在 main/ 和 renderer/ 两处 | 中 | 统一到渲染进程，主进程只做原生桥接 |
| 测试覆盖率低 | 中 | 补全单元测试和集成测试 |
| 主题配置全部硬编码在内存 | 低 | 改为 JSON 按需加载 |

## 9. 安全性分析

| 方面 | 当前做法 | 评估 |
|---|---|---|
| 进程隔离 | `contextIsolation: false`（需注意） | 建议启用 |
| 预加载桥接 | contextBridge 暴露有限 API | 合理 |
| 文件操作 | 主进程处理，渲染进程通过 IPC | 安全 |
| 加密 | crypto-js + node-forge，本地执行 | 合理 |
| 自动更新 | electron-updater | 安全 |
| Node 集成 | `nodeIntegration: true` | 需注意风险 |

## 11. 总结

白泽笔记是一个功能全面的 Markdown 桌面编辑器，具有以下特征：

- **规模大**：50 万+ 行代码，176+ 源文件，89 个 Vue 组件
- **功能丰富**：涵盖编辑、预览、导入导出、加密、转换、网络工具等
- **架构清晰**：三进程 Electron 架构，模块化组织
- **性能已优化**：大文件加载快 50%，内存少 40%，Mermaid 快 3 倍
- **主题完善**：23 种应用主题 + 55 种编辑器主题
- **主要技术债务**：几个关键 TypeScript 文件体积过大，需拆分重构
