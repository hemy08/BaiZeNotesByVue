# 文件导出功能说明

## 功能概述

白泽笔记支持将 Markdown 内容导出为多种文件格式，方便用户分享和发布文档。

## 支持的导出格式

### 1. Word 文档 (.docx)

**导出方式**: 文件 → 导出到文件 → 导出为 Word

**转换说明**:
- 使用 `officegen` 库生成 Word 文档
- 支持标题、段落等基本格式
- 标题会转换为相应的 Word 标题样式
- 普通文本转换为 Word 段落

**示例**:
```
Markdown 内容:
# 标题1
这是一段文字。

导出为 Word:
- 标题1（24号字体，加粗）
- 这是一段文字。（普通段落）
```

### 2. JSON 文件 (.json)

**导出方式**: 文件 → 导出到文件 → 导出为 JSON

**转换说明**:
- 将 Markdown 内容包装为 JSON 对象
- 包含元数据信息（导出时间、版本、类型）
- 使用 UTF-8 编码保存

**示例**:
```json
{
  "content": "# 标题\n\n这是一段文字。",
  "metadata": {
    "exportedAt": "2026-03-29T08:00:00.000Z",
    "version": "1.0.2",
    "type": "markdown"
  }
}
```

### 3. XML 文件 (.xml)

**导出方式**: 文件 → 导出到文件 → 导出为 XML

**转换说明**:
- 将 Markdown 内容包装为 XML 文档
- 使用 CDATA 包裹内容，避免特殊字符问题
- 包含元数据信息

**示例**:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<document>
  <metadata>
    <exportedAt>2026-03-29T08:00:00.000Z</exportedAt>
    <version>1.0.2</version>
    <type>markdown</type>
  </metadata>
  <content><![CDATA[# 标题

这是一段文字。]]></content>
</document>
```

### 4. YAML 文件 (.yaml, .yml)

**导出方式**: 文件 → 导出到文件 → 导出为 YAML

**转换说明**:
- 将 Markdown 内容包装为 YAML 格式
- 使用多行字符串语法
- 包含元数据信息

**示例**:
```yaml
content: |
  # 标题

  这是一段文字。
metadata:
  exportedAt: 2026-03-29T08:00:00.000Z
  version: 1.0.2
  type: markdown
```

### 5. HTML 文件 (.html, .htm)

**导出方式**: 文件 → 导出到文件 → 导出为 HTML

**转换说明**:
- 使用 `markdown-it` 将 Markdown 转换为 HTML
- 生成完整的 HTML 文档（包含 head、body）
- 内置 CSS 样式，确保良好的显示效果
- 支持响应式布局

**示例**:
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>白泽笔记导出</title>
  <style>
    /* 内置样式 */
    body {
      font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Microsoft YaHei", sans-serif;
      line-height: 1.6;
      max-width: 800px;
      margin: 0 auto;
      padding: 20px;
      color: #333;
    }
    /* ... 更多样式 */
  </style>
</head>
<body>
  <h1>标题</h1>
  <p>这是一段文字。</p>
</body>
</html>
```

### 6. PDF 文件 (.pdf)

**导出方式**: 文件 → 导出到文件 → 导出为 PDF

**转换说明**:
- 使用 `markdown-it` 将 Markdown 转换为 HTML
- 使用 Electron 的 `printToPDF` 功能生成 PDF
- A4 纸张大小
- 包含样式，确保良好的打印效果

**特性**:
- 支持中文显示
- 自动分页
- 保留格式和样式

## 使用方法

### 通过菜单导出

1. 在编辑器中编辑 Markdown 内容
2. 点击菜单栏的"文件"菜单
3. 选择"导出到文件"
4. 选择要导出的文件格式（如"导出为 Word"）
5. 在文件保存对话框中选择保存位置和文件名
6. 点击"保存"完成导出

### 导出流程

```
编辑器内容 → 选择导出格式 → 文件保存对话框 → 转换处理 → 保存文件 → 显示成功提示
```


### 依赖库

- **officegen**: 生成 Office 文档（Word、Excel、PPT）
- **markdown-it**: Markdown 解析和渲染
- **Electron**: PDF 生成（printToPDF）

## 导出格式对比

| 格式 | 扩展名 | 优点 | 缺点 | 适用场景 |
|------|--------|------|------|---------|
| Word | .docx | 兼容性好，可编辑 | 格式可能丢失 | 办公文档、协作编辑 |
| JSON | .json | 结构化数据，易解析 | 不适合直接阅读 | 数据交换、程序处理 |
| XML | .xml | 结构化数据，标准格式 | 不适合直接阅读 | 数据交换、系统集成 |
| YAML | .yaml | 易读易写，结构清晰 | 需要解析器 | 配置文件、数据序列化 |
| HTML | .html | 可直接浏览，样式丰富 | 需要浏览器 | 网页发布、在线阅读 |
| PDF | .pdf | 格式固定，跨平台 | 不可编辑 | 打印、分享、存档 |

## 注意事项

1. **内容检查**: 导出前请确保编辑器中有内容，否则会提示"当前没有内容可导出"
2. **格式保留**: 不同导出格式对 Markdown 语法的支持程度不同，部分格式可能丢失
3. **文件编码**: 所有导出文件使用 UTF-8 编码，确保中文正确显示
4. **大文件**: 导出大文件可能需要较长时间，请耐心等待
5. **PDF 生成**: PDF 生成需要创建临时窗口，可能会短暂显示窗口图标

## 导出格式详细说明

### Word 导出

**支持的 Markdown 语法**:
- 标题（#、##、###）
- 段落
- 粗体、斜体（有限支持）

**不支持的语法**:
- 代码块
- 表格
- 图片
- 链接

**建议**: Word 导出功能较为基础，适合简单的文本文档。复杂格式建议使用 HTML 或 PDF 导出。

### HTML 导出

**支持的 Markdown 语法**:
- 标题
- 段落
- 列表（有序、无序）
- 代码块
- 表格
- 链接
- 图片
- 引用

**特性**:
- 响应式布局
- 内置样式
- 可自定义样式（修改导出的 HTML 文件）

### PDF 导出

**支持的 Markdown 语法**:
- 与 HTML 导出相同

**特性**:
- A4 纸张大小
- 自动分页
- 保留样式
- 适合打印

## 常见问题

### Q1: 导出的 Word 文档格式不正确怎么办？

A: Word 导出功能较为基础，建议：
1. 使用 HTML 导出，然后用 Word 打开 HTML 文件
2. 使用 PDF 导出，然后用 Word 打开 PDF 文件
3. 手动调整 Word 文档格式

### Q2: 导出的 PDF 中文显示乱码怎么办？

A: PDF 导出使用系统字体，建议：
1. 确保系统安装了中文字体
2. 检查导出的 HTML 文件是否正确显示中文
3. 尝试使用其他 PDF 阅读器打开

### Q3: 导出的 HTML 文件样式可以自定义吗？

A: 可以，建议：
1. 导出 HTML 文件
2. 用文本编辑器打开 HTML 文件
3. 修改 `<style>` 标签中的 CSS 样式
4. 保存文件

### Q4: 导出大文件时卡住怎么办？

A: 大文件导出需要较长时间，建议：
1. 等待导出完成
2. 如果长时间无响应，可以尝试重启应用
3. 考虑将大文件拆分为多个小文件

### Q5: 支持导出为 Markdown 文件吗？

A: 当前编辑器本身就是 Markdown 文件，可以直接保存为 .md 文件，无需导出功能。
