## 1. 项目概述

### 1.1 产品简介

白泽笔记（BaiZe Notes）是一款基于 Electron + Vue 3 + TypeScript 构建的跨平台 Markdown 桌面编辑器。产品名称来源于中国古代神话中的神兽"白泽"，寓意智慧与知识的汇聚。

### 1.2 产品定位

- **目标用户**: 开发者、技术写作者、学生、研究人员
- **核心价值**: 提供专业级 Markdown 编辑体验，集成 Monaco Editor，支持多种图表语法、丰富的模板系统和强大的插件工具
- **竞争优势**: Monaco 编辑器集成、23种应用主题、55种编辑器主题、40+插件工具、自定义渲染管线

### 1.3 版本信息

| 项目 | 值 |
|------|-----|
| 当前版本 | v1.1.5-beta |
| 发布日期 | 2026-05-01 |
| 支持平台 | Windows (NSIS + Portable)、macOS (DMG)、Linux (AppImage + deb + snap) |
| 作者 | hemy08 |

## 2. 技术架构

### 2.1 三层架构

白泽笔记采用 Electron 标准的三层架构：

```
+------------------------------------------+
|           主进程 (Main Process)           |
|  Electron API + Node.js + 文件系统       |
|  窗口管理 / IPC处理 / 主题 / 渲染管线     |
+------------------------------------------+
|         预加载脚本 (Preload)              |
|         contextBridge API 暴露            |
+------------------------------------------+
|         渲染进程 (Renderer)               |
|  Vue 3 + Monaco Editor + markdown-it     |
|  UI组件 / EventBus / 插件工具             |
+------------------------------------------+
```

## 4. 核心功能详解

### 4.1 Markdown编辑器

- **底层引擎**: Monaco Editor 0.55.0，提供语法高亮、代码折叠、多光标、查找替换等
- **自定义语言**: 注册 PlantUML 和 Mermaid 语言的语法高亮
- **编辑模式**: 编辑模式(F9)、预览模式(F10)、编辑+预览模式(F11)
- **可拖拽分隔条**: 编辑区和预览区宽度自由调节
- **大文件优化**: 1MB阈值，自动禁用minimap等，加载提速50%+

### 4.2 Markdown预览渲染

- **解析引擎**: markdown-it 14.1.0
- **插件链**: markdown-it-highlightjs / markdown-it-plantuml / markdown-it-emoji
- **自定义渲染管线** (HemyRender):
  1. Material Admonitions 渲染
  2. Tabbed Set 渲染
  3. 图片URL转换 (相对路径转绝对路径)
  4. 文件URL转换 (本地文件链接转换)
  5. KaTeX 数学公式渲染 (行内和块级)
- **防抖优化**: 150ms延迟

### 4.3 资源管理器

- 文件树浏览 (递归组件 FileTreeNode.vue)
- Markdown TOC大纲导航
- 右键上下文菜单 (新建/重命名/删除/导入导出/在资源管理器打开)
- 文件编码检测 (jschardet) 和转换 (iconv-lite)

### 4.4 自定义标题栏

- 无边框窗口设计 (frame: false)
- 标题栏拖动移动窗口
- 双击标题栏最大化/还原
- 8方向窗口大小调整 (上/下/左/右/四角)
- 最小窗口尺寸限制 (800x600)


## 9. 状态管理与持久化

### 9.1 多层次状态管理架构

| 层次 | 技术 | 作用域 | 用途 |
|------|------|--------|------|
| Vuex | Vuex 4 | 渲染进程 | 组件间状态共享 (header等) |
| EventBus | 自定义EventBus | 渲染进程 | 组件间事件通信，支持组件级追踪和自动清理 |
| electron-store | electron-store | 主进程持久化 | 配置文件持久化存储 |
| IPC | ipcMain/ipcRenderer | 跨进程 | 主进程与渲染进程通信 |

### 9.2 持久化存储

所有配置文件统一存储在 ~/.baizenotes/config/ 目录下：

| Store | 文件 | 用途 |
|-------|------|------|
| BaiZeStore | baize-config.json | 应用状态 + LRU文件缓存(50个) |
| EditorSetting | editor-setting.json | Monaco编辑器70+配置项 |
| ThemeConfig | theme-config.json | 主题配置 |
| SystemSetting | system-setting.json | 系统设置(语言/菜单/自动保存/字体等) |
| QuickLinkConfig | quick-link-config.json | 快速链接配置 |
| FileState | file-state.json | 文件打开状态 + 最近文件列表 |

### 9.3 Store工厂函数

统一创建Store实例，确保所有配置文件都存储在用户目录下：

```typescript
export function createStore<T>(name: string, defaults: T): Store<T> {
    const configDir = path.join(getUserDataPath(), "config")
    return new Store<T>({ name, cwd: configDir, defaults })
}
```

## 10. 内存泄漏防护体系

### 10.1 IPCListenerManager (单例)

- 统一管理所有IPC监听器，按通道和组件双向索引
- register() / unregister() / cleanupComponent() / cleanupChannel() / cleanupAll()
- 统计信息: getStats() / printStats()

### 10.2 WindowManager (单例)

- 统一管理所有 BrowserWindow 实例
- 窗口关闭时自动清理关联的IPC监听器
- 支持单例模式窗口 (singleton)
- createWindow() / closeByType() / closeAll() / getStats()

### 10.3 EventBus (渲染进程)

- 组件级追踪: $on() 支持 componentId 选项
- 自动清理: $offComponent() 按组件批量清理
- 内存泄漏检测: $checkLeaks() (事件>50监听器或组件>20监听器时警告)
- 最大监听器限制: MAX_LISTENERS_PER_EVENT = 200

### 10.4 BaiZeStore LRU缓存

- 文件内容缓存: Map<string, FileContent>
- 最大缓存: 50个文件
- LRU淘汰: 缓存满时删除最旧项
- 缓存统计: getCacheStats() 返回 {size, capacity}
