1. 技术方案

采用轻量自研 i18n（不引入 vue-i18n），原因：

  • 主进程（HTML 对话框模板）与渲染层（Vue 组件）需要共用同一份词典；
  • 现有组件测试直接 mount 组件，vue-i18n 需插件注入会大面积改测试；
  • 仅中/英两种语言，t() + 词典足够，且零新增依赖。
层模块说明
共享词典src/shared/i18n/messages/{zh-CN,en-US}/*.ts13 个命名空间、中英各 1606+ 词条，键结构完全一致
翻译入口src/shared/i18n/index.tstranslate(key, locale, params)、resolveLocale（兼容 zh-cn/zh_CN/en 等历史写法）、缺失键回落中文再回落键名
渲染层src/renderer/src/common/i18n.ts响应式 currentLocale + t()：模板调用即建立依赖，切换语言即时重渲染
主进程src/main/utils/i18n.ts同步 tMain()：语言取自系统设置，写入后 refreshMainLocale() 失效缓存
语言设置系统设置 language（zh-CN / en-US）SystemSettingDialog 新增语言下拉；保存经既有 config:write('system') → 主进程刷新 + 广播 → 渲染层自动切换

3. 关键设计

3.1 中文逐字一致（默认界面零变化）

  • 所有中文词典值与原硬编码文案逐字一致（含全角/半角标点差异）；
  • 默认中文界面与改造前完全一致；
  • 既有 176 个测试文件的所有中文断言无需修改即通过。

3.2 响应式切换

  • 菜单/常量类数据改为存 labelKey，在渲染处 t(item.labelKey) 输出 → 切换语言即时生效；
  • StatusBar 由 DOM 直改改为 ref + computed → 语言切换即时刷新；
  • 主进程 HTML 对话框在打开时求值 tMain() → 重新打开即为新语言。

3.3 语言归一化

resolveLocale() 兼容历史值：zh-cn/zh_CN/zh → zh-CN，en-us/EN → en-US，空值/非法值回落 zh-CN；主进程语言下拉已对齐为仅 zh-CN/en-US 两项。

6. 使用方式

  1. 打开「系统设置 → 通用设置 → 语言」，选择「中文（简体）」或「English」；
  2. 保存后界面立即切换（渲染层实时）；主进程 HTML 对话框在下次打开时使用新语言；
  3. 默认语言为中文；语言设置持久化于系统设置（systemSetting.json）。
