MEM-01 字体选择对话框监听器无效移除与残留 P1 ✅ 已修复

位置：src/main/dialogs/ShowFontSelectDialog.ts:66-70,110-114 ｜ 影响：每次打开泄漏 1-2 个监听器，闭包持有主窗口 ｜ 工作量：0.5 小时

移除 cancel 监听器时传入"新的空匿名函数"，与注册时的引用不同，移除无效；cancel 监听器本身即为匿名函数，永远无法按引用移除；用户点系统标题栏关闭按钮（而非对话框内按钮）时 exitFontSelectDialog 不执行，insert 监听器同样残留。

ipcMain.removeListener('dialog-user-font-select-btn-cancel', () => {})   // ❌ 无效移除
win.close()
// L110-114
ipcMain.on('dialog-user-font-select-btn-insert', processCustomFontDialogApply)
ipcMain.on('dialog-user-font-select-btn-cancel', () => { exitFontSelectDialog() })

修复建议：cancel 改为命名函数；清理逻辑挂到窗口 closed 事件；或改用 ipcListenerManager.register。

MEM-04 导入选项对话框 ipcMain.once 残留与多重触发 P1 ✅ 已修复

位置：src/main/dialogs/ShowImportOptionDialog.ts:62（HTML 关闭按钮 :283、:320） ｜ 影响：多次取消后残留 once 一次性全触发，重复 onConfirm 且持有大 content ｜ 工作量：0.5 小时

// HTML L283 <button class="close-btn" onclick="window.close()">x</button>
// HTML L320 <button class="btn btn-cancel" onclick="window.close()">取消</button>

MEM-05 文件内容缓存"只写不读" P2 ✅ 已修复

位置：src/main/utils/baize-store.ts:26-27,84-96；写入方 file-operations.ts:61,345,386 ｜ 影响：最多 50 个大文件内容纯驻留且无收益 ｜ 工作量：1 小时

setFileContent 在保存/自动保存/打开文件三处被调用，而 grep 全项目确认 getFileContent 没有任何调用方。缓存上限 50 只按文件数计算（近似 FIFO），单个文件可达 5MB+，可能纯驻留数十至数百 MB。

// baize-store.ts:84-96
setFileContent(path: string, content: string): void {
    if (this.fileCache.size >= this.MAX_CACHE_SIZE) {
        const oldestKey = this.fileCache.keys().next().value!
        this.fileCache.delete(oldestKey)
    }
    this.fileCache.set(path, { content, timestamp: Date.now(), size: content.length })
}

修复建议：删除缓存及 3 处写入；或接入读取路径并增加字节预算淘汰。
