2. 阶段 0：安全止血（fix-security）

  • S-1 P0 XSS 链（FUN-01/CMP-15/ARC-01）：
    • 预览链路加 DOMPurify 消毒（MarkdownPreviewComponent.vue，svg/mathMl profile，保留 mermaid/katex 渲染）；
    • src/renderer/index.html 加 CSP meta（default-src 'self' + 必要放宽）；
    • navi-tab-open-exe 加 sender 校验与路径白名单（utils.ts:105-107）；
    • src/preload/dialog.ts 的 send 改通道白名单；
    • config:read/write/delete/list 加 configName 校验（config-manager.ts，防路径逃逸 ARC-17）。
  • S-2 依赖安全（CMP-16/18/31、PF-04）：
    • 升级：electron ≥43.8.1、markdown-it ≥15.0.3、vue ≥3.5.42、monaco-editor 0.57.0；
    • mermaid 仅当代码调用兼容时才升 12.3（否则留 11.x 最新并记录残留 low）；
    • 移除死依赖（先 grep 验证零引用）：commonmark、encoding、detect-file-encoding-and-language、markdown-it-anchor、monaco-themes、plantuml-cli、vuex、node-forge（若有引用则升级 ^1.4.3）；
    • app-builder-bin 移到 devDependencies；.npmrc 清理废弃键、audit=false 改 true；npm install + audit 复测。
  • S-3 mermaid CDN 本地化（ARC-10）：OpenMermaidRenderFrame.ts 内联 node_modules 的 mermaid.min.js。
  • S-4 死分支清理：src/preload/index.ts 非 contextIsolated 死分支。

  • D-8 对话框 IPC 监听器清理（MEM-01～04）：命名函数 + closed 兜底；

4. 阶段 2：质量门禁（fix-quality）

  • Q-1 ESLint flat config（eslint.config.js）+ 删除 .eslintrc.cjs/.eslintignore；lint 脚本去 --fix（package.json 由 fix-security 统一改）；
