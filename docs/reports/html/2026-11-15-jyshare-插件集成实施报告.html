版本归属 1.3.52026-11-15

一、任务与结论摘要

  • 输入：菜鸟工具镜像站 www.jyshare.com 前端工具"常用工具"区（约 60 个在线工具）。
  • 方法：两个调研子代理逐页抓取工具源码提炼算法（报告见 jyshare 前端工具源码调研，原始 HTML/JS 归档于 out/jyshare-src/）；三个实现子代理并行实现；主代理统一整合注册与发布链路。
  • 成果：新增 18 个插件组件 / 19 个菜单项，插件工具总数 19 → 37；全部零第三方依赖、纯前端离线可用；新增 154 个单元测试用例。

三、接入链路

  • 组件：PluginTools/{Codec,Convert,TextTools,FormatTools,MiscTools,NetWork}/，按需懒加载（PF-6 模式），不占首屏。
  • 注册表：plugin-tools-const.ts 为唯一真源（37 项）；菜单映射经 menu-consts.ts + menu-config.ts，空组由 pruneEmptySubmenus 自动隐藏，数据补齐后自动恢复展示。
  • i18n：菜单词条走 menu.plugins.*，工具内部文案走 toolsConvert.*，中英叶子键严格对称（词典门禁测试守护）。
  • 一致性守护：plugin_tools_const.test.ts 校验总数/分类计数/id 命名规范/注册表↔菜单双向一致。

四、移植过程中的关键改进（相对原站）

项原站实现本项目实现
CMYK → RGBelse-if 链缺陷（仅第一个 >0 分量 /100）四分量统一 /100，往返测试容差 ±1 通过

文本比对Mergely（LGPL，约 500KB）自写行级 LCS（DP），大文本保护

计算器eval 拼接运算双栈 + 显式 switch 运算

五、未集成项与理由（Roadmap）

  • SQL 格式化（701）：原站为服务端 HMAC 接口实现，离线需引入 sql-formatter 前端库。
  • 中国日历（5672）：农历核心 lunar-javascript 约 344KB，节假日依赖逐年外部数据。
  • JS/CSS/HTML 压缩（47/51/52）：压缩需 terser 类库；解压即格式化，体积收益有限。
  • JS 混淆（6939）、HTML 转 JS（846）：依赖 javascript-obfuscator / js-beautifier 大体积库。
  • 拼音多音字消歧：已集成首读音版；词级消歧需引入 pinyin-pro。
  • 在线类工具（IP 查询 5445、汇率 7939、AI 解析 9064/9231、图片压缩 6232、加水印 6502、取色器 6210/6214、涂鸦 6900、地图 9024/9026）：依赖在线服务或超出桌面工具收益范围。
