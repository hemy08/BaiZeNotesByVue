3. 阶段 0 安全止血（fix-security，11 项）

  • P0 XSS 链闭环（FUN-01/CMP-15/ARC-01）：预览 v-html 前 DOMPurify 消毒（svg/mathMl profile）；index.html 加 CSP meta；navi-tab-open-exe 三重校验（sender 白名单 + 绝对路径存在性 + 受信目录确认框）；dialog.ts 预加载 send 改 18 通道白名单。
  • 路径逃逸（ARC-17）：config 读写 configName 强制 ^[A-Za-z0-9_-]+$ 白名单。
  • mermaid CDN 本地化（ARC-10）：隐藏窗口内联 node_modules mermaid.min.js（5.5MB），去除远程 CDN。
  • 依赖治理（CMP-16/18/31、PF-04）：electron 43.8.10、markdown-it 15.0.3、vue 3.5.45、monaco-editor 0.57.0、mermaid 12.3.0；移除 8 个死依赖；app-builder-bin 移 devDeps；7 组 overrides；.npmrc 清理。
  • 死分支清理（S-4）：preload 非 contextIsolated 死分支删除。

4. 阶段 1 数据安全（fix-data，17 项）

  • 统一 dirty 标记（FUN-05/PF-06）：保存快照 + 惰性比较，仅脏写盘、空内容也保存、失败状态栏提示。
  • 自动保存开关修复（FUN-04）：按 payload 启停并重启定时器（间隔≥5s）。
  • 关闭/退出落盘（FUN-03）：close 拦截 → flush 契约（2 秒超时兜底）→ 脏则保存 → 关闭。
  • 编码体系（FUN-02）：BOM 检测 + jschardet + iconv-lite，按原编码写回（GBK 往返测试通过）。
  • 重载保护（FUN-06）：脏状态跳过重载并提示。
  • 配置损坏容错（FUN-11）：createConfigStoreSafely 备份重建；顺带清理 13 处 @ts-ignore。
  • 其余：新建同名不覆盖（FUN-17）、导入失败不插伪内容（FUN-13）、4 个对话框监听器 closed 兜底（MEM-01～04）、只写不读缓存移除（MEM-05）、防抖按配置名分离（MEM-15）、cleanupApp 停止自动保存（MEM-11）。

5. 阶段 2 质量门禁（fix-quality + fix-lint）

  • ESLint flat config（CQ-01）：eslint.config.js 落地，删除 .eslintrc.cjs/.eslintignore；规则收敛回旧策略语义；lint 脚本去 --fix。
  • @ts-ignore 消除（CQ-02）：editor-setting 6 处、encrypt_decrypt 2 处、theme/system/quick-link 13 处等 20+ 处清零。
  • 错误处理（CQ-05）：加密函数不再把 Error 塞返回值。
  • 死代码（CQ-03/04）：default-configs.ts 删除。
  • lint 收官：fix-lint 修复 71 个存量 error（未用变量 23、require 混用 17、空函数 11、Versions.vue 真实模板 bug 等），门禁 0 error。

  • 滚动监听移除（PF-13）。
  • mermaid 缓存（PF-09）：内容 hash 50 条 LRU，SVG id 重写防冲突。
