白泽笔记全量检查 — 总体优化项报告

📦 归档报告（原文：00-总体优化项报告.md）——历史快照，数字与结论以报告时点为准；当前口径见 报告总索引 与 IPC通信矩阵。

  • 项目：白泽笔记（BaiZe Notes）v1.2.2（Electron 43 + Vue 3.5.41 + TypeScript 6.0.2）
  • 检查日期：2026-11-14
  • 检查方式：6 个维度并行子智能体全量深读源码 + 工具链实测（typecheck / vitest / ESLint / npm audit），每个发现均附真实 文件:行号 证据，3 项 P0 已由根代理复核确认
  • 范围：src（40,065 行代码）、tests、build、resources、docs、配置与发布链路
  • 修复状态：已修复 105 / 127（🟡 部分修复 22 · ⏭ 未处理 0；2026-11-15 晚全量复扫口径：6 维度静态核实 + 工具链实测，明细见下表）

1. 执行摘要

健康面（2026-11-15 复扫实测）：三工程 strict 类型检查 0 错误（noImplicitAny 已开启）；ESLint 0 error / 0 warning；生产依赖 audit 0 漏洞；130 个测试文件 2080 用例（2 例断言不同步失败，待修）；webPreferences 安全基线正确；主进程 ipcMain 直连注册清零、监听台账全部纳管。

问题面：共发现 127 项问题（P0×3、P1×37、P2×52、P3×35），其中 3 项 P0 实质是同一条攻击链的三个切面——恶意 Markdown 触发预览 XSS → 调用未校验的 IPC → 主进程执行任意本地程序。四大跨维度系统性根因：

  1. 质量门禁失效：ESLint 升级到 9 后配置从不兼容，lint 从未跑通，@ts-ignore/死代码/死依赖因此无人拦截；
  2. 链路断裂：大量"事件有发送无监听、菜单有入口无实现、配置有双轨无同步"（约 24 个插件菜单点击即空白、自动更新是占位符）；
  3. 数据安全：无统一脏标记，自动保存/关闭/重载/模板全文替换存在多条静默覆盖用户文件的路径；
  4. 全量搬运：击键同步、预览渲染、目录刷新三条核心链路全部"整篇文档全量传输 + 全量重算"，安装包高达 233MB。

5. 跨维度系统性根因

5.1 质量门禁失效 → 系统性欠账（CQ-01、CQ-08、CMP-23、CMP-31、CMP-32）

ESLint 自升级到 9 后从未成功运行（且脚本自带 --fix，修复即引爆批量改写）；noUnusedLocals=false；导致 28 处 @ts-ignore、55 处 any、6 个零引用依赖（commonmark、encoding、node-forge 等）无人拦截。

5.2 链路断裂 → 死功能群（FUN-09、FUN-19、CMP-26、ARC-07、ARC-09、FUN-10、CMP-21、FUN-26、ARC-15）

事件有发送无监听（编码切换、折叠、大纲、查找替换）、菜单有入口无实现（检查更新、约 24 个插件菜单项点击空白）、27 个组件未挂载、快捷键多数仅展示未绑定、自动更新全程占位符。

5.3 数据安全：无脏标记贯穿（FUN-02～07、FUN-11、MEM-04）

打开一律按 UTF-8 读（GBK 乱码后被自动保存回写覆盖原文件）；关闭窗口不保存也无确认；自动保存开关反向失效；磁盘重载静默覆盖未保存修改；"写作模板"全文替换后自动保存覆盖原文件；配置文件损坏则启动崩溃。

5.4 性能：三条核心链路全量搬运（PF-01～05、PF-10）

击键整篇文档经 IPC 同步主进程（无防抖增量）；预览四跳 IPC + 双次全量解析 + KaTeX 主进程同步渲染；目录树任何增删改全量递归重扫 + 整树 JSON 过 IPC；Monaco 无 worker 走主线程回退；安装包 233MB（app-builder-bin 误入生产依赖、plantuml-cli 死重）。

5.5 架构：双轨无真源（ARC-02～09、ARC-11～13、CQ-11、FUN-04、FUN-20、MEM-15）

配置三目录双系统（electron-store vs 裸 JSON）；菜单双注册表 id 错位；IPC 通道常量（168 行）零引用全链路硬编码；主↔渲染双向 import 边界泄漏；IPC 注册随 createWindow 重复执行；共享类型 2/3 零引用。项目处于"主进程旧架构 → 渲染层新架构"迁移中途。
