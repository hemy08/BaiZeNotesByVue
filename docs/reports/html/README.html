使用说明

  • 整体导航：每页顶部固定横条——🏠 报告首页 + 01-检查与扫描 / 02-修复与实施 / 03-专项治理 三个分类下拉（含全部 19 份报告）+ 右侧当前页名称；当前页在导航中自动高亮，所属分类自动展开。
  • 打开方式：浏览器直接打开本目录 README.html 体验最完整（下拉高亮等脚本生效）；在应用内「HTML 查看器」打开时，查看器会注入 <base> 修正相对链接，导航链接可正常点击（查看器沙箱不执行脚本，高亮/自动收起不生效）。
  • 页内目录：每份报告页面自带固定悬浮目录（h2/h3 两级锚点），点击跳转对应章节。
  • Markdown 版：见 ../md/（与 HTML 版同名分类一一对应，顶部同样带报告导航行）。
  • 报告总索引：见 ../README.md（含合并明细与一致性核对结论）。
  • 维护约定：报告正文为历史快照不随状态回写；新增报告先生成 Markdown 到 ../md/（顶部带 report-nav 导航标记），再执行 node build/generate-report-wiki.js 批量生成 HTML（自动注入顶部导航并剥离 Markdown 导航标记），同步更新本页与 _sidebar.md。
