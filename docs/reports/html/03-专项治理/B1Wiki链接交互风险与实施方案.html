B1 Wiki 链接交互风险与实施方案

性质：风险分析与实施方案；1.5.1 方案 A 已实施。 项目基线：v1.5.1（开发中）；当前门禁实测 312 测试文件 / 5,741 用例，IPC 100 通道 / 17 组，preload 白名单 send 66 + receive 28。 评估对象：[[target]]、[[target|alias]]、[[target#heading]] 的编辑器内点击跳转、歧义选择与缺失页创建。 结论先行：当前 B1 已具备“解析 + 反链 + 悬浮预览”的只读能力；1.5.1 方案 A 已补齐 Ctrl/Cmd+Click 跳转、歧义候选与缺失页受控创建，形成“点击—跳转—创建”的最小闭环。

1. 现状与事实

1.1 已具备

能力 当前实现
Wiki 链接解析 主进程工作区索引解析目标、别名、heading，生成 WorkspaceIndexLink
反向链接 知识库对话框展示当前文件反链，点击来源行定位
悬浮预览 E10 HoverProvider 展示目标标题、相对路径、摘要、反链数量
文件打开 既有 OPEN_SELECT_FILE → USER_SELECT_FILE → 编辑器打开链路
行跳转 编辑器已有跳转行/定位能力，可复用于 heading 跳转

1.2 未具备

  • 编辑器内 [[...]] 不可点击；
  • 目标缺失时不能创建页面；
  • 目标歧义时没有候选选择；
  • #heading 只展示不跳转；
  • 反链/悬浮预览的索引快照没有“交互动作”入口。

1.3 当前索引边界

项 当前口径
索引扩展名 .md / .markdown / .txt
单文件上限 2 MiB
文件数上限 20,000
目录深度上限 32
符号链接/忽略目录 跳过
索引缓存 主进程内存快照，5s TTL + 显式 force 刷新
渲染层权限 只能经 IPC 查询，不能直接读盘

2. 风险矩阵

ID 风险 触发条件 影响 等级 处置
B1-R1 链接“看得见、点不动” 用户点击 [[...]] 知识库工作流断裂，用户回到手动搜索 中 点击跳转
B1-R2 缺失页无入口 链接指向不存在文件 无法从写作现场补齐知识网络 中 缺失页创建
B1-R3 歧义目标误打开 多个同名/同标题文件 打开错误文件，用户困惑 中 候选选择
B1-R4 创建路径逃逸 target 含 ../、绝对路径、设备名 越过工作区写文件/覆盖敏感文件 高 主进程 Path Guard + 文件名白名单
B1-R5 已有文件被覆盖 目标已存在但按“创建”处理 数据丢失 高 先查存在，已存在只打开不覆盖
B1-R6 索引过期导致误判 文件刚被创建/删除 跳到错误路径或重复创建 中 创建/跳转前强制刷新或二次 stat
B1-R7 点击与文本选择冲突 普通单击/多光标操作 误跳转，打断编辑 中 仅 Ctrl/Cmd+Click；悬停手型提示
B1-R8 heading 跳转错位 同名 heading、重复标题 跳到错误位置 低 取第一个匹配并在状态栏提示
B1-R9 编码/大小写差异 Windows 大小写不敏感、非 UTF-8 文件 目标命中不稳定 低 沿用索引归一化 + 编码探测口径

3. 方案对比

方案 内容 优点 缺点 结论
A. 只做点击跳转 Ctrl/Cmd+Click 打开已存在目标 改动小、风险低 缺失链接仍无解 可作为第一阶段
B. 点击 + 缺失页创建 在 A 上补创建确认与受控写盘 闭环完整、价值最高 需新增主进程创建通道/契约 推荐
C. 点击 + 创建 + 块引用/图谱 扩展为完整知识网络 能力强 内核改造大、风险高 本版本不做

4. 推荐方案

4.1 交互设计

  • 普通悬停：沿用 E10 悬浮卡片，不改变文本；
  • Ctrl/Cmd + Click：打开目标文件；
  • 普通点击：保持编辑/选词，不跳转；
  • 目标缺失：弹确认框，显示“将创建：相对路径.md”，用户确认后创建并打开；
  • 目标歧义：弹候选列表（标题 + 相对路径 + 修改时间），用户选择后打开；
  • 目标含 #heading：打开后跳转到第一个同名 heading，状态栏提示“已跳转到标题”；
  • 打开后返回：复用现有文件切换/最近文件能力，不新增自定义历史栈。

4.2 解析与打开链路

Monaco 鼠标事件 / 命令
  → 读取当前位置链接（复用 Wiki 链接纯解析）
  → 查询工作区索引（必要时 force 刷新）
  → 唯一命中 → 请求主进程打开文件 + 行跳转
  → 缺失 → 应用内确认 → 主进程受控创建 → 打开
  → 歧义 → 候选框 → 打开选中项
  • 解析优先使用快照中同 raw + 同位置的链接记录；
  • 行号漂移时回退“同 raw 唯一”；
  • 不使用浏览器 window.open，不渲染层直接读文件；
  • 打开文件复用既有 IPC，不新增“任意路径打开”后门。

4.3 缺失页创建

创建前校验（渲染层只做展示，主进程最终裁决）

  1. target 去空格、去 #heading、去 |alias；
  2. 拒绝空目标、绝对路径、盘符、UNC、设备命名空间；
  3. 拒绝 .. 越界与目录段含非法字符；
  4. 相对路径基于当前工作区根，不基于任意绝对路径；
  5. 目标已存在 → 转为打开，不覆盖；
  6. 目标目录不存在 → 默认拒绝，或按产品决策“只创建文件、不递归建目录”。

主进程职责

  • 重新执行 Path Guard、isSafeFileName、工作区根校验；
  • 只允许新建 .md 文件；
  • 创建时使用 wx/排他写入，防并发覆盖；
  • 失败返回结构化错误，不抛裸异常；
  • 成功后使索引缓存失效并广播刷新。

可选增强

  • 创建时写入 front matter title（来自链接显示名）；
  • 创建后保持原文件与链接不变，避免“创建动作顺带改正文”；
  • 若 target 是根目录下的简单名称，可直接创建；含子目录时先提示“目录需已存在”。

4.4 heading 跳转

  • 索引已记录链接 heading 文本；打开文件后按标题文本匹配；
  • 标题匹配使用“去掉 Markdown 标记后的纯文本 + 大小写不敏感”；
  • 多个同名标题取第一个，并在状态栏提示；
  • 找不到 heading 时只打开文件，不报错。

5. 安全与架构约束

约束 落地要求
渲染层无 FS 只发结构化请求；所有路径由主进程再次校验
IPC 链路 常量 → shared/types/ipc.ts 契约 → 生成 preload 白名单 → handler + sender 校验
Path Guard 严格 isPathAllowed/realpath containment；拒绝符号链接逃逸
文件名 isSafeFileName；拒绝 Windows 保留名、尾随点/空格、控制字符、ADS 冒号
创建并发 排他写入；已存在转打开，不覆盖
例外配置 不新增 KNOWN_EXCEPTIONS、CSP、allowlist 例外
日志 记录动作结果与失败原因；不记录笔记正文
索引 创建/跳转前刷新策略明确；失败降级为“手动打开”，不阻塞编辑

6. 分阶段实施

阶段 内容 交付 预估
P0 点击跳转（唯一命中/歧义/缺失三态提示） Ctrl/Cmd+Click、候选框、缺失提示 1～1.5 人日
P1 缺失页创建 确认框、主进程受控创建、索引刷新 1～1.5 人日
P2 heading 跳转 + 交互打磨 跳转定位、状态栏提示、快捷键/命令面板入口 0.5～1 人日
P3 回归与体验 点击/键盘/多光标/大文件/编码/E2E 0.5～1 人日

合计：约 3～4 人日。

7. 测试与验收

7.1 单元测试

  • 链接定位：行首/行尾/多链接/别名/heading/空目标；
  • 解析：唯一、缺失、歧义、大小写、路径归一化；
  • 创建路径：../、绝对路径、盘符、UNC、保留名、已存在、并发；
  • heading：唯一/重复/不存在；
  • 索引缓存：TTL、force 刷新、索引构建失败降级。

7.2 集成/E2E

  • 编辑器内 Ctrl/Cmd+Click 打开唯一目标；
  • 缺失链接确认创建后文件出现且自动打开；
  • 目标已存在时不覆盖，只打开；
  • 歧义候选选择正确；
  • 非法 target 不产生文件、不弹系统错误；
  • 中文/空格/大小写路径可用。

7.3 验收指标

  • 点击到打开 P95 < 500ms（索引已热）；
  • 缺失页创建失败率 0，且失败有可见提示；
  • 不新增 IPC 白名单/例外；Path Guard 测试全绿；
  • 既有 312 文件 / 5,741 用例门禁不退化。

8. 不做什么（本阶段）

  • 不做块引用、嵌入、图谱；
  • 不做自动为缺失链接批量创建页面；
  • 不改变现有 Markdown 链接点击行为；
  • 不引入浏览器式自定义历史/前进后退；
  • 不在渲染层实现文件写入。

9. 待决策

  1. 点击触发方式：仅 Ctrl/Cmd+Click，还是提供“单击打开”设置项？
  2. 缺失页创建是否允许自动建子目录？
  3. 创建时是否自动写入 front matter title？
  4. 歧义候选默认按“最近修改”还是“路径最短”排序？

未决策前建议默认：Ctrl/Cmd+Click、不自动建目录、不自动写 front matter、按最近修改排序。

10. 1.5.1 实施结果（2026-11-22）

已按方案 A 落地：

  • 编辑器内 Ctrl/Cmd+Click 唯一命中打开；普通点击保持编辑；
  • 歧义：对话框展示候选（标题 + 相对路径），选择后打开；
  • 缺失：确认框展示将创建的相对路径；确认后复用既有 FILE.CREATE_FILE_FOLDER 主进程受控创建；
  • 目录不存在时拒绝并提示，不递归建目录；目标已存在只打开不覆盖；非法 target 拒绝；
  • 新增纯逻辑/对话框/宿主测试 40 个，覆盖链接定位、三态、路径安全、创建参数与失败降级。

已知限制：

  • heading 暂不跳转到具体标题，只打开目标文件；
  • 空目录不在索引快照内，无法判定为“目录已存在”；
  • 创建成功后索引刷新依赖主进程缓存策略，若快照滞后可手动刷新；
  • 不新增 IPC 通道，不改变现有 Markdown 链接行为。
