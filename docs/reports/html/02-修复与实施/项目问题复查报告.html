3. 最高优先级问题（P0/P1）

3.1 P0：主窗口导航劫持链（N-01，已复核）

  • 证据：主窗口无 will-navigate（src/main/index.ts 仅 PlantUML 隐藏窗有拦截）；setWindowOpenHandler 直接 shell.openExternal(details.url) 无协议白名单（index.ts:131-132）；preload 暴露全量 electronAPI（preload/index.ts:50）；渲染层无 dragover/drop 拦截 → 把远程链接/HTML 拖入窗口即可完成导航，远程页面获得全部 IPC 能力（文件读写删、OPEN_EXE 等）。
  • 影响：远程内容 → 本机文件系统/程序执行的 RCE 跳板。
  • 修复：主窗口加 will-navigate 白名单 + 拖拽拦截 + openExternal 协议白名单（仅 http/https）；preload 收敛为显式白名单 API；IPC 增加 sender 校验。

3.2 P0：online-web-page 远程页持 preload 且无拦截（C-08，未修）

  • 证据：OpenOnlineWebPages.ts:6-13 以 loadURL(远程URL) 创建持有 dialog preload 的窗口，无导航/打开拦截；shell.openExternal 无协议校验。
  • 影响：远程页可向主进程发 17 类白名单消息、监听全局广播、拉起本地程序/协议。
  • 修复：同 13 号计划 A1（导航拦截 + 去 preload + 协议白名单）。

3.3 P0：自动保存开关静默失效（P0-2.2，未修）

  • 证据：渲染层 SystemSettingDialog.vue:300 用 send；主进程 handlers.ts:231-248 用 registerHandleOnce（仅 invoke 生效）。
  • 影响：Vue 设置中切换"自动保存"不触发主进程定时器启停。
  • 修复：统一 invoke + handle。

3.4 P1：目录大纲（TOC）存储型 XSS（CQ-07 / N-03，已复核）

  • 证据：hemy-editor-render.ts::ParserMarkdownChapters 从 markdown-it text token 取标题文本（实体已解码）；ResourceManager.vue:40 以 v-html="getIndentedText(item)" 渲染且无转义 → 形如 # &lt;img onerror=alert(1)&gt; 的标题会执行 JS，绕过预览区 DOMPurify。
  • 修复：TOC 文本统一 escapeHtml（或 textContent 渲染 + 缩进用 CSS/span 拼接），补回归测试。
