2. 各子智能体交付明细

r3-ipc（CQ-05 / CQ-10 / PF-11 / ARC-21）

  • sendSync → invoke：4 个调用点与 4 个主进程通道改为 ipcMain.handle + await invoke，算法与输出格式零改动；
  • 异步 IPC 兜底（CQ-05）：async on 回调补 try/catch 13 处（错误经状态栏中文提示），handle 补日志 9 处，修正 2 处浮动 Promise；
  • 校验：src 全目录 ipcRenderer.sendSync 零残留（含防回归测试）。

r3-dialogs（CQ-06 / PF-07）

  • jsdom 惰性化：14 个文件移除顶层静态导入，统一 getter 按需加载；
  • 样板治理：14 个对话框迁移 loadDialogHtml；新增 4 个公共函数；4 处主题 CSS 收敛；15/15 对话框渲染 HTML 逐字节一致。

r3-watch（PF-05 / PF-10）

  • 目录增量监听：fs.watch recursive 单例 + 500ms 事件合并 + 自写抑制 1.5s + 未变跳过 IPC + 生命周期清理 + 多级降级；与脏状态保护兼容；
  • 大文件流式读取：5MB 阈值、64KB 分块 + 流式解码（多字节不截断）、编码探测复用；分块 IPC 留后续。

r3-plantuml（PF-08）

  • 本地离线渲染：新增 plantuml-local.ts（隐藏窗口加载 resources/plantuml teaVM 环境），窗口复用 + 串行队列 + sha1 LRU 50 + 10s/20s 超时 + 崩溃重建 + 退出销毁；
  • 渲染层：围栏与裸 @startuml 两类图块本地 SVG，12s 兜底 + hash 缓存 + 同批去重；远程插件仅作降级；DOMPurify 不变；
  • 接线：通道常量收敛 IPC.RENDER.PLANTUML_LOCAL、whenReady 注册、cleanupApp 销毁（根代理执行）。

r3-misc（ARC-15/19/22、ARC-16、FUN-10、CMP-07/21/25）

  • 死代码：window-manager printStats、menu-context 空模块、ipc/index 死 re-export 清理；open-plugin-tool 有发送方保留并注明；
  • 文档：架构文档 3 处 Vuex 矛盾表述同步；
  • Global 声明清理（188→149 行）+ saveFileInterval 魔法值删除；
  • 自动更新支持 resources/config/update.json 配置真实更新源（占位仍诚实提示）+ 示例与 14 个用例；
