FUN-01 预览渲染无 HTML 消毒，恶意 Markdown 可触发任意 IPC/启动本地程序 P0 ✅ 已修复

位置：MarkdownPreviewComponent.vue:32-39,5；hemy-editor-render.ts:152-154；preload/index.ts:48-51；utils.ts:105-107 ｜ 影响：打开恶意 .md 即可执行任意脚本并启动本地任意程序 ｜ 工作量：2-3 人日（含回归）

MarkdownIt 以 html: true 初始化且未挂任何消毒插件；PostMarkdownRender 对 HTML 原样返回；模板直接 v-html="renderedMarkdownContent"。渲染进程 webPreferences 虽为 nodeIntegration:false, contextIsolation:true, sandbox:true（main/index.ts:30-37，做得好），但 preload 通过 contextBridge.exposeInMainWorld('electron', electronAPI) 把 @electron-toolkit/preload 的完整 ipcRenderer（send/invoke/on）暴露给页面上下文。

修复建议：渲染管线末端接入 DOMPurify（生产依赖中已存在该库）；preload 只暴露白名单式窄 API（不暴露通用 ipcRenderer）；主进程对 navi-tab-open-exe / open-external-link / config:* 等渠道做调用来源与参数校验。

FUN-02 编码体系整体失效：乱码回写覆盖 + 编码菜单无监听 P1 ✅ 已修复

位置：file-operations.ts:381,344；auto-save.ts:27；menu_file.ts:6-12 ｜ 影响：非 UTF-8 文件乱码且静默损坏原文件（数据丢失）；编码切换功能是空壳 ｜ 工作量：2 人日

打开文件一律 fs.readFile(path,'utf8')，无编码探测（仅 CSV 导入做了 jschardet，import.ts:143-146）；GBK 文件打开即乱码。更严重的是自动保存不查脏标记，30 秒内把乱码内容以 UTF-8 回写，破坏原文件。而"重新用…编码打开 / 转为…编码"菜单（menu_config.ts:108-150）由主进程 send 'open-with-encoding'/'convert-to-encoding'，全渲染端没有任何 ipcRenderer.on 监听这两个频道（全库 grep 仅命中 menu_file.ts 与 ipc-channels.ts）——编码菜单全部无效。

menu_file.ts:7          mainWindow.webContents.send('open-with-encoding', encoding)  // 渲染端无监听

修复建议：打开时用 jschardet/iconv 探测编码并保留"当前编码"状态；自动保存前若编码与磁盘不一致则要求确认；在渲染端实现 open-with-encoding / convert-to-encoding 监听（主进程重读文件按指定编码解码并更新 appState 与编辑器）。

FUN-03 关闭窗口不保存、无未保存确认 P1 ✅ 已修复

位置：handlers.ts:31-33；main/index.ts:141-146；StatusBar.vue:96 ｜ 影响：60 秒自动保存窗口期内的修改静默丢失 ｜ 工作量：1 人日

标题栏关闭按钮发送 window-close → mainWindow.close()，主窗口无任何 close/before-quit 拦截保存逻辑；渲染端也未监听 beforeunload。未保存标记（isUnsaved）只用于状态栏红点展示，没有任何流程消费它。自动保存间隔默认 60 秒（system-setting.ts:17），最后修改后 60 秒内点关闭（或退出、或"重启应用"）修改静默丢失。

修复建议：mainWindow.on('close') 中先同步待保存内容并落盘（或弹未保存确认）；退出/重启前同样处理。

FUN-04 自动保存开关反向失效 + 设置双轨存储 P1 ✅ 已修复

位置：handlers.ts:148-150；SystemSettingDialog.vue:235-256；main/index.ts:88-90；system-setting.ts:10；config-manager.ts:39 ｜ 影响：打开自动保存实际是停掉它；间隔设置无效；设置与主进程行为脱节 ｜ 工作量：1 人日

FUN-06 磁盘重载/文件操作静默覆盖未保存修改 P1 ✅ 已修复

FUN-08 非法 ```math 代码块使整个预览停止更新 P1 ✅ 已修复
