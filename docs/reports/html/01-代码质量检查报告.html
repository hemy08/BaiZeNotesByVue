// out\tool-results\eslint.txt:22-23
Error: ESLint configuration in .eslintrc.cjs » @electron-toolkit/eslint-config is invalid:
  - Unexpected top-level property "languageOptions".

// package.json:12
"lint": "eslint . --ext .js,.jsx,.cjs,.mjs,.ts,.tsx,.cts,.mts,.vue --fix"

修复建议：新建 eslint.config.js（flat），用 @electron-toolkit/eslint-config（flat）+ @electron-toolkit/eslint-config-ts 的 configs.recommended + eslint-plugin-vue 的 flat/recommended + @vue/eslint-config-prettier 组装；把 .eslintignore 内容迁移为顶层 ignores 并删除该文件；lint 脚本去掉 --fix（另设 lint:fix），并在 CI 增加只读 eslint . 门禁。
