3. 最高优先级问题（P0/P1）

3.1 P0：主窗口导航劫持链（N-01，已复核）

  • 主窗口无 will-navigate（仅 PlantUML 隐藏窗有）；setWindowOpenHandler 直接 shell.openExternal(details.url) 无协议白名单（index.ts:131-132）；preload 暴露全量 electronAPI（preload/index.ts:50）；渲染层无 dragover/drop 拦截；
  • → 拖入远程链接/HTML 即可完成主窗口导航，远程页获得全部 IPC：任意文件读写删、OPEN_EXE 等 → 远程内容到本机程序执行链；
  • 修复：全窗口导航拦截 + 拖拽拦截 + openExternal 协议白名单（仅 http/https）+ preload 白名单化 + IPC sender 校验。

3.2 P0：online-web-page 远程页持 preload 无拦截（C-08，未修）

OpenOnlineWebPages.ts:6-13 远程 loadURL + dialog preload，无导航/打开拦截；远程页可向主进程发白名单消息、监听全局广播、拉起本地程序（插件打开方式切"本地对话框"时触发）。

3.3 P0：自动保存开关静默失效（P0-2.2，未修）

渲染层 SystemSettingDialog.vue:300 用 send，主进程 handlers.ts:231-248 用 registerHandleOnce（仅 invoke 生效）→ 开关不启停定时器。修复：统一 invoke + handle。

3.4 P1：目录大纲 TOC 存储型 XSS（CQ-07 / N-03，已复核）

  • ParserMarkdownChapters 从 markdown-it text token 取标题（实体已解码）→ MarkdownTOC.text；ResourceManager.vue:40 以 v-html="getIndentedText(item)" 渲染且无转义；
  • 形如 # &lt;img onerror=alert(1)&gt; 的标题会执行 JS，绕过预览区 DOMPurify；
  • 修复：TOC 文本统一 escapeHtml 或用 textContent 渲染，补回归测试。
