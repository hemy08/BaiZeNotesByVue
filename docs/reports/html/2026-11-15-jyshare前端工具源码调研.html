一、颜色转换类（6 个）

1. RGB ↔ HEX（/front-end/55/）

  • 核心算法：RGB→HEX：parseInt(v,10) → 上限 255 → v.toString(16) → 单字符补 0（padHex）→ 拼接加 # 并大写。HEX→RGB：去掉 #，仅接受长度 3/6/8，按 .{1,2} 分组后 parseInt(x,16)。输入框过滤非数字/非 HEX 字符。
  • 源码位置：内联 <script>（第 7 个 script，3529B）。依赖 jQuery、ClipboardJS、Pickr（外部库 static.jyshare.com/assets/libs/pickr/dist/pickr.min.js，仅用于取色器，转换逻辑不依赖它）。
  • 关键代码：
    const padHex = (char) => char.length === 1 ? '0' + char : char;
const rgbToHex = () => {
    const hexValues = $rgbInputs.map(function () {
        const value = parseInt(this.value, 10);
        return padHex((value > 255 ? 255 : value).toString(16));
    }).get();
    $hexInput.val('#' + hexValues.join('').toUpperCase());

// HEX→RGB：hex.match(/.{1,2}/g) 后 parseInt(v,16)

2~6. RGB/HEX/HSV/CMYK 互转（/front-end/868, 870, 873, 875, 877/）

  • 核心算法：五个页面共用外部 color.js 的 convertTo(from,to) 调度器（所有互转经 RGB 中转）：
    • hexTorgb：两位切片 parseInt(x,16)。
    • rgbToHex/toHex："0123456789ABCDEF".charAt(...) 手工表转换，Math.max(0,Math.min(n,255)) 夹取。
    • rgb2hsv：r/g/b 归一化；max/min/d；H 用三段公式后 h/=6 归一化到 0-1；S、V 亦 0-1；输出 toFixed(4)。
    • hsv2rgb：H 输入为 0-1（i=floor(h*6); f=h*6-i），S、V 0-1；六分扇区 switch；Math.floor(x*255)。
    • RgbToCmyk：黑点特判 (0,0,0)→[0,0,0,1]；否则 K=min(1-R/255,1-G/255,1-B/255)，C=(calcR-K)/(1-K) 等，输出 0-1 四位小数。
    • cmyk2rgb：存在缺陷——else if 链导致只有第一个 >0 的分量会被 /100（0-100 输入约定下结果错误）；公式 1-min(1, c*(1-k)+k) ×255。
  • 源码位置：外部 js https://www.jyshare.com/wp-content/themes/toolrunoob2/assets/js/color.js（132KB，含约 500 色名对照表）；页面内联 script 仅做 UI 绑定（868/870/873/875/877 的内联脚本各 265~405B，调用 convertTo）。
  • 关键代码：
    function rgb2hsv(r,g,b){
  hsv_red=r/255; hsv_green=g/255; hsv_blue=b/255;
  var max=Math.max(...), min=Math.min(...), d=max-min;
  hsv_s = max==0 ? 0 : d/max;  hsv_v = max;
  if(max==min) hsv_h=0;
  else { switch(max){ case hsv_red: hsv_h=(g-b)/d+(g<b?6:0); break;
          case hsv_green: hsv_h=(b-r)/d+2; break;
          case hsv_blue: hsv_h=(r-g)/d+4; break; } hsv_h/=6; }
  return (hsv_h.toFixed(4)+","+hsv_s.toFixed(4)+","+hsv_v.toFixed(4));
}
function RgbToCmyk(R,G,B){ if(R==0&&G==0&&B==0) return [0,0,0,1];
  var calcR=1-R/255, calcG=1-G/255, calcB=1-B/255;
  var K=Math.min(calcR,Math.min(calcG,calcB));
  return ((calcR-K)/(1-K)).toFixed(4)+","+((calcG-K)/(1-K)).toFixed(4)+","+

  • 关键代码：

  • 离线可实现性：纯前端零依赖。随机源为 Math.random（非密码学安全，可自行换 crypto.getRandomValues 增强）。

8. 随机数生成器（/front-end/6680/）

  • 核心算法：密码学安全随机 + 无偏拒绝采样：
    function randInt(min,max){
  var range=max-min+1,buf=new Uint32Array(1),
      limit=Math.floor(4294967296/range)*range,v;
  do{ crypto.getRandomValues(buf); v=buf[0]; }while(v>=limit);
  return min+(v%range);
}
    范围夹取 ±1e9；数量 1~100；不重复模式用 Set（上限 100 万次守卫）；80ms 定时器实现"滚动抽奖"；历史 10 条。
  • 源码位置：内联 script（5202B），原生 JS 无 jQuery 依赖。
  • 离线可实现性：纯前端零依赖；crypto.getRandomValues 在 Electron 渲染层可用。

9. 随机字符串生成器（/front-end/9111/）

  • 核心算法：四个字符集（小写/大写/数字/标点 !@#$%^&*()_+~|}{[]:;?><,./-=）按勾选**固定顺序轮询追加**，随机索引 Math.ceil(len*Math.random())-1`（该式有分布缺陷：索引 0 概率减半，最后一个字符概率翻倍）。批量生成用换行拼接。
  • 源码位置：内联 script（2661B），依赖 jQuery + ClipboardJS。
  • 离线可实现性：纯前端零依赖；建议用 Math.floor(Math.random()*len) 修正分布。

10. 随机颜色生成器（/front-end/9072/）

  • 核心算法：调用第三方库 randomColor（static.jyshare.com/assets/libs/randomColor.min.js，即 David Merfield 的 randomColor.js）。该库在 HSV 空间生成：按颜色名预设 hue 范围（red/orange/yellow/green/blue/purple/pink/monochrome），luminosity 决定 S/V 区间，支持 format=hex/rgb/rgba/hsl/hsla/hsvArray、alpha、seed（字符串哈希种子）。默认无 seed 用 Math.random。
  • 源码位置：外部库 + 内联调用脚本（2994B，jQuery）。
  • 关键代码：
    colorData = randomColor({alpha:..., format:..., luminosity:..., hue:..., count: numberOfColors});
  • 离线可实现性：需打包 randomColor.js（MIT，4.7KB），或自行实现 HSV→RGB 随机（算法简单，几十行）。

12. 存储单位换算（/front-end/9229/）

  • 源码位置：外部库 UnitOf.min.js（65KB）+ 内联调用脚本（1711B，jQuery），动态拼 from<Unit>/to<Unit> 方法名调用。

17. 在线计算器（/front-end/6904/）

  • 核心算法：双栈（操作数栈+运算符栈）+ 优先级表求值，非表达式字符串解析：

    • 二元运算：Math.pow 处理 ^/yroot；加减乘除取余及位运算用 eval(f+op+s)——但操作数仅来自按键拼装的数字字符串与受限运算符，无任意表达式注入（唯一 eval 面为数字+单个运算符+数字）；程序员型按进制 parseInt(x,16/8/2) 转十进制运算再转回。
    • 一元：sin/cos/tan/sinh/cosh/tanh/√/x²/1/x/n!/log10/10^x/π/±/~（~ 用 eval）。
    • 三种模式（标准/科学/程序员），结果显示 ≤13 位否则 toExponential(7)；科学型角度/弧度由页面切换。
  • 源码位置：内联 script（35067B），原生 JS 无依赖。
  • 关键代码：

18. 图片转 Base64（/front-end/59/）

  • 核心算法：不用 FileReader，用 file.arrayBuffer() → Uint8Array：
    • 编码：字节分块 24576 经 String.fromCharCode(...bytes.subarray) → btoa → data:<mime>;base64,。输出格式 raw/dataURL/HTML img/CSS 四选一。
    • 解码：校验 Base64 字符表/补位 → atob → 回验 btoa(binary)===text → Uint8Array → Blob → new Image() + URL.createObjectURL 解码 → 显示。
    • 魔数探测 probeImage（全部内联实现）：PNG(137 'PNG' + IHDR 宽高)、GIF87a/89a、JPEG(FFD8 段扫描 SOF0-15)、WebP(RIFF/WEBP 的 VP8X/VP8L/VP8)、BMP(BM, BITMAPCORE/INFOHEADER)、SVG(文本 < 开头)。SVG 消毒 cleanSVG：禁 DTD/实体、白名单标签/属性、移除 url() 引用与脚本节点。
    • 限制：20MB、16000px 单边、4000 万像素、SVG ≤1 万元素。导出下载用 canvas.toBlob（jpg 白底填充、质量 .92）。
  • 源码位置：内联 script（18834B），原生 JS 零第三方库。
