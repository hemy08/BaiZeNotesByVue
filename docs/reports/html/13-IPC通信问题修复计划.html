1. 修复原则与验收标准

  • 原则：安全/功能问题优先；行为变化最小化（不改线上通道字符串语义）；每项修复配回归测试；删除类改动先 grep 确认双端零引用。
  • 全局验收：typecheck 双绿、npm run test 全过、eslint 0 error、electron-vite build 通过；新增防回归测试（通道两端模式一致性、死通道零存在、preload 白名单覆盖）；按通信矩阵逐通道重扫输出"修复后矩阵"。

5. 风险与回滚

  • 删除死通道：先 grep 双端 + 动态拼接检查（IPC.X[${var}]），再删代码、最后删常量；单通道独立 commit 便于回滚；
  • C-08 移除远程窗口 preload：若远程页面依赖主题广播，改主进程代发；不影响本地功能；
  • C-05 删除 HTML 对话框：仅删除确认无入口的项；保留项不动；
  • C-09 preload 裁剪：改动面大，先出评估报告，经评审后再实施；未评审前保持现状（DOMPurify + CSP 已降低风险）。
