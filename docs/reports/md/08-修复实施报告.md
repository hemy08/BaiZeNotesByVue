## 3. 阶段 0 安全止血（fix-security，11 项）

- **P0 XSS 链闭环**（FUN-01/CMP-15/ARC-01，已复核）：预览 `v-html` 前 DOMPurify 消毒（svg/mathMl profile，保留 mermaid/KaTeX/高亮）；`index.html` 加 CSP meta；`navi-tab-open-exe` 三重校验（sender 白名单 + 绝对路径存在性 + 受信目录确认框）；`dialog.ts` 预加载 `send` 改 18 通道白名单。
- **路径逃逸**（ARC-17）：config 读写 configName 强制 `^[A-Za-z0-9_-]+$` 白名单。
- **mermaid CDN 本地化**（ARC-10）：隐藏窗口内联 `node_modules/mermaid/dist/mermaid.min.js`（5.5MB），去除远程 CDN 依赖。
- **依赖治理**（CMP-16/18/31、PF-04）：electron 43.8.10、markdown-it 15.0.3、vue 3.5.45、monaco-editor 0.57.0、mermaid 12.3.0（API 兼容已验证）；移除 commonmark、encoding、detect-file-encoding-and-language、markdown-it-anchor、monaco-themes、plantuml-cli、vuex、node-forge；app-builder-bin 移 devDeps；7 组 overrides 修复传递依赖；.npmrc 清理 9 个废弃键、audit 恢复启用。
- **死分支清理**（S-4）：preload 非 contextIsolated 死分支及 @ts-ignore 删除。

## 4. 阶段 1 数据安全（fix-data，17 项）

- **统一 dirty 标记**（FUN-05/PF-06）：app-state 保存快照 + 惰性比较，自动保存仅脏时写盘、空内容也保存、失败经状态栏提示。
- **自动保存开关修复**（FUN-04）：按 payload 启停并重启定时器（间隔≥5s），启动时尊重开关。
- **关闭/退出落盘**（FUN-03）：close/before-quit 拦截 → `editor:flush-content` 契约（渲染层取消防抖立即同步，2 秒超时兜底）→ 脏则保存 → 真正关闭。
- **编码体系**（FUN-02）：打开时 BOM 检测 + jschardet 探测 + iconv-lite 转码，记录编码并按原编码写回（UTF-8 无 BOM / GBK 往返测试通过）。
- **重载保护**（FUN-06）：磁盘重载前检查脏状态，脏则跳过并提示。
- **配置损坏容错**（FUN-11）：electron-store 统一 `createConfigStoreSafely`，损坏时备份 `.corrupt-时间戳` 重建；顺带清理 13 处 @ts-ignore。
- **其余**：新建同名文件不再静默覆盖（FUN-17）；导入失败不再插入 'convert failed' 伪内容（FUN-13）；4 个对话框 IPC 监听器命名函数 + closed 兜底（MEM-01～04）；只写不读的 50 项文件缓存移除（MEM-05）；importOption 关闭清空 + 按配置名分防抖定时器（MEM-06/15）；cleanupApp 停止自动保存（MEM-11）。

## 5. 阶段 2 质量门禁（fix-quality + fix-lint）

- **ESLint flat config**（CQ-01）：`eslint.config.js` 落地，删除 `.eslintrc.cjs`/`.eslintignore`；规则收敛回旧策略语义（`explicit-function-return-type` off；`no-explicit-any`、`vue/require-toggle-inside-transition` warn 待专项清理）；lint 脚本由 `--fix` 改为纯检查。
- **@ts-ignore 消除**（CQ-02）：editor-setting（6 处）、encrypt_decrypt（2 处 any）、theme-config/system-setting/quick-link-config（数据代理顺带 13 处）等 20+ 处清零。
- **错误处理**（CQ-05）：CryptoEncrypt/Decrypt 不再把 Error 塞入返回值，改抛错。
- **死代码**（CQ-03/04）：default-configs.ts 删除。
- **lint 收官**：fix-lint 修复 71 个存量 error（未用变量 23、require 混用 17、空函数 11、Versions.vue 真实模板 bug 等），门禁 0 error。

## 6. 阶段 4 性能（fix-perf，7 项）

- **击键同步防抖**（PF-01）：500ms 空闲防抖 + lastSyncedContent 去重，保存前 flush，卸载兜底同步。
- **滚动监听移除**（PF-13）：无订阅者的 window scroll 监听删除。
- **mermaid 缓存**（PF-09）：按内容 FNV-1a hash 缓存 50 条 LRU，命中时重写 SVG 内部 id 避免 DOM 冲突。
- **math 块降级**（FUN-08）：非法 math 块 try/catch 降级为源码显示，预览不再整体冻结。
- **logger 优化**（PF-12）：文件大小缓存，不再每条日志 statSync。
- **主题注册表惰性加载**（PF-15）：单主题按需读取，55 主题全量构建仅首次。
- **模板插入**（FUN-07）：写作模板改光标处插入，不再全文替换。

## 7. 阶段 3 架构收口（fix-arch，11 项）

- **IPC 注册一次性化**（ARC-06）：三个注册函数移出 createWindow，macOS activate 重建窗口不再重复注册。
- **菜单双注册表对齐**（ARC-07）：渲染层分支 id 对齐实际菜单 id，主进程树剔除死路径 handler；顺带修复编辑器设置对话框路由（ARC-08）。
- **主题广播修正**（FUN-20）：payload 改为 `{themeStyles, monacoTheme, separateEditorTheme}`，死 send 清理。
- **插件菜单治理**（ARC-09/CMP-26/FUN-19）：23 个无组件菜单项隐藏（保留数据），点击不再空白。
- **监听器管理修复**（MEM-08）：按引用清理，不再 split(':') 截断通道；menu_context 死代码全删（ARC-15）。
- **小修**：IPv4 子网数值比较（FUN-25）、编辑器默认值统一（FUN-28）、另存为标题（FUN-16）。
- **测试架构升级**（ARC-18 部分）：vitest 配置加 vue 插件与别名，新增 jsdom 组件测试（@vue/test-utils 真挂载），测试文件从 3 → 61、用例 21 → 1067。
