##### 1. JSON 格式化（/front-end/53/）

- **核心算法**：
  - 输入 → 自写**递归下降解析器 `strictParse`**（严格 JSON 校验）→ 内部 JS 对象 → 按模式输出。
  - 校验边界：去 BOM；UTF-8 字节数 > 2 MB 拒绝；嵌套深度 ≤ 80；节点数 ≤ 12000；对象字段名必须双引号；**重复 key 报错**；**尾随逗号报错**；数值经 `canonical()` 归一化比对，超出 `Number` 安全精度拒绝（提示改字符串）；报错带行列号。
  - 输出模式：格式化/压缩 = `JSON.stringify(data, null, spacing|undefined)`；树形 = jsoneditor 10.4.3 树编辑器（可改值回写）；XML = 自写 `jsonXML` 递归生成（非法 key 归入 `<entry key=…>`，数组项为 `<item>`，带 type 属性）；CSV = 自写 `jsonCSV`（先选"数据位置"路径，对象数组并集取列，RFC4180 双引号转义，**公式防护**：`=+-@` 开头单元格前缀 `'`，输出 `\r\n` + BOM）；YAML = js-yaml 4.1.1 `yaml.dump`（JSON_SCHEMA，保留类型）。

##### 2. JSON 解析（/front-end/7438/）

- **核心算法**：
  - 输入 → `lenientParse`（**宽松解析**：先 `JSON.parse`，失败后正则修复两处——去尾随逗号、给无引号 key 补引号，再 parse）→ `json2html` **递归生成可折叠树**（字符串 HTML 转义；http/ftp 链接化；对象/数组子节点可折叠；显示 `N items` 占位）→ 结果区渲染；同时 `countNodes` 统计节点数。格式化 = `JSON.stringify(parsed,null,2)`，压缩 = `JSON.stringify(parsed)`。
- **关键代码摘录**：

```js
function lenientParse(str) {
  try { return JSON.parse(str); } catch (_) {}
```

##### 3. JSON 转义/去除转义（/front-end/7683/）

- **核心算法**：纯字符串 `replace` 链。**转义**顺序：`\`→`\\` → `"`→`\"` → `/`→`\/` → `\b` → `\f` → `\n`→`\r\n` → `\t`（注意换行转成 `\r\n` 转义对而非 `\n`）；**去转义**逆序还原。注意去转义实现有缺陷：`replaceAll('\\\\"', /\\/)` 把正则对象当替换值（实际得到字符串 "/\/"），且 `\/` 被还原成空格而非 `/`，照实摘录。

##### 4. Base64 编码/解码（/front-end/693/）

- **核心算法**：自写 `Base64` 对象，**中文先 UTF-8 再编码、解码后 UTF-8 还原**。编码：`_utf8_encode`（按 charCodeAt 分 <128 / <2048 / 其余三档生成 1/2/3 字节 UTF-8）→ 每 3 字节切成 4 个 6 位 → 查表 `_keyStr`（`A-Za-z0-9+/=`，`=` 用于填充，余 1/2 字节时对应 64 号索引输出 `=`）→ 拼接。解码：先滤除非 Base64 字符 → 查表还原 6 位 → 拼 8 位字节（跳过 `=`）→ `_utf8_decode` 三档还原。边界：BMP 外字符（>0xFFFF）按 charCodeAt 单码元处理（代理对被拆成两个 3 字节组，UTF-16 层面往返自洽，但非标准 UTF-8 码点编码）；解码容忍输入中的非法字符。
- **关键代码摘录**：

##### 8. 时间戳转换器（/front-end/852/）

- **核心算法**：基于 **moment 2.x + moment-timezone（带 1970–2030 时区数据）+ zh-cn locale + flatpickr 4.6.13**。
  - 时间戳→日期 `unix2human`：输入**仅接受整数秒**（`Number(raw)`、`isFinite`、`Math.floor(n)!==n` 校验，提示"请输入整数时间戳（秒）"）；`moment.unix(n)` 按**本地时区**解析，输出：中文年月日 + 星期（`dddd`）、短日期（`L`）、时刻（`LTS`）、自动检测的时区名（`moment.tz.guess()`）、UTC 时间。
  - 日期→时间戳 `human2unix`：flatpickr 选择日期 + 时间 → 拼接 `YYYY-MM-DD HH:mm:ss` → `moment(s,'YYYY-MM-DD HH:mm:ss',true)` 严格解析 → `m.unix()`（秒），同时显示**毫秒 = 秒 × 1000**。
  - 当前时间戳每秒刷新（`Math.round(Date.now()/1000)`）。
  - 边界：**无毫秒输入切换**（输入固定按秒解释，毫秒仅作为输出展示）；依赖本地时区（浏览器时区），无手动时区选择。

##### 9. 进制转换器（/front-end/58/）

- **核心算法**：**BigNumber.js v9.1.1**（jsDelivr 压缩版整库内联，页面 882–889 行）做任意进制大数转换。流程：输入校验 `isValidForBase`（合法字符集 = `0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ` 前 base 个，大小写不敏感，小数点至多 1 个）→ `new BigNumber(inputVal, sourceBase)` 按源进制解析 → `decimalVal.toString(targetBase).toUpperCase()` 输出。配置 `DECIMAL_PLACES:20`、`ROUNDING_MODE:ROUND_HALF_UP`（支持小数）。边界：预设源/目标进制 **2/8/10/16**，自定义输入 **2–36**；支持负数、小数、任意大整数（BigNumber 十进制精度 20 位）；`generateExplanation` 生成"按权展开求和"与"除基取余"步骤演示。
- **关键代码摘录**：

- **核心算法**：五个页面共用外部 `color.js` 的 `convertTo(from,to)` 调度器（所有互转经 RGB 中转）：
  - `hexTorgb`：两位切片 `parseInt(x,16)`。
  - `rgbToHex/toHex`：`"0123456789ABCDEF".charAt(...)` 手工表转换，`Math.max(0,Math.min(n,255))` 夹取。
  - `rgb2hsv`：r/g/b 归一化；`max/min/d`；H 用三段公式后 `h/=6` **归一化到 0-1**；S、V 亦 0-1；输出 `toFixed(4)`。
  - `hsv2rgb`：**H 输入为 0-1**（`i=floor(h*6); f=h*6-i`），S、V 0-1；六分扇区 switch；`Math.floor(x*255)`。
  - `RgbToCmyk`：黑点特判 `(0,0,0)→[0,0,0,1]`；否则 `K=min(1-R/255,1-G/255,1-B/255)`，`C=(calcR-K)/(1-K)` 等，输出 0-1 四位小数。
  - `cmyk2rgb`：**存在缺陷**——`else if` 链导致只有第一个 >0 的分量会被 `/100`（0-100 输入约定下结果错误）；公式 `1-min(1, c*(1-k)+k)` ×255。
- **源码位置**：外部 js `https://www.jyshare.com/wp-content/themes/toolrunoob2/assets/js/color.js`（132KB，含约 500 色名对照表）；页面内联 script 仅做 UI 绑定（868/870/873/875/877 的内联脚本各 265~405B，调用 `convertTo`）。
- **关键代码**：
  ```js
  function rgb2hsv(r,g,b){
    hsv_red=r/255; hsv_green=g/255; hsv_blue=b/255;
    var max=Math.max(...), min=Math.min(...), d=max-min;
    hsv_s = max==0 ? 0 : d/max;  hsv_v = max;
    if(max==min) hsv_h=0;
    else { switch(max){ case hsv_red: hsv_h=(g-b)/d+(g<b?6:0); break;
            case hsv_green: hsv_h=(b-r)/d+2; break;
            case hsv_blue: hsv_h=(r-g)/d+4; break; } hsv_h/=6; }
    return (hsv_h.toFixed(4)+","+hsv_s.toFixed(4)+","+hsv_v.toFixed(4));
  }
  function RgbToCmyk(R,G,B){ if(R==0&&G==0&&B==0) return [0,0,0,1];
    var calcR=1-R/255, calcG=1-G/255, calcB=1-B/255;
    var K=Math.min(calcR,Math.min(calcG,calcB));
    return ((calcR-K)/(1-K)).toFixed(4)+","+((calcG-K)/(1-K)).toFixed(4)+","+
           ((calcB-K)/(1-K)).toFixed(4)+","+K.toFixed(4); }
  ```
- **离线可实现性**：纯前端、零依赖。移植时注意：HSV 的 H/S/V 均为 0-1 归一化约定；`cmyk2rgb` 的 else-if 缺陷应修复为每个分量独立判断。

#### 二、随机生成类（4 个）

##### 7. 随机密码生成器（/front-end/686/）
- **核心算法**：字符集字典（小写/大写/数字/特殊 `!@#$%^&*()_+-=[]{}|;:,.<>?`）按勾选拼接 → `Math.random()*charset.length` 取字符循环拼接。长度 4~100（`Math.max(4,Math.min(100,val))`）。强度评分：长度>10、有大写、有数字、有非字母数字各 +25 分。
- **源码位置**：内联 script（3583B）。依赖 jQuery（仅 UI）、无算法库。
- **关键代码**：
  ```js
  let password = '';
  for (let i = 0; i < length; i++)
      password += charset.charAt(Math.floor(Math.random() * charset.length));
  ```
- **离线可实现性**：纯前端零依赖。随机源为 `Math.random`（非密码学安全，可自行换 `crypto.getRandomValues` 增强）。

##### 8. 随机数生成器（/front-end/6680/）
- **核心算法**：**密码学安全随机 + 无偏拒绝采样**：
  ```js
  function randInt(min,max){
    var range=max-min+1,buf=new Uint32Array(1),
        limit=Math.floor(4294967296/range)*range,v;
    do{ crypto.getRandomValues(buf); v=buf[0]; }while(v>=limit);
    return min+(v%range);
  }
  ```
  范围夹取 ±1e9；数量 1~100；不重复模式用 `Set`（上限 100 万次守卫）；80ms 定时器实现"滚动抽奖"；历史 10 条。
- **源码位置**：内联 script（5202B），原生 JS 无 jQuery 依赖。
- **离线可实现性**：纯前端零依赖；`crypto.getRandomValues` 在 Electron 渲染层可用。

##### 9. 随机字符串生成器（/front-end/9111/）
- **核心算法**：四个字符集（小写/大写/数字/标点 `!@#$%^&*()_+~`|}{[]\:;?><,./-=`）按勾选**固定顺序轮询追加**，随机索引 `Math.ceil(len*Math.random())-1`（**该式有分布缺陷**：索引 0 概率减半，最后一个字符概率翻倍）。批量生成用换行拼接。
- **源码位置**：内联 script（2661B），依赖 jQuery + ClipboardJS。
- **离线可实现性**：纯前端零依赖；建议用 `Math.floor(Math.random()*len)` 修正分布。

##### 10. 随机颜色生成器（/front-end/9072/）
- **核心算法**：调用第三方库 **randomColor**（`static.jyshare.com/assets/libs/randomColor.min.js`，即 David Merfield 的 randomColor.js）。该库在 HSV 空间生成：按颜色名预设 hue 范围（red/orange/yellow/green/blue/purple/pink/monochrome），luminosity 决定 S/V 区间，支持 format=hex/rgb/rgba/hsl/hsla/hsvArray、alpha、seed（字符串哈希种子）。默认无 seed 用 `Math.random`。
- **源码位置**：外部库 + 内联调用脚本（2994B，jQuery）。
- **关键代码**：
  ```js
  colorData = randomColor({alpha:..., format:..., luminosity:..., hue:..., count: numberOfColors});
  ```
- **离线可实现性**：需打包 randomColor.js（MIT，4.7KB），或自行实现 HSV→RGB 随机（算法简单，几十行）。

##### 12. 存储单位换算（/front-end/9229/）

##### 15. XML 格式化（/front-end/710/）

#### 五、其他（3 个）

##### 16. 人民币数字大小写转换（/front-end/6907/）
- **核心算法**：输入校验 `/^[0-9,]+(\.[0-9]{1,2})?$/` 且 >0 → `toFixed(2)` 拆分。整数部分**从低位每 4 位分组**，组内按"零壹贰叁肆伍陆柒捌玖 + 拾佰仟"拼写，组内零压缩（zeroFlag，连续零只补一个"零"），组尾追加"万/亿/兆"（bigUnits）。小数部分：角、分逐位，无小数则"整"。
- **源码位置**：内联 script（4531B），jQuery。
- **关键代码**：
  ```js
  const digits=['零','壹','贰','叁','肆','伍','陆','柒','捌','玖'];
  const units=['','拾','佰','仟']; const bigUnits=['','万','亿','兆'];
  while(intStr.length>0){ const group=intStr.slice(-4); intStr=intStr.slice(0,-4);
    let groupText='', zeroFlag=false;
    for(let i=0;i<group.length;i++){ const d=parseInt(group[i]);
      if(d===0) zeroFlag=true;
      else { if(zeroFlag){ groupText+='零'; zeroFlag=false; }
             groupText += digits[d]+units[group.length-i-1]; } }
    if(groupText!=='') groupText+=bigUnits[groupIndex]; integerPart=groupText+integerPart; groupIndex++; }
  ```
- **离线可实现性**：纯算法零依赖，最易移植。注意：≥兆（1e12）以上分组溢出 bigUnits 数组（undefined），移植可扩展。

##### 17. 在线计算器（/front-end/6904/）
- **核心算法**：**双栈（操作数栈+运算符栈）+ 优先级表求值**，非表达式字符串解析：
  - 优先级表：`)`:0, `|`:1, `&`:2, `+/-`:3, `*/%`:4, `^/yroot`:5, `(`:6。
  - 二元运算：`Math.pow` 处理 `^`/`yroot`；加减乘除取余及位运算用 **`eval(f+op+s)`**——但操作数仅来自按键拼装的数字字符串与受限运算符，无任意表达式注入（唯一 eval 面为数字+单个运算符+数字）；程序员型按进制 `parseInt(x,16/8/2)` 转十进制运算再转回。
  - 一元：sin/cos/tan/sinh/cosh/tanh/√/x²/1/x/n!/log10/10^x/π/±/~（`~` 用 eval）。
  - 三种模式（标准/科学/程序员），结果显示 ≤13 位否则 `toExponential(7)`；科学型角度/弧度由页面切换。
- **源码位置**：内联 script（35067B），原生 JS 无依赖。
- **关键代码**：
  ```js
  operatorPriority: { ")":0, "|":1, "&":2, "+":3, "-":3, "*":4, "%":4, "/":4, "^":5, "yroot":5, "(":6 },
  _stackHelper: function(f,s,op){
    if(op==="^") result=Math.pow(f,s);
    else if(op==="yroot") result=Math.pow(f,1/s);
    else result = eval(f + op + s);   // 程序员型先按进制 parseInt 再 eval
  }
  ```
- **离线可实现性**：纯前端零依赖，可直接移植；安全上建议把 `eval` 替换为显式 switch 运算（消除依赖 eval 的风险面）。

##### 18. 图片转 Base64（/front-end/59/）
- **核心算法**：**不用 FileReader，用 `file.arrayBuffer()` → Uint8Array**：
  - 编码：字节分块 24576 经 `String.fromCharCode(...bytes.subarray)` → `btoa` → `data:<mime>;base64,`。输出格式 raw/dataURL/HTML img/CSS 四选一。
  - 解码：校验 Base64 字符表/补位 → `atob` → 回验 `btoa(binary)===text` → Uint8Array → Blob → `new Image()` + `URL.createObjectURL` 解码 → 显示。
  - **魔数探测 `probeImage`（全部内联实现）**：PNG(137 'PNG' + IHDR 宽高)、GIF87a/89a、JPEG(FFD8 段扫描 SOF0-15)、WebP(RIFF/WEBP 的 VP8X/VP8L/VP8)、BMP(BM, BITMAPCORE/INFOHEADER)、SVG(文本 < 开头)。**SVG 消毒 cleanSVG**：禁 DTD/实体、白名单标签/属性、移除 url() 引用与脚本节点。
  - 限制：20MB、16000px 单边、4000 万像素、SVG ≤1 万元素。导出下载用 `canvas.toBlob`（jpg 白底填充、质量 .92）。
- **源码位置**：内联 script（18834B），原生 JS 零第三方库。
- **关键代码**：
  ```js
  function bytesBase64(bytes){ let text='';
    for(let i=0;i<bytes.length;i+=24576)
      text += String.fromCharCode(...bytes.subarray(i,i+24576));
    return btoa(text); }
  // 解码：binary=atob(text) → Uint8Array.from(binary,c=>c.charCodeAt(0))
  ```
- **离线可实现性**：纯前端零依赖；Electron 渲染层 Blob/Image/atob/btoa 全部可用，直接移植。

#### 三、移植过程中的关键改进（相对原站）

| 项 | 原站实现 | 本项目实现 |
| --- | --- | --- |
| CMYK → RGB | else-if 链缺陷（仅第一个 >0 分量 /100） | 四分量统一 /100，往返测试容差 ±1 通过 |
| JSON 去转义 | `\/`→空格、`\\"` 还原错误 | 逐字符扫描正确还原，兼容 `\uXXXX`、未知转义原样保留 |
| 随机数/密码 | Math.random（索引 0 概率减半等分布缺陷） | crypto.getRandomValues 拒绝采样 + Fisher-Yates |
| 时间戳 | moment + moment-timezone（约 700KB） | 原生 Date 手工解析 + 日期存在性回验 |
| 正则测试 | Web Worker（需处理打包路径） | 主线程 + 匹配数/字符数防护上限 |
| 文本比对 | Mergely（LGPL，约 500KB） | 自写行级 LCS（DP），大文本保护 |
| 进制转换 | bignumber.js 依赖 | BigInt + 分数表示法（无浮点误差） |
| 计算器 | eval 拼接运算 | 双栈 + 显式 switch 运算 |
