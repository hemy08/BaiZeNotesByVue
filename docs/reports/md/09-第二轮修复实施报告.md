## 3. 第一波修复明细

### r2-monaco（PF-03 / CMP-28 / FUN-09）
- 弃用不兼容的 vite-plugin-monaco-editor（vite 2.x 时代产物），改 Monaco 官方手动方案：`?worker` 导入 + `MonacoEnvironment.getWorker`，裸包名精确重定向到 editor.api + 45 个精选语言 + 全部 contributions；
- 产物：editor.worker 0.57MB 运行时加载，ts/css/html/json worker 按需；主 chunk 10.31 → 10.18MB；
- 编辑器动作：折叠（foldAll/unfoldAll/foldLevelN + markdown 折叠提供器）、查找/替换（actions.find/startFindReplaceAction）、跳行（钳制校验）、大纲下拉（ATX 标题提取 + 点击跳转）。

### r2-func-menu（FUN-09/26/30、CMP-29）
- 菜单 → EventBus 契约事件（与 r2-monaco 对齐）：折叠 8 项、查找、替换、跳行、大纲；
- 剪切/复制/粘贴走既有 Monaco IPC；绘图改 Mermaid/PlantUML 子菜单走模板插入链路；
- 快捷键真实绑定：Ctrl+N/O/R、Ctrl+Shift+R、F4（沿用 globalShortcut 机制）；Monaco 原生键标注如实保留；
- 无法低成本实现的（跨文件检索、模板管理）按 A-4 隐藏并注释；删除右键 alert 调试项。

### r2-func-io（FUN-10/14/15/21/22/24/27/30、PF-10/14、MEM-07）
- 自动更新优雅化：electron-updater 封装 + 占位 URL 时诚实提示"未配置更新源"（CMP-21 收口）；
- 导入：ini 入口可用、文本类统一编码探测、xls/xlsx 明确引导转 CSV（不再乱码）；
- 导出：PDF 窗口 try/finally（MEM-07）、XML CDATA 转义、版本号从 package.json 读取；
- 渲染：围栏代码块全保护、危险协议链接不生成可点击 HTML、mermaid 失败回显源码、TOC 稳定 id；
- 右键"在文件夹中显示"可用；大文件确认改异步对话框；用户提示统一中文。

### r2-mem（MEM-09/10/12/13、FUN-18）
- EventBus 恢复 $checkLeaks()/$stats() 泄漏检测（+5 用例）；
- 59 处直连 IPC 统一经 ipc-listener-manager（registerOnce 防重复 + inventory 库存）；
- 12 个对话框 JSDOM 显式 close；TitleBar/useDialogDrag 拖拽监听兜底卸载；
- 无活动文件时保存请求只提示一次、不弹错误框。

### r2-quality（CQ-06/07、FUN-12）
- 超长文件拆分：ShowEditorSettingDialog 1403→211、Information 1375→29（+12 数据文件）、快捷符号/表情数据文件分离，全部 <800 行、对外 API 不变；

## 4. 第二波重构明细

### r2-arch-ipc（ARC-02/03/11/14、CQ-09/11）
- **通道常量单真源**：ipc-channels.ts 重写为 16 组 125 个常量（补缺 17、删死 7），全项目 465 处 IPC 字面量替换为常量，线上字符串不变，新增防回归测试（8 用例）双向交叉核对；
- **事件双轨收口**：EventBus 26 个事件名常量集中，60 处引用收口，插件工具事件收敛单轨；
- **边界收敛**：渲染层 import 主进程源码 7 处全部收敛到 shared；**循环依赖解除**（新增 file-state-store.ts，删除 @ts-ignore/延迟 require）；
- **重命名**：13 个 snake_case 文件 + event_bus 目录改 kebab-case，63 处路径同步。

### r2-arch-config（ARC-04/05/12、CQ-08、FUN-02/29）
- **配置单真源**：config-manager 增加 STORE_BACKED_CONFIGS 路由表，渲染层读写 system/theme/editor/quick-links 全部落主进程 electron-store（单文件、单目录）；system 写入后联动重启自动保存定时器/注入字体 CSS/广播（FUN-04 存储半边收口）；旧 system.json 一次性合并迁移并改名备份（幂等，可回滚）；
- **ARC-12**：四 config 模块收敛共享安全工厂，setTheme 合并策略防丢字段；
- **CQ-08**：双 tsconfig 开启 noUnusedLocals/noUnusedParameters，修复 20 处未用变量，typecheck 0 错误；
- **any 清零**：消除 306 处（改具体类型/unknown/泛型），豁免 9 个（带中文说明），no-explicit-any 315→0，warning 453→121；
- **编码菜单打通**（FUN-02）：file-reopen-with-encoding / file-convert-encoding 通道四段链路完成；**FUN-29**：状态栏显示实际编码、空文件不注入 \r\n、新建文件内存/磁盘一致。
