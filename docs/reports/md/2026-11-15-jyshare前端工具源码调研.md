## 一、颜色转换类（6 个）

### 1. RGB ↔ HEX（/front-end/55/）
- **核心算法**：RGB→HEX：`parseInt(v,10)` → 上限 255 → `v.toString(16)` → 单字符补 0（`padHex`）→ 拼接加 `#` 并大写。HEX→RGB：去掉 `#`，仅接受长度 3/6/8，按 `.{1,2}` 分组后 `parseInt(x,16)`。输入框过滤非数字/非 HEX 字符。
- **源码位置**：内联 `<script>`（第 7 个 script，3529B）。依赖 jQuery、ClipboardJS、**Pickr**（外部库 `static.jyshare.com/assets/libs/pickr/dist/pickr.min.js`，仅用于取色器，转换逻辑不依赖它）。
- **关键代码**：
  ```js
  const padHex = (char) => char.length === 1 ? '0' + char : char;
  const rgbToHex = () => {
      const hexValues = $rgbInputs.map(function () {
          const value = parseInt(this.value, 10);
          return padHex((value > 255 ? 255 : value).toString(16));
      }).get();
      $hexInput.val('#' + hexValues.join('').toUpperCase());
  };
  // HEX→RGB：hex.match(/.{1,2}/g) 后 parseInt(v,16)
  ```
- **离线可实现性**：纯前端，零算法依赖；可去掉 Pickr 或用原生 color input 替代。注意：3 位 hex 被按 2+1 分割，实现有瑕疵，重写时应修正。

### 2~6. RGB/HEX/HSV/CMYK 互转（/front-end/868, 870, 873, 875, 877/）
- **核心算法**：五个页面共用外部 `color.js` 的 `convertTo(from,to)` 调度器（所有互转经 RGB 中转）：
  - `hexTorgb`：两位切片 `parseInt(x,16)`。
  - `rgbToHex/toHex`：`"0123456789ABCDEF".charAt(...)` 手工表转换，`Math.max(0,Math.min(n,255))` 夹取。
  - `rgb2hsv`：r/g/b 归一化；`max/min/d`；H 用三段公式后 `h/=6` **归一化到 0-1**；S、V 亦 0-1；输出 `toFixed(4)`。
  - `hsv2rgb`：**H 输入为 0-1**（`i=floor(h*6); f=h*6-i`），S、V 0-1；六分扇区 switch；`Math.floor(x*255)`。
  - `RgbToCmyk`：黑点特判 `(0,0,0)→[0,0,0,1]`；否则 `K=min(1-R/255,1-G/255,1-B/255)`，`C=(calcR-K)/(1-K)` 等，输出 0-1 四位小数。
  - `cmyk2rgb`：**存在缺陷**——`else if` 链导致只有第一个 >0 的分量会被 `/100`（0-100 输入约定下结果错误）；公式 `1-min(1, c*(1-k)+k)` ×255。
- **源码位置**：外部 js `https://www.jyshare.com/wp-content/themes/toolrunoob2/assets/js/color.js`（132KB，含约 500 色名对照表）；页面内联 script 仅做 UI 绑定（868/870/873/875/877 的内联脚本各 265~405B，调用 `convertTo`）。
- **关键代码**：
  ```js
  function rgb2hsv(r,g,b){
    hsv_red=r/255; hsv_green=g/255; hsv_blue=b/255;
    var max=Math.max(...), min=Math.min(...), d=max-min;
    hsv_s = max==0 ? 0 : d/max;  hsv_v = max;
    if(max==min) hsv_h=0;
    else { switch(max){ case hsv_red: hsv_h=(g-b)/d+(g<b?6:0); break;
            case hsv_green: hsv_h=(b-r)/d+2; break;
            case hsv_blue: hsv_h=(r-g)/d+4; break; } hsv_h/=6; }
    return (hsv_h.toFixed(4)+","+hsv_s.toFixed(4)+","+hsv_v.toFixed(4));
  }
  function RgbToCmyk(R,G,B){ if(R==0&&G==0&&B==0) return [0,0,0,1];
    var calcR=1-R/255, calcG=1-G/255, calcB=1-B/255;
    var K=Math.min(calcR,Math.min(calcG,calcB));
    return ((calcR-K)/(1-K)).toFixed(4)+","+((calcG-K)/(1-K)).toFixed(4)+","+
           ((calcB-K)/(1-K)).toFixed(4)+","+K.toFixed(4); }
  ```
- **离线可实现性**：纯前端、零依赖。移植时注意：HSV 的 H/S/V 均为 0-1 归一化约定；`cmyk2rgb` 的 else-if 缺陷应修复为每个分量独立判断。

## 二、随机生成类（4 个）

### 7. 随机密码生成器（/front-end/686/）
- **核心算法**：字符集字典（小写/大写/数字/特殊 `!@#$%^&*()_+-=[]{}|;:,.<>?`）按勾选拼接 → `Math.random()*charset.length` 取字符循环拼接。长度 4~100（`Math.max(4,Math.min(100,val))`）。强度评分：长度>10、有大写、有数字、有非字母数字各 +25 分。
- **源码位置**：内联 script（3583B）。依赖 jQuery（仅 UI）、无算法库。
- **关键代码**：
  ```js
  let password = '';
  for (let i = 0; i < length; i++)
      password += charset.charAt(Math.floor(Math.random() * charset.length));
  ```
- **离线可实现性**：纯前端零依赖。随机源为 `Math.random`（非密码学安全，可自行换 `crypto.getRandomValues` 增强）。

### 8. 随机数生成器（/front-end/6680/）
- **核心算法**：**密码学安全随机 + 无偏拒绝采样**：
  ```js
  function randInt(min,max){
    var range=max-min+1,buf=new Uint32Array(1),
        limit=Math.floor(4294967296/range)*range,v;
    do{ crypto.getRandomValues(buf); v=buf[0]; }while(v>=limit);
    return min+(v%range);
  }
  ```
  范围夹取 ±1e9；数量 1~100；不重复模式用 `Set`（上限 100 万次守卫）；80ms 定时器实现"滚动抽奖"；历史 10 条。
- **源码位置**：内联 script（5202B），原生 JS 无 jQuery 依赖。
- **离线可实现性**：纯前端零依赖；`crypto.getRandomValues` 在 Electron 渲染层可用。

### 9. 随机字符串生成器（/front-end/9111/）
- **核心算法**：四个字符集（小写/大写/数字/标点 `!@#$%^&*()_+~`|}{[]\:;?><,./-=`）按勾选**固定顺序轮询追加**，随机索引 `Math.ceil(len*Math.random())-1`（**该式有分布缺陷**：索引 0 概率减半，最后一个字符概率翻倍）。批量生成用换行拼接。
- **源码位置**：内联 script（2661B），依赖 jQuery + ClipboardJS。
- **离线可实现性**：纯前端零依赖；建议用 `Math.floor(Math.random()*len)` 修正分布。

### 10. 随机颜色生成器（/front-end/9072/）
- **核心算法**：调用第三方库 **randomColor**（`static.jyshare.com/assets/libs/randomColor.min.js`，即 David Merfield 的 randomColor.js）。该库在 HSV 空间生成：按颜色名预设 hue 范围（red/orange/yellow/green/blue/purple/pink/monochrome），luminosity 决定 S/V 区间，支持 format=hex/rgb/rgba/hsl/hsla/hsvArray、alpha、seed（字符串哈希种子）。默认无 seed 用 `Math.random`。
- **源码位置**：外部库 + 内联调用脚本（2994B，jQuery）。
- **关键代码**：
  ```js
  colorData = randomColor({alpha:..., format:..., luminosity:..., hue:..., count: numberOfColors});
  ```
- **离线可实现性**：需打包 randomColor.js（MIT，4.7KB），或自行实现 HSV→RGB 随机（算法简单，几十行）。

## 三、单位换算类（2 个）

### 11. 长度单位换算（/front-end/5575/）
- **核心算法**：**以米为基准的系数表**（21 个单位），`值×from系数 ÷ to系数`；结果 ≥1e6 或 ≤0.0001 用 `toExponential(6)`，否则正则截取 6 位小数。
- **系数表**：mm=0.001, cm=0.01, dm=0.1, m=1, km=1000, um=1e-6, nm=1e-9, pm=1e-12, in=0.0254, ft=0.3048, yd=0.9144, mi=1609.344, nmi=1852, ly=9460730472580800, au=149597870700, pc=30856775814913672.789, zhang(丈)=3.3333, chi(尺)=0.33333, cun(寸)=0.033333, fen(分)=0.0033333, li(里)=500。
- **源码位置**：内联 script（2568B），jQuery。
- **离线可实现性**：纯前端零依赖，一张表即可移植。

### 12. 存储单位换算（/front-end/9229/）
- **核心算法**：第三方库 **UnitOf.js**（`static.jyshare.com/assets/UnitOf/JavaScript/UnitOf.min.js`）的 `DataStorage` 模块，**基准单位为 MB（系数 1）**，二进制 1024 制：B=8×1024×1024（bit→MB）、KB=1024、GB=1/1024、TB=1/1024²、PB=1/1024³…；SI 系列（SIKB 等）经 `1024×(1024/1e3)/1e3^n` 折算；另含 CD/DVD/软盘等介质单位（CD74: 665096/1024，D11 等）。
- **源码位置**：外部库 UnitOf.min.js（65KB）+ 内联调用脚本（1711B，jQuery），动态拼 `from<Unit>/to<Unit>` 方法名调用。
- **关键代码**：
  ```js
  var unit = UnitOf.DataStorage;
  unit = unit[fromFuncName](_theVal);   // fromKilobytes(1024)
  var x = unit[toFuncName];             // toMegabytes -> 1
  ```
- **离线可实现性**：需打包 UnitOf.js（开源库），或自行实现约 40 条系数（B/KB/MB/GB/TB/PB/EB/ZB/YB × bit/byte × SI/IEC，简单）。

## 四、文本处理类（3 个）

### 13. 正则表达式在线测试（/front-end/854/）
- **核心算法**：主线程脚本（28089B）收集 pattern/flags/text/replacement，**在 Web Worker（外部 regex-worker.js）中执行**：`new RegExp(pattern,flags)` → `regex.exec(text)` 循环（g 标志）→ 匹配项（含分组、命名组、indices）；**零宽匹配手动推进 lastIndex**（unicode 模式下跳过代理对）。替换不用 `String.replace` 而是自定义 `substitute` 解析 `$&、$`、$'、$$、$n、$<name>`。防卡死：1.5s 超时 `worker.terminate()`；上限：5000 匹配、200 万字符输出、100 分组、表达式 5000 字符、文本 20 万字符。**JS 标志全集 d/g/i/m/s/u/v/y**，u/v 互斥。附 17 组预设、速查表、JS/PHP/Python/Java/Go/Ruby 代码生成。
- **源码位置**：内联 script + 外部 `https://www.jyshare.com/wp-content/themes/toolrunoob2/assets/tool-regex-tester/regex-worker.js`（5434B）。零第三方库（原生 Worker）。
- **关键代码**（worker）：
  ```js
  regex = new RegExp(pattern, flags);
  while(true){ const m = regex.exec(text); if(!m) break;
    if(matches.length === MAX_MATCHES){ truncated = true; break; }
    ... matches.push({index:m.index, end:m.index+m[0].length, value:m[0], groups, named, groupCount});
    if(!regex.global) break;
    if(m[0]==='') regex.lastIndex = advance(text, regex.lastIndex, regex.unicode||regex.unicodeSets);
  }
  ```
- **离线可实现性**：纯前端零库。Electron 渲染层 Worker 可用（需处理打包路径）；桌面插件中也可以直接在主线程跑（省去 Worker，但需自己加超时/大文本限制）。

### 14. SQL 格式化/压缩（/front-end/701/）
- **核心算法**：**服务端实现，前端无格式化算法**。前端仅：CodeMirror（mode: text/x-mariadb）编辑器取值 → `hmacJson('/more/ajax.php?type=SqlFormatter'+(action?'&action=compress':''), {query: sql})`。hmacJson 流程：先 `GET /more/ai/search_token.php` 换 HMAC 凭证（格式 `时间戳10位.md5_32位.hmac_64位`）→ 带 `X-Auth-Token` POST ajax.php → 服务端格式化后返回 HTML 片段（`result.res`）直接 `innerHTML` 注入。
- **源码位置**：内联 script（2263B）+ 外部 `https://www.jyshare.com/more/ai/hmac-client.js?v=2` + CodeMirror 三件套（codemirror.min.js / mode/simple.js / mode/sql/sql.js）。
- **关键代码**：
  ```js
  function runFormatter(action){
    var url = "/more/ajax.php?type=SqlFormatter" + (action ? "&action=" + action : "");
    hmacJson(url, {query: editor1.getValue()}).then(function(result){
      if (!result || typeof result.res !== 'string') throw new Error('bad response');
      resultEl.innerHTML = result.res;
    });
  }
  ```
- **离线可实现性**：**不可离线**（依赖服务端 PHP 格式化器 + 凭证接口）。离线插件必须改用前端库（如 `sql-formatter`）自行实现。

### 15. XML 格式化（/front-end/710/）
- **核心算法**：**自研轻量词法解析器**（非第三方 vkbeautify），三件套全部同域静态文件：
  - `core.js`（3368B）：`tokens(xml)` 词法扫描（text/open/close/comment/CDATA/PI/DOCTYPE，引号与 DOCTYPE 内括号处理）；`tree(xml)` 用栈建树并校验闭合（≤255 层、≤15 万 token）；`layout(xml,step,compact)` 递归重排——**文本敏感子树（含非空白文本或 CDATA 或 `xml:space="preserve"`）整体按原始字节保留**，其余按缩进 step 重排；compact 模式即压缩。
  - `app.js`（10850B）：UI 主逻辑；**校验用浏览器内置 `DOMParser.parseFromString(text,'application/xml')` + parsererror 检测**；格式化=layout、压缩=layout(compact)、校验=仅 DOMParser；撤销/重做栈 8 步；文件导入带编码探测（UTF-8 BOM/UTF-16 LE-BE/XML 声明）；导出强制 UTF-8；10MB 上限。
  - `loader.js`：按需加载 vendor 版 CodeMirror + xml 语法模式。
- **源码位置**：外部 `static.jyshare.com/assets/libs/xml-formatter/{core.js,loader.js,app.js?v=2.1.0}` + vendor CodeMirror。
- **关键代码**（core.js layout 片段）：
  ```js
  function render(n,depth){ if(n.type!=='open') return n.raw;
    const textSensitive = n.children.some(c => c.type==='cdata' ||
      (c.type==='text' && (c.raw.trim()!=='' || !/[\r\n]/.test(c.raw))));
    if(n.preserve||textSensitive){ protectedCount++; return xml.slice(n.start,n.end); }
    ...
    if(compact) return n.raw + children.map(c=>render(c,depth+1)).join('') + n.close;
    return n.raw + '\n' + children.map(c=>step.repeat(depth+1)+render(c,depth+1)).join('\n')
         + '\n' + step.repeat(depth) + n.close; }
  ```
- **离线可实现性**：纯前端、解析器自研可整体移植（core.js 仅 3.4KB）。编辑器可换 textarea 或轻量编辑器；`DOMParser` 在 Electron 渲染层可用。

## 五、其他（3 个）

### 16. 人民币数字大小写转换（/front-end/6907/）
- **核心算法**：输入校验 `/^[0-9,]+(\.[0-9]{1,2})?$/` 且 >0 → `toFixed(2)` 拆分。整数部分**从低位每 4 位分组**，组内按"零壹贰叁肆伍陆柒捌玖 + 拾佰仟"拼写，组内零压缩（zeroFlag，连续零只补一个"零"），组尾追加"万/亿/兆"（bigUnits）。小数部分：角、分逐位，无小数则"整"。
- **源码位置**：内联 script（4531B），jQuery。
- **关键代码**：
  ```js
  const digits=['零','壹','贰','叁','肆','伍','陆','柒','捌','玖'];
  const units=['','拾','佰','仟']; const bigUnits=['','万','亿','兆'];
  while(intStr.length>0){ const group=intStr.slice(-4); intStr=intStr.slice(0,-4);
    let groupText='', zeroFlag=false;
    for(let i=0;i<group.length;i++){ const d=parseInt(group[i]);
      if(d===0) zeroFlag=true;
      else { if(zeroFlag){ groupText+='零'; zeroFlag=false; }
             groupText += digits[d]+units[group.length-i-1]; } }
    if(groupText!=='') groupText+=bigUnits[groupIndex]; integerPart=groupText+integerPart; groupIndex++; }
  ```
- **离线可实现性**：纯算法零依赖，最易移植。注意：≥兆（1e12）以上分组溢出 bigUnits 数组（undefined），移植可扩展。

### 17. 在线计算器（/front-end/6904/）
- **核心算法**：**双栈（操作数栈+运算符栈）+ 优先级表求值**，非表达式字符串解析：
  - 优先级表：`)`:0, `|`:1, `&`:2, `+/-`:3, `*/%`:4, `^/yroot`:5, `(`:6。
  - 二元运算：`Math.pow` 处理 `^`/`yroot`；加减乘除取余及位运算用 **`eval(f+op+s)`**——但操作数仅来自按键拼装的数字字符串与受限运算符，无任意表达式注入（唯一 eval 面为数字+单个运算符+数字）；程序员型按进制 `parseInt(x,16/8/2)` 转十进制运算再转回。
  - 一元：sin/cos/tan/sinh/cosh/tanh/√/x²/1/x/n!/log10/10^x/π/±/~（`~` 用 eval）。
  - 三种模式（标准/科学/程序员），结果显示 ≤13 位否则 `toExponential(7)`；科学型角度/弧度由页面切换。
- **源码位置**：内联 script（35067B），原生 JS 无依赖。
- **关键代码**：
  ```js
  operatorPriority: { ")":0, "|":1, "&":2, "+":3, "-":3, "*":4, "%":4, "/":4, "^":5, "yroot":5, "(":6 },
  _stackHelper: function(f,s,op){
    if(op==="^") result=Math.pow(f,s);
    else if(op==="yroot") result=Math.pow(f,1/s);
    else result = eval(f + op + s);   // 程序员型先按进制 parseInt 再 eval
  }
  ```
- **离线可实现性**：纯前端零依赖，可直接移植；安全上建议把 `eval` 替换为显式 switch 运算（消除依赖 eval 的风险面）。

### 18. 图片转 Base64（/front-end/59/）
- **核心算法**：**不用 FileReader，用 `file.arrayBuffer()` → Uint8Array**：
  - 编码：字节分块 24576 经 `String.fromCharCode(...bytes.subarray)` → `btoa` → `data:<mime>;base64,`。输出格式 raw/dataURL/HTML img/CSS 四选一。
  - 解码：校验 Base64 字符表/补位 → `atob` → 回验 `btoa(binary)===text` → Uint8Array → Blob → `new Image()` + `URL.createObjectURL` 解码 → 显示。
  - **魔数探测 `probeImage`（全部内联实现）**：PNG(137 'PNG' + IHDR 宽高)、GIF87a/89a、JPEG(FFD8 段扫描 SOF0-15)、WebP(RIFF/WEBP 的 VP8X/VP8L/VP8)、BMP(BM, BITMAPCORE/INFOHEADER)、SVG(文本 < 开头)。**SVG 消毒 cleanSVG**：禁 DTD/实体、白名单标签/属性、移除 url() 引用与脚本节点。
  - 限制：20MB、16000px 单边、4000 万像素、SVG ≤1 万元素。导出下载用 `canvas.toBlob`（jpg 白底填充、质量 .92）。
- **源码位置**：内联 script（18834B），原生 JS 零第三方库。
- **关键代码**：
  ```js
  function bytesBase64(bytes){ let text='';
    for(let i=0;i<bytes.length;i+=24576)
      text += String.fromCharCode(...bytes.subarray(i,i+24576));
    return btoa(text); }
  // 解码：binary=atob(text) → Uint8Array.from(binary,c=>c.charCodeAt(0))
  ```
- **离线可实现性**：纯前端零依赖；Electron 渲染层 Blob/Image/atob/btoa 全部可用，直接移植。

## 适合作为离线桌面插件实现的优先级排序

**P0 — 零/轻依赖、直接移植（1~2 天级）**：
1. **人民币大写转换**（纯算法 30 行，零依赖）
2. **长度单位换算**（一张系数表）
3. **颜色转换全家桶**（6 页合一，公式全在手，含 bug 修正）
4. **随机四件套**（密码/数/字符串/颜色；颜色可用自写 HSV 随机替代 randomColor）
5. **在线计算器**（双栈求值自包含，替换 eval 即可）

**P1 — 纯前端但需打包库或适配环境**：
6. **图片转 Base64**（零库，依赖 Blob/Image API，Electron 渲染层天然支持）
7. **正则测试**（原生 Worker+RegExp，需处理打包后 worker 路径或改主线程）
8. **存储单位换算**（打包 UnitOf.js 或自写 ~40 条系数）
9. **XML 格式化**（自研解析器可直接搬，编辑器降级为 textarea 更省体积）

**P2 — 重实现**：
10. **SQL 格式化/压缩**（原站后端依赖无法离线；必须用前端库 sql-formatter 重写，工作量最大，不建议首期做）
