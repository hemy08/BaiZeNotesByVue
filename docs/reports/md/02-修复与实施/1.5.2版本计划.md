## 2. 批次设计要点

### 2.1 批次 1：E6 日记 / 模板 / 快速收件箱

- **目录约定**（相对工作区根，不新增可配置路径以避免 Path Guard 扩大）：日记 `diary/YYYY-MM-DD.md`；收件箱 `inbox/YYYY-MM-DD-HHmmss.md`。
- **模板变量**（纯函数，shared 层）：`{{date}}` `{{time}}` `{{datetime}}` `{{year}}` `{{month}}` `{{day}}` `{{weekday}}` `{{title}}`。
- **主进程能力**（新增 1 个 invoke 通道，渲染层不传任意路径）：`FILE.OPEN_OR_CREATE_ENTRY`
  - 入参 `{ kind: 'daily' | 'inbox' }`（白名单枚举）；
  - 主进程基于 `appState.rootPath` 生成目标路径 → 目录 `mkdir -p` → 文件不存在则写模板 → 复用既有「打开文件」链路通知渲染层；
  - 路径必须 resolve 后位于工作区根内；已存在文件不覆盖（返回 `created: false`）。
- **入口**：命令面板 2 条命令（今日日记 / 快速收件箱）、工具菜单 2 项、能力开关 `featureDailyNotes`（默认关闭）。
- **验收**：无工作区时明确提示；目录/文件不存在时正确创建；已存在时直接打开不覆盖；模板变量展开正确；开关关闭时命令不注册。

### 2.2 批次 2：E1 剪藏（剪贴板/文件导入增强）

- 命令「从剪贴板剪藏」：读剪贴板 `text/html` → Turndown → 新笔记（`inbox/…-clip.md`，front matter：`source`/`title`/`capturedAt`）或插入当前笔记（带来源引用）。
- 解析浏览器复制片段（`<!--StartFragment-->` 与来源元注释）；无 HTML 时回退纯文本。
- 不新增本地端口/扩展；剪贴板读取仅用户显式触发。

### 2.3 批次 3：E2 PDF 标注与摘录

- 基于现有 `ShowPdfEditor`（pdfjs-dist）增加文本层选择与高亮；标注存 sidecar（同名 `.pdf.annotations.json`），经 Path Guard 校验。
- 摘录插入当前 Markdown：`> 摘录文本` + 出处（文件、页码）；不做 PDF 内嵌编辑。

### 2.4 批次 4：E3 图片 OCR / 文字搜索

- OCR worker 懒加载（不在首屏）；引擎仅首次使用时加载；新增体积预算行并重跑 `budget:check`。
- 提取文本可插入当前笔记或参与工作区检索（与 A2 搜索/索引联动）；识别结果不落库时给出明确说明。

## 3. 通用验收与门禁（每批）

- 单元测试 + 关键 E2E；不降低现有覆盖率阈值（全局 80/80/73/75 + 目录 glob）；
- 门禁全绿：typecheck 四段 / ESLint 0 warning / Prettier / vitest+coverage / E2E / audit / budget / fuses / docs:check / quality:check；
- 新增 IPC 必须按六步链路落地（常量 → 契约 → 生成白名单 → handler + sender 校验 → 渲染层 → 四类测试），不新增例外；
- 新能力默认关闭（能力开关），关闭时零行为变化；
- 涉及文件写入的能力必须有失败提示与回滚/不覆盖语义；
- 每批完成后回写 CHANGELOG 1.5.2 条目与本节状态。

## 4. 风险与回滚

| 风险 | 缓解 |
| --- | --- |
| 新增 IPC 扩大攻击面 | 渲染层不传路径；主进程按约定生成并做 resolve 内根校验；sender 校验 + Path Guard |
| 模板变量展开注入 | 纯函数 + 白名单变量；不 eval；标题做文件名安全校验 |
| PDF 标注 sidecar 损坏 | 读取容错（损坏→空标注+日志）；写入原子化 |
| OCR 体积超预算 | 懒加载独立 chunk + worker；预算新增行；首次使用提示下载/加载 |
| 与并行会话冲突 | 每批独立提交；共享文件（ipc-channels/types/registry/i18n）集中由单批次修改 |

## 5. 里程碑

1. M1（批次 1 合并）：E6 可用、开关默认关闭、门禁全绿；
2. M2：E1 剪藏可用（不新增端口）；
3. M3：E2 标注摘录可用；
4. M4：E3 OCR 可用 + 体积预算重测通过；
5. M5：1.5.2 发布前全量复核（CHANGELOG/RELEASE-NOTES/应用内发布说明三段链路 + 全部门禁）。
