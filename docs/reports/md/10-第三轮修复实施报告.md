## 2. 各子智能体交付明细

### r3-ipc（CQ-05 / CQ-10 / PF-11 / ARC-21）
- **sendSync → invoke 改造**：4 个调用点（HashText.vue、HmacGenerator.vue、CryptoEncDec.vue×2）与 4 个主进程通道改为 `ipcMain.handle` + `await invoke`，加密算法与输出格式零改动；结果数组改 reactive + 请求序号防乱序。
- **异步 IPC 兜底（CQ-05）**：async `ipcMain.on` 回调补 try/catch 13 处（console.error + 状态栏中文提示）；handle 补日志 9 处；修正 2 处浮动 Promise。
- **同步校验**：src 全目录 `ipcRenderer.sendSync(` 零残留（新增防回归测试）。

### r3-dialogs（CQ-06 / PF-07）
- **PF-07 jsdom 惰性化**：14 个文件移除顶层 jsdom 静态导入，统一经 `dialog-defaults.ts` 缓存 getter 按需加载；`src/main` 内仅剩 1 处懒加载 getter。
- **CQ-06 样板治理**：14 个对话框迁移到 `loadDialogHtml` 公共函数；新增 4 个公共函数（getJSDOM/createJSDOM/notifyReloadDirFromDisk/getInlineDialogThemeVariables）；4 处内联主题 CSS 收敛到 `dialog-shared-css.ts`；**15/15 对话框渲染 HTML 逐字节一致（SHA-256 相同）**。
- 目录操作的 reload 定时器样板由 r3-watch 的 `ScheduleReloadFromDisk()` 统一收敛（5 处调用）。

### r3-watch（PF-05 / PF-10）
- **PF-05 目录增量监听**：`fs.watch(rootPath, { recursive: true })` 单例监听当前目录；事件 500ms 合并窗口（N 次事件只刷新 1 次）；自写抑制窗口 1.5s 防回环；整树未变则跳过 IPC；目录切换/退出清理 watcher；不支持 recursive 的平台降级为根目录监听，失败再降级为原全量模式；**与脏状态保护（FUN-06）完全兼容**。
- **PF-10 大文件流式读取**：5MB 阈值自适应；超阈值走 `createReadStream` 64KB 分块 + 流式解码（多字节字符跨块不截断）；编码探测抽取 `ProbeFileEncoding()`；IPC 仍单次传输（分块协议注释留后续）。

### r3-plantuml（PF-08）
- **本地离线渲染**：新增 `src/main/renders/plantuml-local.ts`（隐藏 BrowserWindow 加载 `resources/plantuml/index.html` teaVM 离线环境，`executeJavaScript` 取回 SVG）；窗口复用 + 串行队列 + sha1 LRU 缓存 50 + 单图 10s/窗口加载 20s 超时 + 渲染进程崩溃重建 + 主窗口关闭时销毁。
- **渲染层接入**：`hemy-editor-render.ts` 新增 `preRenderPlantumlProc`（```plantuml/```puml 围栏 + 裸 `@startuml…@enduml` 两种图块，12s 兜底 + hash LRU + 同批去重）；保留 markdown-it-plantuml 仅作资源缺失时的远程降级；DOMPurify 消毒层不变。
- **根代理接线 3 点**：`src/shared/ipc-channels.ts` 新增 `IPC.RENDER.PLANTUML_LOCAL`（两侧改为引用同一常量）；`index.ts` 在 `app.whenReady` 注册、`cleanupApp` 销毁隐藏窗口；`main-index.test.ts` 补 ipcMain mock。
- 无 GUI 环境用 jsdom+teaVM 替代验证：成功渲染 2205 字符 SVG（含节点文本），DOMPurify 消毒后 svg 元素保留。
