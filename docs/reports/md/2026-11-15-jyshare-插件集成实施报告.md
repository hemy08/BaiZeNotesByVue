# jyshare 常用工具插件集成实施报告（1.3.5）

> 日期：2026-11-15　归属版本：1.3.5　任务来源：将菜鸟工具镜像站（www.jyshare.com）前端工具区的可用能力移植为本项目插件。

## 一、任务与结论摘要

- **输入**：https://www.jyshare.com/#runoob-goto-front-end（菜鸟工具镜像站"常用工具"区，约 60 个在线工具）。
- **方法**：先由两个调研子代理逐页抓取工具源码并提炼算法（报告见 [jyshare 前端工具源码调研](2026-11-15-jyshare-前端工具源码调研.md)，原始 HTML/JS 归档于 `out/jyshare-src/`），再由三个实现子代理并行实现、主代理统一整合注册。
- **成果**：新增 18 个插件组件 / 19 个菜单项，插件工具总数 19 → **37**；全部**零第三方依赖、纯前端离线可用**；新增 **154** 个单元测试用例。

## 三、移植过程中的关键改进（相对原站）

| 项 | 原站实现 | 本项目实现 |
| --- | --- | --- |
| CMYK → RGB | else-if 链缺陷（仅第一个 >0 分量 /100） | 四分量统一 /100，往返测试容差 ±1 通过 |
| JSON 去转义 | `\/`→空格、`\\"` 还原错误 | 逐字符扫描正确还原，兼容 `\uXXXX`、未知转义原样保留 |
| 随机数/密码 | Math.random（索引 0 概率减半等分布缺陷） | crypto.getRandomValues 拒绝采样 + Fisher-Yates |
| 时间戳 | moment + moment-timezone（约 700KB） | 原生 Date 手工解析 + 日期存在性回验 |
| 正则测试 | Web Worker（需处理打包路径） | 主线程 + 匹配数/字符数防护上限 |
| 文本比对 | Mergely（LGPL，约 500KB） | 自写行级 LCS（DP），大文本保护 |
| 进制转换 | bignumber.js 依赖 | BigInt + 分数表示法（无浮点误差） |
| 计算器 | eval 拼接运算 | 双栈 + 显式 switch 运算 |

## 四、未集成项与理由（Roadmap）

- **SQL 格式化**（701）：原站为服务端 HMAC 接口实现，离线需引入 sql-formatter 前端库。
- **中国日历**（5672）：农历核心 lunar-javascript 约 344KB，且节假日依赖逐年外部数据。
- **JS/CSS/HTML 压缩**（47/51/52）：压缩需 terser 类库，解压=格式化；体积收益有限。
- **JS 混淆**（6939）、**HTML 转 JS**（846）：依赖 javascript-obfuscator / js-beautifier 大体积库。
- **汉字转拼音多音字**：已集成首读音版；词级消歧需引入 pinyin-pro。
- **在线类工具**（IP 查询 5445、汇率 7939、AI 解析 9064/9231、图片压缩 6232、加水印 6502、取色器 6210/6214、涂鸦 6900、世界/中国地图 9024/9026）：依赖在线服务或超出桌面工具收益范围。
