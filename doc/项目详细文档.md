## 1. 项目概述

### 1.1 项目简介

**白泽笔记** 是一款基于 Electron + Vue 3 + TypeScript 构建的现代化 Markdown 编辑器桌面应用程序。项目名称来源于中国古代神话中的神兽"白泽"，寓意智慧与知识的管理。

### 1.2 核心特性

#### Markdown 编辑功能
- **实时预览**: 所见即所得的编辑体验
- **语法高亮**: 支持 100+ 种编程语言
- **代码块支持**: 带语法高亮的代码块
- **表格支持**: 可视化表格编辑
- **数学公式**: KaTeX 渲染支持
- **流程图/时序图**: Mermaid 图表支持
- **PlantUML 支持**: UML 图表渲染

#### 编辑器功能
- **Monaco Editor**: VS Code 同款编辑器
- **多主题支持**: 20+ 种编辑器主题
- **快捷键支持**: 丰富的快捷键操作
- **快速访问**: Emoji、特殊符号快速插入
- **右键菜单**: 上下文菜单支持
- **查找替换**: 强大的搜索功能

#### 文件管理
- **文件树浏览**: 树形结构文件管理
- **多标签页编辑**: 同时编辑多个文件
- **文件编码检测**: 自动检测文件编码
- **多格式导入导出**: 支持 Word、HTML 等格式

#### 扩展功能
- **快速链接自定义**: 自定义快速访问链接
- **加密解密**: 文本加密解密工具
- **格式转换**: 多种格式互转
- **网络工具**: URL 编码、Base64 等
- **主题定制**: 自定义编辑器主题

#### 应用特性
- **跨平台支持**: Windows、macOS、Linux
- **自动更新**: 应用自动更新功能
- **系统托盘**: 最小化到系统托盘
- **原生菜单**: 原生应用菜单

## 2. 技术架构

### 2.1 架构模式

白泽笔记采用 **Electron 多进程架构**，遵循 Electron 的标准架构模式：

```
┌─────────────────────────────────────────────────────────┐
│                    Electron 应用                         │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  ┌──────────────────┐      ┌──────────────────┐        │
│  │   主进程 (Main)   │◄────►│  渲染进程 (Renderer) │        │
│  │                  │ IPC  │                    │        │
│  │  - 窗口管理       │      │  - Vue 3 应用      │        │
│  │  - 文件系统       │      │  - UI 组件         │        │
│  │  - 原生菜单       │      │  - Monaco 编辑器   │        │
│  │  - 对话框         │      │  - Markdown 渲染   │        │
│  │  - IPC 通信       │      │  - 用户交互        │        │
│  └──────────────────┘      └──────────────────┘        │
│           ▲                          ▲                  │
│           │                          │                  │
│           │      ┌──────────────────┐│                  │
│           └──────┤  预加载脚本       ├┘                  │
│                  │  (Preload)        │                   │
│                  │  - API 暴露       │                   │
│                  │  - 安全桥接       │                   │
│                  └──────────────────┘                   │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 2.2 进程职责

#### 2.2.1 主进程 (Main Process)

**文件位置**: `src/main/index.ts`

**主要职责**:
- 创建和管理 BrowserWindow 窗口
- 管理应用生命周期（启动、退出）
- 处理原生菜单和系统托盘
- 管理文件系统操作
- 处理对话框窗口
- 监听和处理 IPC 通信
- 管理主题配置
- 处理自动更新

**核心功能模块**:
```
src/main/
├── index.ts              # 主进程入口
├── dialogs/              # 对话框模块 (18个)
├── menu/                 # 菜单模块 (13个)
├── utils/                # 工具函数 (16个)
├── templates/            # 模板文件
├── plugins/              # 插件模块
└── model/                # 数据模型
```

#### 2.2.2 渲染进程 (Renderer Process)

**文件位置**: `src/renderer/src/main.ts`

**主要职责**:
- 运行 Vue 3 应用
- 渲染用户界面
- 管理 Monaco Editor 编辑器
- 处理 Markdown 解析和渲染
- 响应用户交互
- 发起 IPC 通信请求

**核心功能模块**:
```
src/renderer/src/
├── main.ts               # Vue 应用入口
├── App.vue               # 根组件
├── components/           # Vue 组件
│   ├── Markdown/         # Markdown 编辑器
│   ├── WorkSpaceArea/    # 工作区
│   ├── ResourceManager/  # 资源管理器
│   └── PluginTools/      # 插件工具
├── lib/                  # 第三方库
└── style/                # 样式文件
```

#### 2.2.3 预加载脚本 (Preload Script)

**文件位置**: `src/preload/index.ts`

**主要职责**:
- 使用 `contextBridge` 安全地暴露 Electron API
- 提供主进程与渲染进程的通信桥梁
- 实现安全隔离和权限控制

**暴露的 API**:
```typescript
window.electron.ipcRenderer  // IPC 通信
window.api                   // 自定义 API
```

### 2.3 数据流向

```
用户操作 → Vue 组件 → IPC 发送 → 主进程处理 → IPC 返回 → Vue 组件更新
```

**示例：文件保存流程**
```
1. 用户点击保存按钮
2. MarkdownEditComponent.vue 捕获事件
3. window.electron.ipcRenderer.send('save-file-content-to-disk', content)
4. 主进程 file.ts 接收消息
5. 主进程写入文件到磁盘
6. 主进程返回结果
7. 渲染进程更新 UI 状态
```

### 3.3 设计模式

#### 3.3.1 发布-订阅模式

用于 IPC 通信和事件处理：

```typescript
// 主进程发布事件
mainWindow.webContents.send('baize-notes:theme-updated', theme)

// 渲染进程订阅事件
window.electron.ipcRenderer.on('baize-notes:theme-updated', (event, theme) => {
  // 处理主题更新
})
```

#### 3.3.2 单例模式

用于窗口管理和配置管理：

```typescript
// 主窗口单例
let mainWindow: Electron.CrossProcessExports.BrowserWindow

function createWindow(): void {
  mainWindow = new BrowserWindow({ ... })
}
```

#### 3.3.3 工厂模式

用于对话框和菜单创建：

```typescript
// 菜单工厂
function getApplicationMenu(mainWindow: BrowserWindow): MenuItem[] {
  return [
    ...getFileMenu(mainWindow),
    ...getEditMenu(mainWindow),
    ...getViewMenu(mainWindow),
    // ...
  ]
}
```

#### 3.3.4 策略模式

用于不同渲染器的选择：

```typescript
// 根据类型选择渲染器
function render(content: string, type: string) {
  switch(type) {
    case 'mermaid':
      return MermaidRender.render(content)
    case 'katex':
      return KatexRender.render(content)
    case 'plantuml':
      return PlantumlRender.render(content)
    default:
      return HemyRender.render(content)
  }
}
```

  const detected = jschardet.detect(buffer)
  return detected.encoding
}

// 获取文件树
export async function getFileTree(dirPath: string): Promise<FileTreeNode[]> {
  const files = await fs.readdir(dirPath)
  const tree: FileTreeNode[] = []

  for (const file of files) {
    const filePath = join(dirPath, file)
    const stat = await fs.stat(filePath)

    tree.push({
      name: file,
      path: filePath,
      isDirectory: stat.isDirectory(),
      children: stat.isDirectory() ? await getFileTree(filePath) : []
    })
  }

  return tree
}

## 6. 通信机制

### 6.1 IPC 通信概述

Electron 使用 IPC (Inter-Process Communication) 实现主进程与渲染进程之间的通信。白泽笔记使用以下两种 IPC 通信方式：

1. **ipcMain.on / ipcRenderer.send**: 异步通信，不等待返回
2. **ipcMain.handle / ipcRenderer.invoke**: 异步通信，等待返回结果
3. **ipcRenderer.sendSync**: 同步通信，阻塞等待返回

### 6.2 通信矩阵

#### 6.2.1 主进程监听的 IPC 事件

| IPC 事件名称 | 触发源 | 功能说明 | 参数 |
|-------------|--------|---------|------|
| `ping` | 渲染进程 | 测试通信 | 无 |
| `baize-notes:update-theme` | 渲染进程 | 更新主题 | 无 |
| `baize-notes:set-theme` | 渲染进程 | 设置主题 | themeName |
| `baize-notes:get-quick-links` | 渲染进程 | 获取快速链接 | 无 |
| `baize-notes:save-quick-links` | 渲染进程 | 保存快速链接 | links |
| `baize-notes:reset-quick-links` | 渲染进程 | 重置快速链接 | 无 |
| `update-select-file-content` | 渲染进程 | 更新选中文件内容 | content |
| `save-file-content-to-disk` | 渲染进程 | 保存文件到磁盘 | content |
| `open-select-file` | 渲染进程 | 打开选中文件 | fileInfo |
| `pre-render-monaco-editor-content` | 渲染进程 | 预渲染编辑器内容 | content |
| `post-render-monaco-editor-content` | 渲染进程 | 后渲染编辑器内容 | content |
| `get-current-theme` | 渲染进程 | 获取当前主题 | 无 |
| `get-current-theme-styles` | 渲染进程 | 获取当前主题样式 | 无 |
| `get-all-themes` | 渲染进程 | 获取所有主题 | 无 |

### 6.4 通信最佳实践

#### 6.4.1 命名规范

白泽笔记采用统一的 IPC 事件命名规范：

```
格式: [命名空间]:[动作]

示例:
- baize-notes:update-theme    # 白泽笔记命名空间，更新主题
- baize-notes:set-theme       # 白泽笔记命名空间，设置主题
- file-manager-context-menu:create-file  # 文件管理器命名空间，创建文件
- monaco-editor-tools:insert-table  # Monaco 编辑器工具命名空间，插入表格
```

#### 6.4.2 安全考虑

1. **使用 contextIsolation**: 启用上下文隔离，防止渲染进程直接访问 Node.js API
2. **使用 contextBridge**: 通过 contextBridge 安全地暴露 API
3. **禁用 nodeIntegration**: 禁用 Node 集成，提高安全性
4. **验证 IPC 消息**: 在主进程验证 IPC 消息的合法性

```typescript
// 预加载脚本
if (process.contextIsolated) {
  contextBridge.exposeInMainWorld('electron', electronAPI)
}

// 主进程
ipcMain.on('some-event', (event, ...args) => {
  // 验证参数
  if (!validateArgs(args)) {
    console.error('Invalid arguments')
    return
  }

  // 处理事件
  // ...
})
```

### 10.1 添加新对话框

#### 10.1.1 创建对话框文件

在 `src/main/dialogs/` 目录下创建新文件:

```typescript
// src/main/dialogs/ShowMyDialog.ts
import { BrowserWindow, ipcMain } from 'electron'
import { join } from 'path'

export function ShowMyDialog(mainWindow: BrowserWindow) {
  // 创建对话框窗口
  const dialogWindow = new BrowserWindow({
    width: 600,
    height: 400,
    parent: mainWindow,
    modal: true,
    show: false,
    webPreferences: {
      preload: join(__dirname, '../preload/index.js'),
      nodeIntegration: false,
      contextIsolation: true
    }
  })

  // 加载对话框 HTML
  dialogWindow.loadFile(join(__dirname, '../../renderer/dialogs/my-dialog.html'))

  dialogWindow.once('ready-to-show', () => {
    dialogWindow.show()
  })

  // 监听对话框事件
  ipcMain.once('dialog-my-dialog-btn-confirm', (event, data) => {
    // 处理确认操作
    mainWindow.webContents.send('my-dialog-result', data)
    dialogWindow.close()
  })

  ipcMain.once('dialog-my-dialog-btn-cancel', () => {
    dialogWindow.close()
  })
}
```
