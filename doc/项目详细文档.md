## 1. 项目概述

### 1.1 项目简介

**白泽笔记** 是一款基于 Electron + Vue 3 + TypeScript 构建的现代化 Markdown 编辑器桌面应用程序。项目名称来源于中国古代神话中的神兽"白泽"，寓意智慧与知识的管理。

### 1.2 核心特性

#### Markdown 编辑功能
- **实时预览**: 所见即所得的编辑体验
- **语法高亮**: 支持 100+ 种编程语言
- **代码块支持**: 带语法高亮的代码块
- **表格支持**: 可视化表格编辑
- **数学公式**: KaTeX 渲染支持
- **流程图/时序图**: Mermaid 图表支持
- **PlantUML 支持**: UML 图表渲染

#### 编辑器功能
- **Monaco Editor**: VS Code 同款编辑器
- **多主题支持**: 18种应用主题 + 多种编辑器主题
- **快捷键支持**: 丰富的快捷键操作
- **快速访问**: Emoji、特殊符号快速插入
- **右键菜单**: 上下文菜单支持
- **查找替换**: 强大的搜索功能

#### 文件管理
- **文件树浏览**: 树形结构文件管理
- **多标签页编辑**: 同时编辑多个文件
- **文件编码检测**: 自动检测文件编码
- **多格式导入导出**: 支持 Word、HTML、JSON、YAML、XML 等格式

#### 扩展功能
- **快速链接自定义**: 自定义快速访问链接
- **加密解密**: 文本加密解密工具
- **格式转换**: 多种格式互转
- **网络工具**: URL 编码、Base64 等
- **主题定制**: 自定义编辑器主题

#### 应用特性
- **跨平台支持**: Windows、macOS、Linux
- **自动更新**: 应用自动更新功能
- **系统托盘**: 最小化到系统托盘
- **原生菜单**: 原生应用菜单

## 2. 技术架构

### 2.1 架构模式

白泽笔记采用 **Electron 多进程架构**，遵循 Electron 的标准架构模式：

```
┌─────────────────────────────────────────────────────────┐
│                    Electron 应用                         │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  ┌─────────────────────────────────────────────────┐   │
│  │              主进程 (Main Process)               │   │
│  │  - Node.js 环境                                 │   │
│  │  - 文件系统访问                                 │   │
│  │  - 原生 API 调用                                │   │
│  │  - 窗口管理                                     │   │
│  │  - 菜单管理                                     │   │
│  │  - 对话框管理                                   │   │
│  └─────────────────────────────────────────────────┘   │
│                          ↕                              │
│                    IPC 通信                              │
│                          ↕                              │
│  ┌─────────────────────────────────────────────────┐   │
│  │           预加载脚本 (Preload Script)            │   │
│  │  - Context Bridge                                │   │
│  │  - API 暴露                                      │   │
│  │  - 安全桥接                                      │   │
│  └─────────────────────────────────────────────────┘   │
│                          ↕                              │
│  ┌─────────────────────────────────────────────────┐   │
│  │            渲染进程 (Renderer Process)           │   │
│  │  - Chromium 环境                                 │   │
│  │  - Vue 3 应用                                    │   │
│  │  - Monaco Editor                                 │   │
│  │  - UI 渲染                                       │   │
│  │  - 用户交互                                      │   │
│  └─────────────────────────────────────────────────┘   │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 2.2 架构优势

#### 性能优势
- **多进程架构**: 主进程和渲染进程分离，避免 UI 阻塞
- **Chromium 渲染**: 现代化的渲染引擎，性能优异
- **Node.js 集成**: 直接访问文件系统，无需 HTTP 请求

#### 安全优势
- **Context Isolation**: 上下文隔离，防止原型污染
- **Node Integration**: 禁用 Node 集成，提高安全性
- **Preload Script**: 通过预加载脚本安全暴露 API

#### 开发优势
- **热重载**: 开发模式下支持热重载
- **TypeScript**: 类型安全，减少运行时错误
- **Vue 3**: Composition API，更好的代码组织

## 3. 软件架构

### 3.1 主进程架构

主进程是 Electron 应用的核心，负责系统级操作和原生功能。

#### 3.1.1 核心模块

**文件工具模块** (`src/main/utils/file-utils.ts`)
- 文件/文件夹的创建、打开、保存、删除
- 文件树遍历和构建
- 多格式导入（Word, HTML, JSON, YAML, XML, TXT）
- 多格式导出（Word, JSON, XML, YAML, HTML, PDF）
- 编码检测和转换
- 自动保存功能
- 文件状态持久化

**对话框管理模块** (`src/main/dialogs/`)
- 22个对话框组件
- 文件操作对话框（新建、重命名、导入选项）
- 编辑功能对话框（插入图片、数学公式、Mermaid图表）
- 设置对话框（系统设置、主题设置、快捷链接设置）
- 信息展示对话框（关于、技术栈、联系方式）

**菜单系统模块** (`src/main/menu/`)
- 应用菜单栏
- 右键上下文菜单
- IPC菜单动作处理
- 菜单项状态管理

**主题管理模块** (`src/main/themes/`)
- 18种主题配置
- CSS变量管理
- 主题切换处理
- 主题持久化

#### 3.1.2 IPC通信

主进程监听的主要IPC事件：
- `window-minimize` - 窗口最小化
- `window-maximize` - 窗口最大化
- `window-close` - 窗口关闭
- `baize-notes:update-theme` - 主题更新
- `baize-notes:menu-action` - 菜单动作
- `file-manager-*` - 文件管理操作
- `dialog-*` - 对话框操作

### 3.2 渲染进程架构

渲染进程负责UI渲染和用户交互。

#### 3.2.1 核心组件

**编辑器组件** (`src/renderer/src/components/Markdown/`)
- `MarkdownMonacoEditor.vue` - Monaco编辑器封装
- `MarkdownPreviewComponent.vue` - 预览组件
- `MarkdownContainer.vue` - 容器组件
- `hemy-editor.ts` - 编辑器核心逻辑
- `hemy-editor-quick-access.ts` - 快速访问功能

**工作区组件** (`src/renderer/src/components/WorkSpaceArea/`)
- 文件标签管理
- 编辑器实例管理
- 布局管理

**资源管理器组件** (`src/renderer/src/components/ResourceManager/`)
- 文件树展示
- 文件操作
- 搜索功能

**插件工具组件** (`src/renderer/src/components/PluginTools/`)
- 转换工具（JSON/YAML/XML/TOML互转、大小写转换等）
- 加密工具（Hash、加密/解密、RSA、Token生成等）
- 信息工具（文本统计、JSON路径查询、正则测试等）
- 网络工具（URL解析、HTTP请求、WebSocket测试等）

#### 3.2.2 状态管理

**Vuex Store配置**:
```typescript
const store = createStore({
    state: {
        header: ''
    },
    mutations: {
        setFormatHeader(state, value) {
            state.header = value
        }
    },
    actions: {
        updateFormatHeader({ commit }, value) {
            commit('setFormatHeader', value)
        }
    }
})
```

**事件总线** (`src/renderer/src/event-bus.ts`):
- 基于 Map 的事件订阅发布模式
- 支持 `$on`, `$emit`, `$off`, `$offAll` 方法
- 用于组件间通信

### 3.3 预加载脚本架构

预加载脚本作为主进程和渲染进程之间的安全桥梁。

#### 3.3.1 Context Bridge

通过 `contextBridge.exposeInMainWorld` 暴露安全的API：
- 文件系统API
- 对话框API
- 窗口控制API
- 主题管理API
- 加密工具API

## 6. 通信机制

### 6.1 IPC通信

**主进程到渲染进程**:
```typescript
// 发送消息
mainWindow.webContents.send('channel', data)

// 渲染进程接收
window.electron.ipcRenderer.on('channel', (event, data) => {
  // 处理数据
})
```

**渲染进程到主进程**:
```typescript
// 发送消息
window.electron.ipcRenderer.send('channel', data)

// 主进程接收
ipcMain.on('channel', (event, data) => {
  // 处理数据
  event.reply('reply-channel', result)
})
```

### 6.2 事件总线

**组件间通信**:
```typescript
// 订阅事件
eventBus.$on('event-name', callback)

// 触发事件
eventBus.$emit('event-name', data)

// 取消订阅
eventBus.$off('event-name')
```

### 6.3 Vuex状态管理

**状态更新**:
```typescript
// 提交mutation
store.commit('mutation-name', payload)

// 分发action
store.dispatch('action-name', payload)
```

## 7. 业务流程

### 7.1 应用启动流程

```
1. Electron 启动主进程
   ├─> 加载主进程入口文件 (src/main/index.ts)
   ├─> 初始化应用配置
   ├─> 创建主窗口
   ├─> 加载预加载脚本 (src/preload/index.ts)
   └─> 加载渲染进程 (src/renderer/src/main.ts)

2. 渲染进程初始化
   ├─> 创建 Vue 应用实例
   ├─> 注册全局组件
   ├─> 配置路由和状态管理
   ├─> 挂载根组件 (App.vue)
   └─> 初始化编辑器和文件管理器

3. 主窗口显示
   ├─> 恢复上次的文件状态
   ├─> 加载主题配置
   └─> 显示主窗口
```

### 7.2 文件编辑流程

```
1. 打开文件
   ├─> 用户选择文件
   ├─> 发送 IPC: 'file-manager-open-file'
   ├─> 主进程读取文件
   ├─> 检测文件编码
   ├─> 返回文件内容
   └─> 渲染进程加载到编辑器

2. 编辑文件
   ├─> 用户在编辑器中编辑
   ├─> 编辑器触发 change 事件
   ├─> 更新预览
   └─> 标记文件为已修改

3. 保存文件
   ├─> 用户触发保存操作
   ├─> 发送 IPC: 'file-manager-save-file'
   ├─> 主进程写入文件
   └─> 更新文件状态
```

### 7.3 主题切换流程

```
1. 用户选择主题
   ├─> 发送 IPC: 'baize-notes:update-theme'
   ├─> 主进程获取主题配置
   ├─> 生成 CSS 变量
   └─> 广播到所有窗口

2. 应用主题
   ├─> 渲染进程接收主题样式
   ├─> 更新 CSS 变量
   ├─> 更新编辑器主题
   └─> 保存主题设置
```
