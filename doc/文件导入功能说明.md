# 文件导入功能说明

## 功能概述

白泽笔记支持从多种文件格式导入内容，并将其转换为 Markdown 格式，方便用户编辑和管理。

## 支持的文件格式

### 1. Word 文档 (.doc, .docx)

**导入方式**: 文件 → 从文件导入 → 从 Word 导入

**转换说明**:
- 使用 `mammoth` 库将 Word 文档转换为 HTML
- 使用 `turndown` 库将 HTML 转换为 Markdown
- 支持基本的文本格式、标题、列表、表格等

**示例**:
```
Word 文档内容:
标题1
这是一段文字。

转换为 Markdown:
# 标题1

这是一段文字。
```

### 2. HTML 文件 (.html, .htm, .mhtml)

**导入方式**: 文件 → 从文件导入 → 从 HTML 导入

**转换说明**:
- 使用 `turndown` 库将 HTML 转换为 Markdown
- 支持标题、段落、列表、链接、图片等常见 HTML 元素

**示例**:
```
HTML 内容:
<h1>标题</h1>
<p>这是一段文字。</p>
<a href="https://example.com">链接</a>

转换为 Markdown:
# 标题

这是一段文字。

[链接](https://example.com)
```

### 3. JSON 文件 (.json)

**导入方式**: 文件 → 从文件导入 → 从 JSON 导入

**转换说明**:
- 读取 JSON 文件内容
- 格式化 JSON 字符串（美化输出）
- 使用代码块包裹：` ```json ... ``` `

**示例**:
```
JSON 内容:
{"name":"白泽笔记","version":"1.0.2"}

转换为 Markdown:
```json
{
  "name": "白泽笔记",
  "version": "1.0.2"
}
```
```

### 4. YAML 文件 (.yaml, .yml)

**导入方式**: 文件 → 从文件导入 → 从 YAML 导入

**转换说明**:
- 读取 YAML 文件内容
- 使用代码块包裹：` ```yaml ... ``` `

**示例**:
```
YAML 内容:
name: 白泽笔记
version: 1.0.2

转换为 Markdown:
```yaml
name: 白泽笔记
version: 1.0.2
```
```

### 5. XML 文件 (.xml)

**导入方式**: 文件 → 从文件导入 → 从 XML 导入

**转换说明**:
- 读取 XML 文件内容
- 使用代码块包裹：` ```xml ... ``` `

**示例**:
```
XML 内容:
<?xml version="1.0" encoding="UTF-8"?>
<note>
  <to>用户</to>
  <from>白泽笔记</from>
</note>

转换为 Markdown:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<note>
  <to>用户</to>
  <from>白泽笔记</from>
</note>
```
```

### 6. CSV 文件 (.csv)

**导入方式**: 文件 → 从文件导入 → 从 CSV 导入（通过文本文件导入）

**转换说明**:
- 读取 CSV 文件内容
- 自动检测文件编码
- 转换为 Markdown 表格格式

**示例**:
```
CSV 内容:
姓名,年龄,城市
张三,25,北京
李四,30,上海

转换为 Markdown:
| 姓名| 年龄| 城市 |
| ---| ---| --- |
| 张三 | 25 | 北京 |
| 李四 | 30 | 上海 |
```

### 7. 文本文件 (.txt, .log, .ini)

**导入方式**: 文件 → 从文件导入 → 从文本文件导入

**转换说明**:
- 读取文本文件内容
- 使用代码块包裹：` ```text ... ``` `

**示例**:
```
文本内容:
这是一段普通文本。
可以包含多行。

转换为 Markdown:
```text
这是一段普通文本。
可以包含多行。
```
```

### 8. Excel 文件 (.xls, .xlsx)

**导入方式**: 文件 → 从文件导入 → 从 Excel 导入（通过文本文件导入）

**转换说明**:
- 读取 Excel 文件内容
- 使用代码块包裹：` ```text ... ``` `
- 注意：当前仅读取文本内容，未实现表格转换

## 使用方法

### 方法一：通过菜单导入

1. 点击菜单栏的"文件"菜单
2. 选择"从文件导入"
3. 选择要导入的文件格式（如"从 Word 导入"）
4. 在文件选择对话框中选择文件
5. 文件内容将自动转换为 Markdown 并显示在编辑器中

### 方法二：通过资源管理器导入

1. 在左侧资源管理器中右键点击文件
2. 选择"导入"选项
3. 文件内容将自动转换为 Markdown 并显示在编辑器中

## 导入模式

### 1. 完全导入（Import）

- **菜单**: 文件 → 从文件导入 → 选择格式
- **行为**: 清空当前编辑器内容，导入新文件内容
- **IPC 通道**: `show-selected-file-context`

### 2. 插入导入（Insert）

- **菜单**: 编辑 → 插入 → 从文件插入 → 选择格式
- **行为**: 在当前光标位置插入导入的文件内容
- **IPC 通道**: `monaco-editor-insert-after-cursor`

### 转换函数

- `convertDocxToMarkdown`: Word 转 Markdown

## 注意事项

1. **文件编码**: 系统会自动检测文件编码，支持 UTF-8、GBK 等常见编码
2. **大文件**: 导入大文件可能需要较长时间，请耐心等待
3. **格式保留**: 转换过程可能会丢失部分格式信息，建议导入后检查并调整
4. **图片处理**: Word 和 HTML 中的图片可能无法正确导入，需要手动处理
5. **表格转换**: CSV 文件会自动转换为 Markdown 表格，但复杂表格可能需要手动调整

## 常见问题

### Q1: 导入 Word 文档时图片丢失怎么办？

A: 当前版本不支持自动导入图片。建议：
1. 手动保存图片到项目目录
2. 在 Markdown 中使用相对路径引用图片

### Q2: 导入的表格格式不正确怎么办？

A: CSV 转 Markdown 表格功能有限，建议：
1. 导入后手动调整表格格式
2. 使用 Markdown 表格语法重新编写

### Q3: 导入大文件时卡住怎么办？

A: 大文件导入需要较长时间，建议：
1. 等待导入完成
2. 如果长时间无响应，可以尝试重启应用
3. 考虑将大文件拆分为多个小文件

### Q4: 支持导入 PDF 文件吗？

A: 当前版本不支持 PDF 导入。可以考虑：
1. 将 PDF 转换为 Word 或 HTML 后导入
2. 使用 OCR 工具将 PDF 转换为文本后导入
