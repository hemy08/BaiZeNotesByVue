## 1. 菜单系统概述

### 1.1 系统简介

白泽笔记的菜单系统采用 Electron 原生菜单 API 实现，提供了完整的应用菜单栏和上下文菜单功能。菜单系统具有以下特点：

- **原生体验**: 使用 Electron 原生菜单，提供与操作系统一致的用户体验
- **模块化设计**: 每个主菜单独立模块，便于维护和扩展
- **IPC通信**: 通过 IPC 机制实现菜单动作的处理
- **快捷键支持**: 丰富的快捷键配置，提升操作效率
- **动态菜单**: 支持动态生成菜单项（如导入导出格式）

### 1.2 菜单类型

1. **应用菜单栏**: 顶部菜单栏，包含所有主要功能
2. **上下文菜单**: 右键菜单，提供上下文相关操作
3. **系统托盘菜单**: 系统托盘图标菜单

### 1.3 技术实现

- **菜单定义**: TypeScript 配置文件
- **菜单构建**: Electron Menu API
- **动作处理**: IPC 通信机制
- **快捷键**: Electron Accelerator API

### 2.3 菜单动作解析

菜单动作采用统一的命名格式：

```
baize:menu:主菜单:子菜单:动作
```

例如：
- `baize:menu:file:new:create-file` - 创建新文件
- `baize:menu:edit:undo` - 撤销操作
- `baize:menu:view:theme:switch` - 切换主题

## 5. 菜单IPC通信

### 5.1 IPC通信机制

菜单系统通过 IPC (Inter-Process Communication) 实现主进程和渲染进程之间的通信。

**通信流程**:

```
渲染进程                    主进程
    │                        │
    │  用户点击菜单          │
    │  ──────────────────>  │
    │                        │  解析菜单动作
    │                        │  执行对应处理函数
    │                        │
    │  <──────────────────  │
    │  发送IPC消息           │  发送处理结果
    │                        │
    │  更新UI                │
    │                        │
```

### 5.2 IPC事件列表

**主要IPC事件**:

| IPC事件 | 方向 | 说明 |
|---------|------|------|
| `baize-notes:menu-action` | 渲染→主 | 菜单动作触发 |
| `monaco-editor-trigger-undo-redo` | 主→渲染 | 编辑器撤销/重做 |
| `plugin-tools-show` | 主→渲染 | 显示插件工具 |
| `convert-to-encoding` | 主→渲染 | 转换文件编码 |
| `OpenFile` | 主→渲染 | 打开文件 |

### 5.3 菜单动作处理器

**处理器注册** (`src/main/menu/menu_ipc.ts`):

```typescript
const menuHandlers = {
    file: {
        new: {
            'create-file': (mainWindow) => {
                dialogs.ShowNewFileFolderDialog(mainWindow, 'file')
            },
            'create-folder': (mainWindow) => {
                dialogs.ShowNewFileFolderDialog(mainWindow, 'folder')
            }
        },
        open: {
            'open-file': (mainWindow) => {
                fileUtils.OpenFileDialog(mainWindow)
            },
            'open-folder': (mainWindow) => {
                fileUtils.OpenFolderDialog(mainWindow)
            }
        },
        save: {
            'save-file': (mainWindow) => {
                fileUtils.SaveActiveFile()
            },
            'save-as': (mainWindow) => {
                fileUtils.SaveActiveFileAs()
            }
        }
    },
    edit: {
        undo: (mainWindow) => {
            mainWindow.webContents.send('monaco-editor-trigger-undo-redo', 'undo')
        },
        redo: (mainWindow) => {
            mainWindow.webContents.send('monaco-editor-trigger-undo-redo', 'redo')
        }
    },
    // ... 更多处理器
}
```

### 7.2 添加新主菜单

**步骤**:

1. 创建新的菜单模块文件（如 `newmenu.ts`）
2. 实现菜单构建函数
3. 在主进程中导入并添加到菜单栏
4. 注册菜单动作处理器

**示例**:

```typescript

export function getAppNewMenuItem(
    mainWindow: Electron.BrowserWindow
): Electron.MenuItemConstructorOptions {
    const newMenuItems: Electron.MenuItemConstructorOptions[] = [
        {
            label: '菜单项1',
            click: () => {
                // 处理逻辑
            }
        },
        // ... 更多菜单项
    ]
    
    return {
        label: '新菜单(N)',
        enabled: true,
        accelerator: 'alt+n',
        submenu: newMenuItems
    }
}

// 2. 在主进程中导入
import { getAppNewMenuItem } from './menu/newmenu'

// 3. 添加到菜单栏
const menuTemplate = [
    getAppFileMenuItem(mainWindow),
    getAppEditMenuItem(mainWindow),
    // ... 其他菜单
    getAppNewMenuItem(mainWindow)  // 添加新菜单
]
```

## 8. 最佳实践

### 8.1 菜单设计原则

1. **一致性**: 菜单结构和命名应与操作系统惯例一致
2. **可发现性**: 常用功能应放在显眼位置
3. **分组**: 使用分隔符对相关菜单项进行分组
4. **快捷键**: 为常用操作提供快捷键
5. **禁用状态**: 不适用的菜单项应禁用而非隐藏

### 8.2 性能优化

1. **延迟加载**: 复杂菜单项延迟初始化
2. **缓存**: 缓存菜单构建结果
3. **最小化IPC**: 减少不必要的IPC通信

### 8.3 可访问性

1. **快捷键提示**: 在菜单项中显示快捷键
2. **菜单访问键**: 提供Alt+字母的菜单访问方式
3. **清晰的标签**: 使用清晰、简洁的菜单项标签

### 8.4 国际化支持

菜单系统支持国际化，可以通过以下方式实现：

```typescript
// 使用i18n库
{
    label: i18n.t('menu.file.new'),
    accelerator: 'ctrl+n',

        // 处理逻辑
    }
}
```
