## 1. 项目概述

### 1.1 项目简介

白泽笔记（BaiZeNotes）是一款基于 Electron + Vue 3 + TypeScript 构建的现代化 Markdown 桌面编辑器。项目名称取自中国古代神话中的神兽"白泽"，寓意博学多识、通晓万物。

| 项目属性 | 值 |
|---------|-----|
| **项目名称** | 白泽笔记 (BaiZe Notes) |
| **版本** | 1.1.3-bate |
| **项目类型** | Electron 桌面应用程序 - Markdown 编辑器 |
| **开发语言** | TypeScript + Vue 3 |
| **作者** | hemy08 (zhaojunwei008@yeah.net) |
| **仓库** | https://github.com/hemy08/BaiZeNotesByVue.git |
| **首次提交** | 2024-05-27 |
| **最近提交** | 2026-04-12 |
| **总提交数** | 170 |
| **发布标签** | release-1.0.1, 1.0.2, 1.1.0, 1.1.1, 1.1.2 |

### 1.2 核心特性

- **强大的编辑器**: 基于 Monaco Editor（VS Code 同款），支持实时预览、语法高亮、自动补全
- **丰富的主题**: 20种应用主题（18浅色 + 2深色）+ 55种 Monaco 编辑器主题
- **多格式支持**: 支持7种格式导入、6种格式导出
- **图表渲染**: Mermaid 和 PlantUML，支持40+种图表类型
- **数学公式**: KaTeX 数学公式渲染
- **实用工具**: 43个插件工具，涵盖加密、转换、信息、网络等
- **模板系统**: 丰富的 Mermaid、PlantUML 和写作模板
- **编辑器设置**: 59个配置项，13个分类，完善的持久化机制
- **自动保存**: 可配置间隔的自动保存功能
- **文件状态恢复**: 关闭时保存工作状态，重新打开自动恢复
- **自动更新**: 集成 electron-updater，支持应用自动更新

## 4. 核心功能详解

### 4.1 Monaco 编辑器集成

基于 VS Code 同款 Monaco Editor，提供专业级编辑体验：

- **语法高亮**: 支持 50+ 种编程语言
- **自动补全**: Markdown 语法自动补全
- **代码折叠**: 标题和代码块折叠
- **多光标编辑**: 支持多光标同时编辑
- **查找替换**: 支持正则表达式查找替换
- **迷你地图**: 代码缩略图导航
- **59个配置项**: 分13个类别，支持持久化存储

### 4.2 Markdown 预览

- **实时预览**: 编辑时同步渲染预览
- **三套引擎**: markdown-it（主）、marked（备）、remarkable（辅）
- **图表支持**: Mermaid 流程图、PlantUML UML图
- **数学公式**: KaTeX 渲染 LaTeX 公式
- **代码高亮**: highlight.js 语法高亮
- **Emoji**: markdown-it-emoji 表情支持
- **锚点**: markdown-it-anchor 标题锚点

### 4.3 文件管理

- **多格式导入**: Word(.docx)、HTML、CSV、纯文本等7种格式
- **多格式导出**: Word、HTML、PDF、纯文本等6种格式
- **文件树**: 侧边栏文件树导航
- **自动保存**: 可配置间隔（默认30秒）
- **状态恢复**: 关闭时保存工作状态，重新打开自动恢复
- **文件加密**: AES、DES、3DES、RSA 等加密方式
- **编码检测**: 自动检测文件编码

### 4.4 窗口管理

- **无边框窗口**: 自定义标题栏，支持拖动
- **窗口调整**: 支持拖拽调整窗口大小
- **最大化/最小化**: 双击标题栏切换最大化
- **多窗口**: 支持多窗口操作
- **状态栏**: 显示文件状态、编码、光标位置等信息

## 8. 通信机制

### 8.1 IPC 通信架构

```
渲染进程 (Vue 3)                    主进程 (Electron)
    │                                    │
    ├── ipcRenderer.send() ──────────────>── ipcMain.on()
    │   'baize-notes:menu-action'        │   HandleBaiZeMenuAction()
    │                                    │
    ├── ipcRenderer.invoke() ────────────>── ipcMain.handle()
    │   'baize-notes:load-monaco-theme'  │   getMonacoThemeData()
    │                                    │
    <── webContents.send() ──────────────┤   BrowserWindow.getAllWindows()
        'baize-notes:theme-updated'      │   getCurrentThemeStyles()
```

### 8.2 主要 IPC 通道

| 通道 | 方向 | 说明 |
|------|------|------|
| `baize-notes:menu-action` | 渲染→主 | 菜单动作处理 |
| `baize-notes:update-theme` | 渲染→主 | 请求主题更新 |
| `baize-notes:theme-updated` | 主→渲染 | 主题更新通知 |
| `baize-notes:load-monaco-theme` | 渲染⇄主 | 加载 Monaco 主题 |
| `window-toggle-maximize` | 渲染→主 | 切换最大化 |
| `window-is-maximized` | 渲染→主 | 查询最大化状态 |
| `window-minimize` | 渲染→主 | 最小化窗口 |
| `window-close` | 渲染→主 | 关闭窗口 |
| `window-resize` | 渲染→主 | 调整窗口大小 |

## 12. 总结与展望

### 12.1 项目现状

白泽笔记是一个功能完善、架构清晰、技术先进的现代化 Markdown 桌面编辑器。项目采用 Electron 多进程架构，结合 Vue 3 响应式框架和 TypeScript 类型安全，实现了专业的编辑体验、丰富的功能特性和良好的用户体验。

### 12.2 项目亮点

1. **VS Code 同款编辑器** - Monaco Editor 提供专业级编辑体验
2. **双主题系统** - 应用主题和编辑器主题独立设置，75种主题可选
3. **丰富的工具集** - 43个实用工具即开即用，无需配置
4. **多格式支持** - 7种导入 + 6种导出格式
5. **强大的图表** - Mermaid + PlantUML + KaTeX 三引擎
6. **优秀的架构** - 三进程 + 类型安全 + 模块化
7. **完善的配置** - 59个编辑器配置项 + 持久化存储
8. **自动保存与恢复** - 防止数据丢失，工作状态自动恢复
