# 白泽笔记 - 配置文件路径优化说明

## 修改日期
2026-05-01

## 修改目的
1. 修复 win-unpacked 目录下 resources\resources 重复问题
2. 实现用户目录 .baizenotes 配置文件存储
3. 优化资源文件打包结构
4. 实现卸载时问询用户是否保留配置文件

## 修改内容

### 1. electron-builder.yml 配置优化

**修改前问题**:
- extraResources 配置导致 resources 目录嵌套
- 打包后路径: `win-unpacked/resources/resources/...`

**修改后方案**:
```yaml
extraResources:
  - from: "resources/config"
    to: "config"
  - from: "resources/icon"
    to: "icon"
  - from: "resources/katex"
    to: "katex"
  - from: "resources/themes"
    to: "themes"
  - from: "resources/mermaid"
    to: "mermaid"
  - from: "resources/plantuml"
    to: "plantuml"
```

**效果**:
- 打包后路径: `win-unpacked/config/...`
- 资源文件与 resources.asar 同级

### 2. 用户配置目录实现

**新增文件**: `src/main/utils/app-paths.ts`

**功能**:
- 在用户目录创建 `.baizenotes` 目录
- 统一管理应用各种路径
- 支持开发和生产环境路径切换

**目录结构**:
```
C:\Users\用户\.baizenotes\
├── config\          # 配置文件
│   ├── baize-config.json
│   ├── theme-config.json
│   ├── systemSetting.json
│   └── editor-setting.json
├── cache\           # 缓存文件
└── logs\            # 日志文件
```

**API**:
```typescript
getUserDataPath()      // 获取用户数据目录
getAppResourcesPath()  // 获取应用资源目录
getConfigPath()        // 获取配置文件路径
getIconPath()          // 获取图标文件路径
getThemesPath()        // 获取主题文件路径
initUserDataDirectory() // 初始化用户数据目录
```

```
C:\Program Files\BaiZeNotes\
├── BaiZeNotes.exe          # 主程序
├── resources.asar          # 应用资源（打包）
├── config\                 # 配置文件（不打包）
├── icon\                   # 图标文件
├── themes\                 # 主题文件
├── katex\                  # KaTeX 资源
```

## 开发环境 vs 生产环境

### 开发环境
- 资源文件路径: `项目目录/resources/...`
- 配置文件路径: `C:\Users\用户\.baizenotes\...`

### 生产环境
- 资源文件路径: `安装目录/...` (与 resources.asar 同级)
- 配置文件路径: `C:\Users\用户\.baizenotes\...`

## 测试建议

1. **开发环境测试**:
   ```bash
   npm run dev
   ```
   - 检查用户目录是否创建 `.baizenotes`
   - 检查配置文件是否正确保存

2. **打包测试**:
   ```bash
   npm run build:win
   ```
   - 检查 win-unpacked 目录结构
   - 确认没有 resources\resources 重复
   - 确认资源文件在正确位置

3. **安装测试**:
   - 安装应用
   - 修改配置
   - 卸载应用，选择保留配置
   - 重新安装，检查配置是否保留

4. **卸载测试**:
   - 卸载应用
   - 选择删除配置
   - 检查用户目录是否清理

## 注意事项

1. **首次运行**:
   - 自动创建用户配置目录
   - 使用默认配置

2. **配置迁移**:
   - 如果需要从旧版本迁移配置，需要手动处理
   - 旧配置位置: `%APPDATA%/baize-notes/...`
   - 新配置位置: `C:\Users\用户\.baizenotes/...`

3. **权限问题**:
   - 用户目录通常有写入权限
   - 如果权限不足，会提示错误

4. **多用户支持**:
   - 每个用户有独立的配置目录
   - 配置互不影响
