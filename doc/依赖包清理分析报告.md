## 二、重复依赖识别

### 2.1 Markdown解析库重复 🔴

**问题**：同时使用4个Markdown解析库，功能重复

| 库名 | 版本 | 用途 | 建议 |
|------|------|------|------|
| `markdown-it` | 14.1.0 | Markdown解析器 | ✅ **保留** - 主解析器 |
| `marked` | 12.0.2 | Markdown解析器 | ❌ **移除** - 功能重复 |
| `remarkable` | 2.0.1 | Markdown解析器 | ❌ **移除** - 功能重复 |
| `commonmark` | 0.31.0 | Markdown解析器 | ❌ **移除** - 功能重复 |

**理由**：
- `markdown-it` 是最活跃维护的库，插件生态最丰富
- 已有`markdown-it-anchor`、`markdown-it-emoji`等插件
- 其他三个库功能完全重复，增加包体积

### 2.2 代码高亮库重复 🔴

**问题**：同时使用2个代码高亮库

| 库名 | 版本 | 用途 | 建议 |
|------|------|------|------|
| `highlight.js` | 11.9.0 | 代码高亮 | ✅ **保留** - 主高亮库 |
| `prismjs` | 1.29.0 | 代码高亮 | ❌ **移除** - 功能重复 |

**理由**：
- `highlight.js` 支持更多语言，自动语言检测更好
- 已有`markdown-it-highlightjs`插件集成
- `prismjs`需要手动引入语言，使用复杂

### 2.3 Monaco Editor插件重复 🔴

| `monaco-editor-esm-webpack-plugin` | 2.1.0 | Webpack插件 | ❌ **移除** - 不使用Webpack |
| `monaco-editor-nls` | 3.1.0 | 国际化 | ❌ **移除** - 未使用 |

## 六、执行建议

### 6.1 立即移除（安全）

```bash
npm uninstall marked remarkable commonmark prismjs
npm uninstall monaco-editor-webpack-plugin monaco-editor-esm-webpack-plugin monaco-editor-nls
npm uninstall md-it-mermaid markdown-it-prism
npm uninstall psl punycode querystringify requires-port tough-cookie url-parse universalify renderer
```

### 6.2 验证后移除

```bash
# 先搜索使用情况
grep -r "markdown-it-textual-uml" src/
grep -r "markdown-it-mermaid" src/

# 确认无使用后移除
npm uninstall markdown-it-textual-uml
```

### 6.3 开发依赖清理

```bash
npm uninstall markdown-it-mermaid markdown-it-mermaid-less markdown-it-mermaid-plugin markdown-it-textual-uml --save-dev
```
