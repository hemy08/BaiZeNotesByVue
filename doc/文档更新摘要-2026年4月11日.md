### 2. 配置持久化

**存储方式**:
- 使用 electron-store 进行本地持久化
- 配置文件位置：`%APPDATA%/baize-notes/config.json`
- 存储键名：`editorSetting`

**相关函数**:
```typescript
getEditorSetting(): EditorSetting      // 获取配置
saveEditorSetting(setting): void       // 保存配置
resetEditorSetting(): void             // 重置配置
getDefaultEditorSetting(): EditorSetting // 获取默认配置
```

### 3. IPC通信机制

**主进程发送**:
| 信号 | 说明 |
|------|------|
| `baize-notes:init-editor-setting` | 初始化编辑器配置 |
| `baize-notes:editor-setting-updated` | 编辑器配置更新通知 |

**渲染进程发送**:
| 信号 | 说明 |
|------|------|
| `dialog-editor-setting-apply` | 应用配置 |
| `dialog-editor-setting-ok` | 确定保存配置 |
| `dialog-editor-setting-cancel` | 取消配置 |
| `dialog-editor-setting-reset` | 重置配置 |

### 4. 按钮功能

| 按钮 | 功能 | IPC信号 |
|------|------|---------|
| 重置默认 | 恢复默认配置 | `dialog-editor-setting-reset` |
| 取消 | 放弃修改，关闭对话框 | `dialog-editor-setting-cancel` |
| 应用 | 保存配置，保持对话框打开 | `dialog-editor-setting-apply` |
| 确定 | 保存配置，关闭对话框 | `dialog-editor-setting-ok` |

## 五、Bug修复

### 1. IPC通信修复

**问题描述**:
- `get-current-theme` 使用 `ipcMain.on` 而非 `ipcMain.handle`
- `get-current-theme-styles` 同样存在问题

**修复方案**:
```typescript
// 修复前
ipcMain.on('get-current-theme', (event) => {
    event.returnValue = currentTheme
})

// 修复后
ipcMain.handle('get-current-theme', () => {
    return currentTheme
})
```

**影响范围**:
- 编辑器设置对话框的主题信息获取
- 主题样式预览功能

### 2. 系统设置信号修复
