# 白泽笔记 - 产品规格文档

## 1. 产品概述

### 1.1 产品简介
白泽笔记是一款基于Electron和Vue 3构建的跨平台桌面Markdown编辑器，旨在为用户提供强大、灵活的文档编辑和管理体验。产品名称来源于中国古代神话中的神兽"白泽"，寓意智慧与知识的汇聚。

### 1.2 产品定位
- **目标用户**: 开发者、技术写作者、学生、研究人员
- **核心价值**: 提供专业的Markdown编辑体验，支持丰富的图表绘制和文档管理功能
- **竞争优势**: 集成Monaco编辑器、支持多种图表语法、丰富的模板系统、强大的插件工具

### 1.3 版本信息
- **当前版本**: v1.1.5-beta
- **发布日期**: 2026-04-30
- **支持平台**: Windows、macOS、Linux

### 1.4 技术栈
- **核心框架**: Electron 38.0.0 + Vue 3.4.27
- **开发语言**: TypeScript 6.0.2
- **核心编辑器**: Monaco Editor 0.55.0
- **项目规模**: 135个源代码文件，61个Vue组件，约50,000+行代码

## 3. 技术规格

### 3.1 系统架构

#### 3.1.1 技术栈
```
前端框架: Vue 3.4.27 + TypeScript 6.0.2
桌面框架: Electron 38.0.0
编辑器: Monaco Editor 0.55.0
状态管理: Pinia
路由管理: Vue Router
构建工具: Vite
```

#### 3.1.2 架构设计
- **主进程**: Electron主进程负责文件系统、窗口管理
- **渲染进程**: Vue应用运行在渲染进程
- **IPC通信**: 主进程与渲染进程通过IPC通信
- **模块化**: 清晰的模块划分和组件设计

### 3.2 性能优化

#### 3.2.1 缓存机制
- **LRU缓存**: 最近最少使用缓存策略
- **文件缓存**: 文件内容缓存
- **主题缓存**: 主题配置缓存

#### 3.2.2 渲染优化
- **并行渲染**: 支持并行渲染提升性能
- **虚拟滚动**: 大文件虚拟滚动
- **懒加载**: 组件和模块懒加载

#### 3.2.3 内存管理
- **内存监控**: 实时监控内存使用
- **垃圾回收**: 及时释放不用的资源
- **内存限制**: 设置内存使用上限

### 3.3 打包发布

#### 3.3.1 支持平台
- **Windows**: Windows 10/11
- **macOS**: macOS 10.15+
- **Linux**: 主流Linux发行版

#### 3.3.2 打包格式
- **Windows**: NSIS安装包 + Portable便携版
- **macOS**: DMG安装包
- **Linux**: AppImage、deb、snap
