## 功能概述

编辑器设置功能允许用户通过图形界面配置Monaco编辑器的各项参数，包括基础配置、显示配置、性能配置等。共支持**59个配置项**，分为**13个类别**。

## 配置项关联关系

### 1. 字体配置组
- `fontFamily`、`fontSize`、`fontWeight`、`fontLigatures`、`lineHeight`、`letterSpacing`
- 这些配置共同决定文本的显示外观

### 2. 折叠配置组
- `folding` 为 false 时，其他折叠配置不生效
- `foldingStrategy` 决定折叠的计算方式
- `showFoldingControls` 决定折叠控件的显示时机

### 3. 光标配置组
- `cursorStyle` 为 'block' 时，`cursorWidth` 不生效
- `cursorBlinking` 为 'solid' 时，光标不闪烁
- `cursorSmoothCaretAnimation` 需要配合 `cursorBlinking` 使用

### 4. 指南配置组
- `guides.indentation` 控制缩进指南显示
- `guides.bracketPairs` 控制括号对指南显示
- `guides.highlightActiveIndentation` 需要配合 `guides.indentation` 使用

### 5. 性能配置组
- `largeFileOptimizations` 为 true 时，会禁用某些功能以提升性能
- `maxTokenizationLineLength` 影响语法高亮的处理

## 配置持久化

### 存储方式
- 使用 **electron-store** 进行本地持久化存储
- 配置文件位置：`%APPDATA%/baize-notes/config.json`
- 存储键名：`editorSetting`

### 存储时机
1. **初始化加载**：应用启动时自动加载已保存的配置
2. **应用按钮**：点击"应用"按钮时保存配置
3. **确定按钮**：点击"确定"按钮时保存配置并关闭对话框
4. **重置按钮**：点击"重置默认"按钮时恢复默认配置

### 相关函数
```typescript
// 获取编辑器设置
function getEditorSetting(): EditorSetting

// 保存编辑器设置
function saveEditorSetting(setting: EditorSetting): void

// 重置为默认设置
function resetEditorSetting(): void

// 获取默认设置
function getDefaultEditorSetting(): EditorSetting
```

## 按钮功能说明

### 重置默认
- 功能：将所有配置项恢复为默认值
- 实现：调用 `resetEditorSetting()` 函数
- 效果：立即更新编辑器显示

### 取消
- 功能：放弃当前修改，关闭对话框
- 实现：发送 `dialog-editor-setting-cancel` 信号
- 效果：不保存任何修改

### 应用
- 功能：保存当前配置，保持对话框打开
- 实现：发送 `dialog-editor-setting-apply` 信号
- 效果：配置立即生效，编辑器更新显示

### 确定
- 功能：保存当前配置，关闭对话框
- 实现：发送 `dialog-editor-setting-ok` 信号
- 效果：配置保存并生效，对话框关闭

## 特殊配置项处理

### minimap（缩略图）
- 类型：boolean
- 实际传递给Monaco：`{ enabled: boolean }`
- 转换原因：Monaco的minimap配置为对象类型

### rulers（标尺线）
- 当前版本未启用
- 计划在后续版本中添加

### guides（指南）
- 类型：嵌套对象
- 包含三个子配置项
- 需要整体传递给Monaco

## 性能优化建议

### 大文件编辑
- 启用 `largeFileOptimizations: true`
- 禁用 `minimap: false`
- 设置 `renderWhitespace: 'none'`
- 降低 `maxTokenizationLineLength`

### 性能优先配置
- 禁用 `smoothScrolling: false`
- 设置 `cursorBlinking: 'solid'`
- 设置 `cursorSmoothCaretAnimation: 'off'`
- 禁用 `folding: false`

### 视觉优先配置
- 启用 `smoothScrolling: true`
- 设置 `cursorBlinking: 'smooth'`
- 设置 `cursorSmoothCaretAnimation: 'on'`
- 启用 `renderLineHighlight: 'all'`

---

## 注意事项

1. **配置保存**：配置会自动保存到本地，应用重启后保持
2. **立即生效**：大部分配置修改后立即生效，无需重启
3. **字体要求**：自定义字体需要系统已安装
4. **性能影响**：某些配置会影响编辑器性能，请根据需要调整
5. **嵌套配置**：guides、bracketPairColorization、unicodeHighlight、stickyScroll 为嵌套对象

## 配置项值说明

### wordWrap (自动换行)
- **on**: 自动换行
- **off**: 不换行
- **bounded**: 在视口边界换行

### lineNumbers (行号)
- **on**: 显示绝对行号
- **off**: 隐藏行号
- **relative**: 显示相对行号
- **interval**: 间隔显示行号

### renderWhitespace (空白字符)
- **none**: 不显示
- **boundary**: 仅显示边界空白
- **selection**: 选中时显示
- **all**: 显示所有空白字符

### cursorBlinking (光标闪烁)
- **blink**: 标准闪烁
- **smooth**: 平滑闪烁
- **phase**: 相位闪烁
- **expand**: 扩展闪烁
- **solid**: 实心光标（不闪烁）

### cursorStyle (光标样式)
- **line**: 竖线
- **block**: 块状
- **underline**: 下划线
- **line-thin**: 细竖线
- **block-outline**: 块状轮廓
- **underline-thin**: 细下划线

### autoClosingBrackets/Quotes (自动闭合)
- **always**: 总是自动闭合
- **languageDefined**: 根据语言定义
- **beforeWhitespace**: 仅在空白前
- **never**: 从不自动闭合
