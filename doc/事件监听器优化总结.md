# 事件监听器泄漏风险优化总结

> 优化时间：2026年4月30日  
> 优化范围：EventBus、IPC监听器、Vue组合式API

---

## 一、问题分析

### 1.1 原有问题

**EventBus问题**：
- 虽然已有`$cleanup`和`componentId`机制，但清理效率不高
- 组件销毁时需要手动调用`$cleanup`，容易遗漏
- 缺少内存泄漏检测工具

**IPC监听器问题**：
- 已有`IPCListenerManager`管理器，实现较好
- 但部分代码未使用管理器，直接使用`ipcMain.on`

**Vue组件问题**：
- 大量组件手动管理监听器，代码冗余
- 容易忘记在`onUnmounted`中清理

### 1.2 影响范围

通过代码分析发现：
- EventBus使用点：**50+处**
- IPC监听器注册点：**50+处**
- 需要优化的组件：**20+个**

## 二、优化方案

### 2.1 EventBus优化

#### 优化前

```typescript
class EventBus {
    private callbacks: Map<string, Set<EventListener>> = new Map()
    
    $cleanup(componentId: string): void {
        // 遍历所有事件，查找并删除监听器
        this.callbacks.forEach((listeners, eventName) => {
            // O(n) 复杂度
        })
    }
}
```

#### 优化后

```typescript
class EventBus {
    private callbacks: Map<string, Set<EventListener>> = new Map()
    // 新增：组件监听器映射
    private componentListeners: Map<string, Set<{ eventName: string; listener: EventListener }>> = new Map()
    
    $cleanup(componentId: string): void {
        // 直接从映射中获取，O(1) 复杂度
        const componentSet = this.componentListeners.get(componentId)
        if (!componentSet) return
        
        componentSet.forEach(({ eventName, listener }) => {
            // 快速删除
        })
    }
    
    // 新增：内存泄漏检测
    $checkLeaks(): { hasLeaks: boolean; warnings: string[] } {
        // 检测潜在泄漏
    }
}
```

**优化效果**：
- ✅ 清理速度从O(n)提升到O(1)
- ✅ 添加内存泄漏检测功能
- ✅ 增强统计信息，包含组件详情

### 2.2 Vue组合式API封装

创建`useEventBus`组合式函数，实现自动清理：

```typescript
export function useEventBus() {
    const instance = getCurrentInstance()
    const componentId = instance?.uid?.toString() || `anonymous-${Date.now()}`
    
    // 关键：组件卸载时自动清理
    onUnmounted(() => {
        EventBus.$cleanup(componentId)
    })
    
    const on = (eventName: string, callback: Function) => {
        EventBus.$on(eventName, callback, { componentId })
    }
    
    return { on, once, emit, off }
}
```

**使用对比**：

```typescript
// ❌ 旧代码 - 需要手动清理
import EventBus from '@/event-bus'

onMounted(() => {
    EventBus.$on('event', handler)
})

onUnmounted(() => {
    EventBus.$off('event', handler) // 容易忘记
})

// ✅ 新代码 - 自动清理
import { useEventBus } from '@/composables/useEventBus'

const { on } = useEventBus()
on('event', handler) // 自动清理，无需担心
```

## 四、使用指南

### 4.1 基本使用

```typescript
import { defineComponent } from 'vue'
import { useEventBus } from '@/composables/useEventBus'

export default defineComponent({
  setup() {
    const { on, once, emit } = useEventBus()
    
    // 注册监听器（自动清理）
    on('event-name', (data) => {
      console.log(data)
    })
    
    // 触发事件
    emit('my-event', { message: 'hello' })
  }
})
```

### 4.2 调试工具

```typescript
import { useEventBusStats } from '@/composables/useEventBus'

const { getStats, checkLeaks } = useEventBusStats()

// 获取统计信息
const stats = getStats()
console.log('Total listeners:', stats.totalListeners)

// 检查内存泄漏
const leaks = checkLeaks()
if (leaks.hasLeaks) {
  console.warn('Leaks:', leaks.warnings)
}
```

### 4.3 迁移步骤

1. **识别需要迁移的组件**：查找使用`EventBus.$on`的组件
2. **替换导入**：从`import EventBus`改为`import { useEventBus }`
3. **修改注册方式**：使用`const { on } = useEventBus()`
4. **移除手动清理**：删除`onUnmounted`中的`EventBus.$off`
5. **测试验证**：确保功能正常
