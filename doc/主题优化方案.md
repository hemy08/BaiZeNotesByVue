## 1. 问题分析

### 1.1 当前主题机制的问题

**原始实现方式**:
- 所有主题配置硬编码在 `src/main/utils/theme-config.ts` 文件中
- 每次调用 `getCurrentThemeStyles()` 都需要从内存中的对象读取
- 虽然已经是内存读取，但代码结构不够清晰，维护困难
- 添加新主题需要修改代码文件，不够灵活

**性能问题**:
- ❌ 主题配置占用大量代码空间（约600行代码）
- ❌ 每次打开对话框都需要重新获取主题样式
- ❌ 没有独立的主题文件管理，不利于维护
- ❌ 无法动态加载主题，所有主题都在内存中

### 1.2 优化目标

1. **性能优化**: 减少加载窗口时的延时
2. **代码优化**: 提高代码可维护性和可扩展性
3. **功能优化**: 支持主题文件化管理
4. **架构优化**: 实现主题缓存机制

### 2.2 核心优化策略

#### 2.2.1 主题缓存机制

**实现方式**:
```typescript
// 主题缓存 - 避免重复读取文件
const themeCache = new Map<ThemeType, ThemeStyles>()

// 主题目录路径 - 作为全局变量存储
let THEME_DIR_PATH: string = ''
```

**优势**:
- ✅ 应用启动时一次性加载所有主题到内存
- ✅ 后续访问主题时直接从缓存读取，无需文件I/O操作
- ✅ 主题目录路径作为全局变量，避免重复计算

#### 2.2.2 预加载机制

**实现方式**:
```typescript
/**
 * 初始化主题管理器
 * 在应用启动时调用一次，预加载所有主题到缓存
 */
export function initializeThemeManager(): void {
    // 设置主题目录路径
    THEME_DIR_PATH = path.join(__dirname, '../../config/theme')

    // 预加载所有主题到缓存
    preloadAllThemes()
}
```

**调用时机**:
```typescript
// 在 src/main/index.ts 中
app.whenReady().then(() => {
    // 初始化主题管理器 - 在应用启动时预加载所有主题
    initializeThemeManager()

    // ... 其他初始化代码
})
```

#### 2.2.3 懒加载机制

**实现方式**:
```typescript
/**
 * 获取当前主题样式
 * 从缓存中读取，避免文件I/O操作
 */
export function getCurrentThemeStyles(): ThemeStyles {
    const themeType = getCurrentTheme()

    // 从缓存中获取
    let themeStyles = themeCache.get(themeType)

    // 如果缓存中没有，尝试加载
    if (!themeStyles) {
        themeStyles = loadThemeToCache(themeType)
    }

    // 如果还是没有，返回默认主题
    if (!themeStyles) {
        console.warn(`Theme ${themeType} not found, using default theme`)
        themeStyles = themeCache.get('baize')!
    }

    return themeStyles!
}
```

**优势**:
- ✅ 优先从缓存读取
- ✅ 缓存未命中时才加载文件
- ✅ 加载失败时返回默认主题，保证应用稳定性

```typescript
// src/main/utils/theme-config.ts
function preloadAllThemes(): void {
    try {
        const themeFiles = fs.readdirSync(THEME_DIR_PATH)

        themeFiles.forEach(file => {
            if (file.endsWith('.json')) {
                const themeId = file.replace('.json', '') as ThemeType
                loadThemeToCache(themeId)
            }
        })
    } catch (error) {
        console.error('Failed to preload themes:', error)
    }
}
```
