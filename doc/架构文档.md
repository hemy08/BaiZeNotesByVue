# 白泽笔记 - 架构文档

## 1. 架构概述

### 1.1 系统架构定义
白泽笔记采用Electron多进程架构，结合Vue 3响应式框架，构建了一个现代化的桌面Markdown编辑器应用。系统架构遵循关注点分离原则，将应用分为三个主要层次：主进程层、渲染进程层和预加载脚本层。

### 1.2 架构目标
- **高性能**: 利用Electron的多进程特性，确保UI响应和数据处理的性能
- **可扩展**: 模块化设计，支持插件和模板扩展
- **可维护**: 清晰的架构分层，便于理解和维护
- **安全性**: 通过预加载脚本和上下文隔离，确保应用安全
- **跨平台**: 基于Electron，实现一次开发，多平台运行

### 1.3 架构原则
- **单一职责原则**: 每个模块专注于单一功能
- **开闭原则**: 对扩展开放，对修改关闭
- **依赖倒置原则**: 依赖抽象而非具体实现
- **接口隔离原则**: 使用小而专一的接口
- **最少知识原则**: 模块间最小化依赖

#### 2.2.3 预加载脚本 (Preload)
**职责**:
- 提供安全的API桥接
- 实现上下文隔离
- 暴露有限的Node.js功能

**实现**:
```javascript
// 预加载脚本示例
const { contextBridge, ipcRenderer } = require('electron')

contextBridge.exposeInMainWorld('electron', {
  ipcRenderer: {
    send: (channel, data) => ipcRenderer.send(channel, data),
    on: (channel, func) => ipcRenderer.on(channel, func)
  }
})
```

## 9. 架构决策记录

### 9.1 关键架构决策

#### ADR-001: 选择Electron作为桌面框架
**状态**: 已采纳
**背景**: 需要开发跨平台桌面应用
**决策**: 使用Electron框架
**理由**:
- 跨平台支持 (Windows, macOS, Linux)
- 使用Web技术栈 (JavaScript/TypeScript, HTML, CSS)
- 丰富的生态系统和社区支持
- 与Vue 3良好集成
**影响**:
- 应用体积较大
- 内存占用相对较高
- 开发效率高

#### ADR-002: 选择Monaco Editor作为编辑器
**状态**: 已采纳
**背景**: 需要专业的代码编辑体验
**决策**: 使用Monaco Editor
**理由**:
- VS Code同款编辑器，功能强大
- 原生支持TypeScript
- 丰富的API和扩展能力
- 性能优秀
**影响**:
- 增加应用体积
- 学习曲线较陡

#### ADR-003: 采用多进程架构
**状态**: 已采纳
**背景**: Electron应用架构选择
**决策**: 采用主进程+渲染进程+预加载脚本的多进程架构
**理由**:
- 符合Electron最佳实践
- 提高应用稳定性和安全性
- 便于职责分离
**影响**:
- IPC通信复杂度增加
- 需要处理进程间同步

#### ADR-004: 使用Vuex进行状态管理
**状态**: 已采纳
**背景**: Vue应用状态管理方案选择
**决策**: 使用Vuex进行全局状态管理
**理由**:
- Vue官方推荐
- 简单易用
- 满足当前需求
**影响**:
- 状态管理相对简单
- 未来可能需要迁移到Pinia

#### 模块职责

**1. 配置存储层 (quick-link-config.ts)**
- 提供配置的CRUD操作接口
- 管理配置的持久化存储
- 提供默认配置
- 配置数据验证

**2. 配置管理对话框 (ShowQuickLinkSettingDialog.ts)**
- 提供图形化配置界面
- 处理用户交互
- 表单验证
- 配置预览

**3. IPC通信层**
- 主进程与渲染进程通信
- 配置数据传输
- 事件处理

**4. UI展示层**
- 动态渲染快速链接
- 处理链接点击事件
- 响应配置更新

#### 接口设计

**配置存储接口**
```typescript

export function getQuickLinks(): QuickLinkItem[]

export function saveQuickLinks(links: QuickLinkItem[]): void

export function addQuickLink(link: QuickLinkItem): void

export function updateQuickLink(link: QuickLinkItem): void

// 删除快速链接
export function deleteQuickLink(id: string): void

// 重置为默认配置
export function resetToDefault(): void
```

**IPC通信接口**
```typescript
// 获取快速链接配置
ipcMain.on('get-quick-links', (event) => {
    const links = getQuickLinks()
    event.returnValue = links
})

// 保存快速链接配置
ipcMain.on('save-quick-links', (_, links: QuickLinkItem[]) => {
    saveQuickLinks(links)
})

// 重置快速链接配置
ipcMain.on('reset-quick-links', () => {
    resetToDefault()
})
```

#### 配置数据结构

```typescript
interface QuickLinkItem {

    path: string            // URL或程序路径
    icon: 'svg' | 'img' | 'emoji'  // 图标类型
    iconContent: string     // 图标内容

interface QuickLinkConfig {
    links: QuickLinkItem[]
}
```

#### 技术选型

**配置存储**: electron-store
- 优点: 简单易用,自动持久化,支持加密
- 适用场景: 应用配置存储

**IPC通信**: Electron IPC
- 优点: 安全可靠,支持同步和异步
- 适用场景: 主进程与渲染进程通信

**UI框架**: 原生HTML + CSS + JavaScript
- 优点: 无需额外依赖,性能好
- 适用场景: 简单对话框界面
